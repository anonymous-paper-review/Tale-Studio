# 밤 매니페스트 — 러너 계약 v1

> 상태: **러너 미스케줄** (스케줄 배선은 오너 결정 대기). 러너가 뜨면 이 문서를 가장 먼저 읽는다.
> 러너는 맥락 제로 전제 — 티켓 밖 정보가 필요해지면 그 티켓은 잘못 쓰인 것이다(실행 말고 blocked 처리 + 사유 기록).

## 티켓 선택

- `status: ready`만 집는다. `priority: high` 먼저, 같으면 T0 → T1 → T-fix 순.
- `blockers`가 비어있지 않으면 실행 금지. 단 티켓 본문에 "준비" 범위가 명시된 준비 티켓은 그 범위까지만.
- 한 번에 하나씩 완결(산출 계약 이행 → status 갱신) 후 다음 티켓.

## 예산 (실측 단가: 텍스트 풀런 $1.9~2.1 · 영상 $7/9클립 · $35.56/30클립+15장)

- **T0**: 건수 무제한 — 단 read-only 강제.
- **T1**: 밤 합산 **$10**.
- **T2**: 티켓에 오너 승인 금액이 명시된 것만. 밤중 신규 발주 금지.
- 예산 소진 시: 실행 중 티켓만 마무리하고 정지. 지출은 리포트에 티켓별 기재.
- 쿼터: 밤은 유저 트래픽과 비경합이나 RPD는 일 단위 잔고를 소모한다(런당 71콜 — 실질 미미, 기재만).

## 불변 규칙

1. **기각 조건 소급 수정 금지** — 티켓의 가설 5줄은 읽기 전용. 결과 보고 문구를 고치고 싶으면 그 사실 자체를 리포트에 적는다.
2. **판정 3원칙** — LLM은 지각만, 채점은 코드, 연결 불확실은 추측 금지·NA. 혼합 지표 금지(A2 계기 결함의 교훈).
3. 고분산 지표(벽시계 등)는 팔당 ≥3런 + ±30% 가드 (shotCheck 다이어트 기각의 교훈).
4. **제품 코드(src/) 수정 금지** — T-fix도 브랜치 준비까지. 머지·커밋·push 금지. **메인 워크트리에서 브랜치 전환 금지** — T-fix는 별도 git worktree(`git worktree add ~/projects/tale-studio-night <새브랜치>`)에서 작업한다. 유저의 체크아웃(main, 미커밋 변경 포함)은 아침에 그대로여야 한다.
5. **DB는 read-only** — write가 필요한 티켓은 존재 자체가 오류(blocked 처리).
6. **vault(.claude/vault/) 수정 금지** — 밤 산출의 정본은 `research/experiments/<id>/`. vault는 사람 세션의 증류.
7. **컨텍스트 위생** — 모델 원출력을 대화 컨텍스트에 대량 인용하지 않는다. 스크립트 직변환·서브에이전트 경유 (2026-08-10 안티-증류 분류기 오탐 실발생, 우회 실증됨).
8. **티켓 밖 신규 가설 실행 금지** — 실행 중 새 가설이 보이면 `status: draft` 티켓 초안으로만 제안하고 아침 자격 심사로 넘긴다.
9. 실험 코드 규칙(`.claude/rules/experiments.md`) 준수 — 제품 함수 직접 import(복붙 금지)·상류 fixture 고정·좌표 기록.

## 산출 계약 (밤 전체)

- `research/backlog/reports/YYYY-MM-DD.md` — 원장: 티켓별 1줄(판정·발동한 기각 조건·지출) + 합계 + draft 제안 목록 + `_MORNING.md`에 새로 붙인 증거 목록.
- `research/backlog/reports/YYYY-MM-DD.html` — 사람용 리포트: `~/.claude/skills/readable-report/SKILL.md` 형식 (티켓마다 맥락→가설→확인→결과, 본문 개발 표기 금지, 상세는 접기). 가능하면 Artifact 발행 + URL을 md 원장에 기록.
