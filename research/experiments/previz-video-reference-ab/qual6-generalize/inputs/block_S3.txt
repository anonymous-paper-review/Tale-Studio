Camera choreography, one move: this shot has no camera move at all — the single instruction is to hold. The camera is locked off on a tripod at the framing of the start image and that framing is held exactly, edge for edge, from the first frame to the last: the same lens, the same height, the same distance, the same window mullions cutting the frame in the same places, the same dark desk edge across the bottom. First the frame is exactly the start image; then it simply stays that frame. Nothing travels — no pan, no tilt, no dolly, no push-in, no drift, no orbit, no crane, no zoom, no roll, no reframing of any kind — the only things that change inside the locked frame are the dust drifting in the light and the flicker of the light itself, and the final frame is still the same framing as the first.
