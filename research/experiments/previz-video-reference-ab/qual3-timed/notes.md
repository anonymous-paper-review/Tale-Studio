## 넣은 것 (양 암 완전 동일 — 통제 조건)

동결 기본 프롬프트 전문 뒤에 초 단위 카메라 안무 블록 1개를 붙였다. 시간표 숫자는 추측이 아니라
`../qual2-fullmotion/blockout_v2.py`의 실제 키프레임(FPS 24, f=1..168)에서 환산한 것:

| 구간 | blockout_v2.py 실제 값 | 프롬프트 문장 요지 |
|---|---|---|
| 0.0–1.0s (f 1–24) | φ=0 (러너 정면 +X), r 6.0→4.8 선형, z=1.1 고정 | 정면 head-on, 도어웨이를 등진 소녀, 카메라가 그녀보다 조금 느리게 후퇴해 간격 6→4.8 m로 좁아짐, 각도·높이 불변 |
| 1.0–2.0s (f 25–48) | φ 0→−90° smoothstep, r 4.8→6.0, 항상 러너 조준 | 1/4 원호 스윙(1.5s 부근이 가장 빠름), 거리 4.8→6.0으로 다시 벌어짐, 끝나면 화면 오른쪽으로 달리는 측면 프로필 |
| 2.0–7.0s (f 49–168) | φ=−90° 고정, r=6.0 고정, cam.x = runner.x (동속 5.5 m/s) | 측면 프로필 유지, 6 m 거리 고정, 러너 속도와 같은 속도로 횡이동, 벽이 오른→왼으로 흐름, 마지막 프레임까지 변화 없음 |

두 암의 차이는 `video_urls` 하나뿐 — **T3D** = 블록아웃 v2 영상 참조 재사용(qual2에서 올린 fal URL 그대로),
**TXT** = 영상 참조 없이 START 그림 1장만. 프롬프트·모델·해상도·duration·오디오 플래그는 동일.

## 나온 것 — T3D (블록아웃 v2 동반)

1. **0~1초** — 시간표대로 정면 head-on으로 열린다. 첫 프레임은 START 그림 구도(문틀 안 소녀, 하단 양측
   무너진 격자 전경)와 거의 겹친다. 0→1초 동안 전경의 격자가 뒤로 물러나 소녀 발치까지 밀리고
   소녀는 전신 → 허벅지 위 프레이밍으로 커진다(간격이 좁아지는 방향은 시간표와 같음).
   1.0초 프레임에서 시작 문틀은 이미 화면 밖이고 양측 벽만 남는다. 각도·높이 변화는 안 보인다.
2. **전환 시각** — 지시한 1.0~2.0초에는 아무 일도 안 일어난다. 정면 구도가 **약 3.0초까지** 그대로
   이어지고, 3.0초 부근부터 서서히 비스듬해져 **4.25~4.5초에 완전 측면 프로필**에 도달한다.
   즉 스윙이 **약 2초 늦게 시작**했고, 스윙 길이도 지시한 1.0초보다 길다(약 1.25~1.5초).
   방향과 종착 구도(측면·화면 오른쪽 질주)는 지시와 같다.
3. **유지 구간** — 측면 프로필에 도달한 뒤 4.5~7.0초 내내 측면 횡이동이 끊기지 않는다. 소녀 크기는
   대체로 일정하고 벽이 오른쪽→왼쪽으로 흐른다. 마지막 프레임도 측면 프로필(끝까지 감).
4. **배경 정체** — 회색 콘크리트 산업 복도로 시작해 끝까지 같은 재질·톤을 유지한다(바닥의 무너진 격자,
   벽 패널, 천장 채광창). 다만 **마지막 0.3초 부근에서 큰 개구부가 열리며 바깥(밝은 야외 폐허)이 보인다**
   — 7초 내내 닫힌 복도는 아니다.
5. **도형·색 유출** — 주황 캡슐·회색 박스·플랫 셰이딩 등 블록아웃 도형이나 색이 화면에 나온 프레임은
   못 찾았다. 출력 기하는 발주대로 **1280×720(16:9)**.

## 나온 것 — TXT (3D 없이 START 1장)

1. **0~1초** — 역시 정면 head-on으로 열리고 첫 프레임은 START 구도와 겹친다. 격자가 물러나고 소녀가
   전신 → 허벅지 위로 커지는 정도는 T3D와 비슷하다. 차이는 배경 잔존: **1.0초 프레임에도 시작 문틀이
   그녀 뒤에 아직 남아 있고**, 화면 하단에 바닥 잔해가 T3D보다 넓게 잡힌다. 각도 변화는 안 보인다.
2. **전환 시각** — 1.0~2.0초에는 변화가 없다. 정면 구도가 **약 3.5초까지** 유지되다가 3.5초 부근부터
   빠르게 돌아 **4.0~4.25초에 측면 프로필**이 된다. 스윙 시작이 **약 2.5초 늦고**, 스윙 자체는 짧다
   (약 0.5~0.75초로 T3D보다 급하다). 종착 구도는 지시대로 측면·화면 오른쪽 질주.
3. **유지 구간** — 4.25~7.0초 측면 횡이동이 끝까지 유지된다. 소녀 크기·화면 위치가 T3D보다 안정적이고,
   수평 파이프 레일과 형광등이 일정한 리듬으로 오른→왼으로 흐른다. 마지막 프레임도 측면 프로필.
4. **배경 정체** — 7초 내내 **닫힌 실내**를 유지한다(야외 노출 0). 다만 배경의 성격이 중간에 바뀐다:
   0~3초는 늘어진 전선·거친 콘크리트 벽, 4초 이후는 형광등 + 수평 파이프가 이어지는 정비 통로.
5. **(해당 없음 — 3D 없음)** 출력 기하는 **1112×834(4:3)**로 발주 720p(16:9)가 아니라 참조 이미지
   비율을 따라갔다(1차 (a)·(b)와 같은 현상, `../probe-startframe/findings.md`의 남는 불확실성 항목).

## 두 암을 나란히 놓았을 때 눈에 띄는 차이 (관찰, 판정 아님)

| 축 | T3D | TXT |
|---|---|---|
| 0~1초 구도 | 정면 head-on, 1.0초에 문틀 소실 | 정면 head-on, 1.0초에도 문틀 잔존 |
| 스윙 시작 | 약 3.0초 | 약 3.5초 |
| 스윙 완료 | 약 4.25~4.5초 (완만) | 약 4.0~4.25초 (급함) |
| 유지 구간 | 4.5~7.0초 유지, 크기 다소 요동 | 4.25~7.0초 유지, 크기·위치 안정 |
| 배경 | 산업 복도 → 끝에 야외 개구부 노출 | 끝까지 닫힌 통로(전선 → 형광등 정비로) |
| 출력 기하 | 1280×720 (발주대로) | 1112×834 (참조 비율) |
| 도형 유출 | 없음 | 해당 없음 |

공통: 양 암 모두 **구간의 순서와 종착 구도는 시간표와 같고(정면 → 스윙 → 측면 유지), 구간의 시각만
뒤로 밀렸다** — 정면 구간이 지시된 1초의 3~3.5배로 늘어났고, 스윙은 지시된 1~2초 창이 아니라
3~4.5초 사이에 일어났다. 유지 구간은 두 암 모두 마지막 프레임까지 끊기지 않았다.
