# 글에서만 의미 있는 지적이 그림 주문서에서 실제로 빠졌는가

**판정: 가설 유지 — 새는 곳이 없다.** 라우팅 수정 이후에 만들어진 작업물에서 그림 주문서로 넘어간
지적은 **전부 "화면으로 확인 가능"으로 분류된 것**이었고, 텍스트 전용 지적이 섞여 들어간 사례는 0건이다.

**다만 반쪽 확인이다.** 그 작업물에서는 애초에 텍스트 전용으로 분류된 지적이 **하나도 나오지 않았다.**
즉 "새지 않는다"는 확인됐지만, **"골라내는 기능이 실제로 골라내는 것"은 아직 목격되지 않았다.**

- 날짜: 2026-08-12 (밤 러너)
- 지출: $0 (읽기 전용 조회)
- 기각 조건 발동: **없음** (사전 등록: "텍스트 전용 지적이 1건이라도 그림 주문서에 있으면 기각")

## 결과

| | 수정 이후 (1건) | 수정 이전 (대조 5건) |
|---|---|---|
| 지적 총계 | 12 | 54 |
| 그중 "화면 확인 가능"으로 분류 | **12 (전부)** | 0 |
| 분류 자체가 없는 옛 지적 | 0 | **54 (전부)** |
| 그림 주문서로 넘어간 것 | 12 | **0** |
| 텍스트 전용이 새어 들어간 것 | **0** | 0 |
| 지적 문장이 주문서 본문에 통째로 박힌 것 | **0** | 0 |

옛 작업물의 지적 54건은 분류 칸이 아예 없어서 **전부 차단**됐다. 이건 설계대로다 —
"분류가 없으면 일단 막는다"는 안전 쪽 기본값이 실제로 그렇게 동작하고 있다.

## 무엇이 아직 확인 안 됐나

수정 이후 작업물이 **1건뿐**이고, 그 안의 지적 12건이 **전부 시각 분류**였다.
그래서 이번 확인이 증명한 것은 정확히 이것뿐이다 — **"시각으로 분류된 것은 통과하고, 분류가 없으면 막힌다."**

증명되지 않은 것: **"텍스트 전용으로 분류되는 지적이 실제로 생기고, 그것이 막히는가."**
그런 지적이 한 건도 안 나왔기 때문에 그 경로는 이번에 밟히지 않았다. 다음 작업물에서
텍스트 분류가 하나라도 나오면 같은 스크립트를 그대로 다시 돌려 확인하면 된다(좌표 동일).

## 정직 보고 — 첫 판정은 틀렸다

처음에는 지적 문장에서 **단어를 보고** 텍스트 전용 여부를 가리려 했다(대명사·문법·대사 관련 단어).
그 방식으로는 **위반 3건**이 나왔고, 그대로 믿었으면 "가설 기각"으로 보고할 뻔했다.

실제로 열어보니 셋 다 **멀쩡한 시각 제약**이었다:

- "The guard leader is visually distinguished … with **his** crimson-trimmed gorget visible …"
- "The girl is shown standing upright beside the pipe, not kneeling, as **she** presses **her** ear to the surface."
- "The valve handle is mounted on the chamber wall behind the girl … visible around **her**."

영어 시각 묘사에 대명사가 들어가는 건 당연한데, 그걸 "텍스트 전용 지적"의 표지로 삼은 게 잘못이었다.
그래서 판별을 **단어 추측에서 분류 필드 대조로 바꿨다** — 지적마다 붙어 있는 분류 값을 그대로 읽고,
그림 주문서에 실린 문장이 그 분류가 시각인 지적에서 왔는지 **글자 단위로 대조**한다. 추측이 사라졌다.
