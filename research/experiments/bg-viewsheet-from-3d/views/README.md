# 법정 배경 뷰 시트 — 각도별 스냅샷 5장

한 채의 3D 블록아웃(`../courtroom_blockout.py`)에서 **카메라만 바꿔** 뽑은 배경 스냅샷.
전부 1280×720 PNG, Cycles 160 samples, 렌즈 센서폭 36mm.

좌표계: **+Y = 판사석 쪽**, **-Y = 방청석/입구**, **+X = 방청석에서 판사석을 볼 때의 오른쪽**, **+Z = 위**.
실내 X ∈ [-7, 7] · Y ∈ [-10, 10] · 천장 소핏 4.45 / 중앙 리세스 4.95 (단위 m).

각도 5개는 발명이 아니라 이 로케이션 54샷의 실제 수요에서 유도했다 —
eye_level 39 / low_angle 10 / high_angle 3, 뷰 클러스터 = 판사석·벽·방청석·천장·디테일.

## 각 뷰가 담은 것

- **`view_bench_eye`** — 방청석 뒤 중앙축에서 본 판사석 정면. 참조 사진(`../ref_location_wide.png`)과
  같은 자리·같은 렌즈라 **직접 대조용**이다. 담긴 것: 판사석 + 단상, 배면 휘장·금속 명패,
  좌 태극기 / 우 법원기, 그 바깥 어두운 출입구 2, 좌우 유리 난간 단, 유리 바, 방청 벤치, 챔퍼 천장 라인.
- **`view_gallery_eye`** — 판사석 앞에서 입구 벽을 보는 **리버스**. 2D 참조 1장이 무너지는 지점이
  정확히 여기(반대편을 보면 다른 방이 됨)라 이 실험의 급소다. 담긴 것: 방청 벤치 5행 ×2열과 중앙 통로,
  입구 양문, 유리 바를 뒤에서 본 모습, 앞뒤로 이어지는 같은 벽 패널·코브·천장 리세스.
- **`view_witness_low`** — 법정 안쪽 빈 바닥에서 유리 증인석을 올려다본 low angle.
  담긴 것: 유리 증인석 근경, 그 너머 판사석 2단 프로파일과 모니터, 배면 휘장·명패, 천장 매립 슬롯과 리세스 단차.
- **`view_room_high`** — 방청석 위에서 내려다본 법정 전체. 배치 전체(통로·유리 바·좌우 단·단상·판사석)가
  한 장에 들어와 **다른 4장의 공간 관계를 검산하는 기준 도면** 역할을 한다.
- **`view_wall_eye`** — 좌측에서 우측 벽을 향한 대각선 eye level. 담긴 것: 우측 벽 대리석 패널 조인트와
  코브, 좌측에 판사석 측면 프로파일 + 휘장 + 금속 명패, 법원기, 중앙에 유리 증인석.

## 이 스냅샷들이 지키는 것

- 텍스처 이미지 0장, 인물 0명. 기하와 랜드마크 배치만 — 그림체는 하류 모델이 다시 입힌다는 전제.
- 5장 전부 같은 씬의 같은 프레임에서 렌더됐다. 벽·천장·바닥·랜드마크가 좌표 수준에서 동일하므로
  각도가 바뀌어도 "다른 방"이 될 수 없다. 그게 이 시트의 유일한 주장이다.
