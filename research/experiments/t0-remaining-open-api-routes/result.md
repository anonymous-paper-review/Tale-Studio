# 열어둔 채 남긴 창구가 정말 무해한가

**판정: 가설 기각.** 사전 등록한 추출 규칙("로그인 확인 코드가 없는 창구")으로 뽑으면 **9개**가 나오고,
그중 **3개가 돈 쓰는 호출이나 데이터 쓰기를 한다.** 기각선("1건이라도 있으면 기각")이 발동했다.

다만 곧바로 붙여야 할 단서가 있다 — 그 3개는 **로그인이 아닌 다른 문지기**를 각자 두고 있다
(서명 검증 / 서버끼리만 아는 비밀번호). "누구나 부를 수 있는 채로 돈을 쓴다"는 뜻이 아니다.
정확한 결론은 **"어제 선언한 '남은 건 전부 읽기 전용 공개 표면'은 사실이 아니다"** 쪽이다.

- 날짜: 2026-08-12 (밤 러너)
- 지출: $0 (코드 추적만 — 실제 호출 0건, 티켓 지시 준수)
- 기각 조건 발동: **있음 🔴** (사전 등록: "무인증 라우트 중 유료 호출 또는 DB 쓰기가 1건이라도 있으면 기각")

## 전체 그림

창구 66개 중 로그인 확인이 있는 것은 57개. 나머지 9개를 문지기 종류별로 갈랐다.

### ① 문지기가 아예 없는 5개 — 전부 읽기 전용 ✅

| 창구 | 하는 일 | 위험 |
|---|---|---|
| 카메라 사전 | 고정된 장비 목록 반환 | 없음 (파일 읽기) |
| 카메라 무빙 사전 | 고정된 무빙 목록 반환 | 없음 |
| 공개 갤러리 | 게재 승인된 항목 60개 반환 | 없음 (승인된 것만) |
| 이미지 서버 상태 | 내부 이미지 서버가 살아 있는지 | **내부 주소가 응답에 실려 나온다** |
| 영상 서버 상태 | 내부 영상 서버가 살아 있는지 | **내부 주소가 응답에 실려 나온다** |

앞의 3개는 어제 "의도된 공개 표면"이라고 선언된 그대로다. **뒤의 2개(서버 상태 확인)는 그 선언에 없던 것**이고,
살아 있을 때 내부망 주소를 그대로 응답에 담는다. 돈도 안 쓰고 쓰기도 안 하므로 기각 사유는 아니지만,
"열어둔 것을 전수 확인했다"는 진술은 이 둘을 빠뜨리고 있었다.

### ② 로그인은 없지만 다른 문지기가 있는 4개

| 창구 | 문지기 | 하는 일 | 판정 |
|---|---|---|---|
| 공유 링크 열람 | 공유 토큰(64자리) + 만료·폐기 확인 | 스냅샷 반환 | 읽기 전용 ✅ |
| 그림 생성 완료 콜백 | **전자 서명 검증**(위조 차단) | 작업 결과를 저장소·DB에 기록 (쓰기 지점 29곳) | 🔴 쓰기 |
| 작업 단계 실행 | 서버끼리 아는 비밀번호. 미설정 시 **운영에선 거부**, 개발에선 통과 | 글쓰기 파이프라인 실행 — **돈 쓰는 모델 호출** | 🔴 유료 |
| 멈춘 작업 되살리기 | 정기 실행 비밀번호. 미설정 시 **운영에선 거부**, 개발에선 통과 | 멈춘 작업을 찾아 단계 실행 재트리거 | 🔴 유료 |

세 개 모두 어제 감사에서 손을 댄 자리다(원래는 "비밀번호가 없으면 검사 자체를 건너뛰는" 구조여서
실제로 아무나 부를 수 있었고, 지금은 **없으면 거부**로 뒤집혀 있다). 즉 알려진 구멍은 막혔고,
남은 것은 **로그인 기반이 아닌 문지기에 의존한다는 사실 자체**다.

## 그래서 무엇이 실제 리스크로 남나

1. **운영 환경에 비밀번호가 실제로 설정돼 있는지는 이 티켓에서 확인 불가**(배포 환경 변수를 못 본다) — **NA**.
   설정돼 있으면 안전, 없으면 거부(500)라 악용은 안 되지만 **작업 재개 자체가 죽는다.** 확인할 사람은 오너다.
2. **개발 환경은 무방비다** — 비밀번호가 없으면 경고만 찍고 통과한다. 로컬·프리뷰 배포가 외부에서
   닿는 상태면 그대로 유료 호출을 부를 수 있다.
3. **서버 상태 확인 2개의 내부 주소 노출** — 어제 목록에 없던 창구다. 공격 표면은 작지만 "전수 확인"의
   구멍이었다는 사실이 더 중요하다.

## 이 판정의 경계 (읽는 사람이 알아야 할 것)

기각은 **사전 등록한 추출 규칙을 문자 그대로 적용한 결과**다. 그 규칙은 문지기를 "로그인 확인 코드가
있느냐"로만 판별하기 때문에, 서명·비밀번호 같은 다른 문지기를 가진 창구도 "무인증"으로 분류된다.
러너는 기각 조건을 고칠 수 없으므로(불변 규칙), 규칙대로 기각을 적고 그 옆에 이 단서를 남긴다.
**"위험한 창구가 열려 있다"가 아니라 "열려 있다고 부를 창구의 정의가 어제 판단보다 넓다"**로 읽는 게 맞다.
