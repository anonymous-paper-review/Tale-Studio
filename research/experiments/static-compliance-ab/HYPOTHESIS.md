# 가설 — static 계약문 강화 A/B (금지조항 문구 넣기 전/후)

> 사전 등록 2026-08-10. 재검증 2호 — 1호(ti2v-camera-cap-recheck)의 역전 발견에서 파생:
> "움직이지 마라"(LOCKED) 계약이 운동 함의 콘텐츠 3샷에서 3/3 위반됨(모델이 피사체를 따라
> 카메라를 스스로 움직임). 오너 지시: "멈추라는 지시를 지키게 만들기 — 프롬프트 개선 진행".

- **가설**: static 계약문에 ① 고정 마운트 비유("rigidly bolted in place") ② 프레이밍 불변식
  ("첫 프레임과 끝 프레임의 배경 구도가 동일") ③ 피사체 이탈 허용("피사체가 프레임 밖으로
  나가도 카메라는 절대 따라가지 않는다")을 명시하면, 운동 함의 콘텐츠에서 LOCKED 준수율이
  현행(0/3) 대비 오른다. — 위반의 원인이 "피사체를 프레임에 잡아두려는 본능"이라는 진단에서
  유도된 문구다.
- **전제**: 대조군(A: 현행 문구)은 1호 실험의 T0 3클립을 재사용 — 같은 3샷·같은 첫 프레임·
  같은 모델(happy-horse 720p)·같은 판정 프로토콜이므로 비교 유효. 처치(B)는 buildVideoPrompt
  산출에서 static 절만 문자열 교체(다른 절 — 피사체·페이스·금지문 — 은 동일, 원문 부재 시
  실험 중단으로 오염 방지).
- **예측**: 참이면 — B 3클립 중 2개 이상에서 블라인드 판독이 "카메라 고정"(배경 구도 불변)을
  보고한다. 거짓이면 — B에서도 피사체 추종·자발 무빙이 다수.
- **측정**: 같은 3샷(질주/발견 클로즈업/지하 전경) × 강화 문구 = 3클립 신규 생성. 판독자 3인이
  각자 3클립 전부를 독립 판독(발주 은닉, 1fps 프레임열) → 클립당 3표 다수결로 "카메라 고정 /
  움직임" 판정 → A(기존 T0 판독)와 대조.
- **기각 조건**: B 준수 ≤ 1/3이면 문구 강화 무효 판정 — 프롬프트 밖 해법(모델 파라미터·후처리·
  모델 교체)으로 넘긴다. 채택 기준: B 준수 ≥ 2/3이면 motion-contract static 절에 배선(오너
  기승인). 비용: 3클립 ≈ $2.4.
