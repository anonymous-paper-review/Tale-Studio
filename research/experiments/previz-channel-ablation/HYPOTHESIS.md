# 가설 — previz 채널 판독력 ablation (축 A, 2026-08-10)

- **가설**: 우리 previz 채널은 생성기를 실제로 조향한다 — ① 리페인트(I2I)가 러프 스트립의 구도·포즈·블로킹을 따르고(정적 조향) ② 영상 생성이 END 참조가 지시한 도착 상태로 수렴한다(동적 조향 — END 프레임이 곧 이미지 형태의 모션 주문).
- **전제**: 프로덕션 경로 = 러프 3패널 스트립(START / DIRECTION[화살표+라벨] / END, 목각 마네킹) → `buildRealStripPrompt` 리페인트(캐릭터/스타일 참조 동반, 화살표는 중간 패널 주석으로만 재현 지시) → reference-to-video(START+END 등 다중 참조 + 모션 텍스트, fal `referenceImages` #previz-video 2026-07-22). 정확한 배선 좌표(영상이 받는 참조의 패널 구성·API 파라미터)는 Phase 0에서 확정해 아래 좌표 섹션에 기입 — **측정·기각 조건은 그와 무관하게 불변**.
- **예측**: 참이면 — A1(리페인트) 블로킹 일치 ≥95%, 화살표 오염(중간 패널 주석 외 위치 출현) ≤5%. A2(영상) END-참조 팔의 도착 상태 일치율이 START-only 팔보다 **≥20%p** 높다. 거짓이면 — A1 일치 낮음(리페인트가 러프 무시) 또는 A2 증분 ≈0(END 참조가 장식).
- **측정**: 실제 프로덕션 산출물(러프·리얼 스트립·에셋이 이미 존재하는 프로젝트)에서 대표 샷 5개 — 모션 복잡도 스펙트럼(정지 1 · 단일동작 2 · 2동작 1[검수 분할 부모면 이상적] · 카메라무빙 1). A1: 샷당 리페인트 3회 = 15장, 패널별 체크리스트(블로킹 일치 / 마네킹→캐릭터 치환 / 화살표 위치). A2: 샷당 {START-only, START+END} × 3회 = 30클립, 판정 = 마지막 1초가 END 프레임 구도와 일치하는가 · 모션 방향 일치 · 오염(화살표/패널 경계 유출). 판정자 = VLM 1차(`src/lib/adherence/vision.ts` 재사용 가능성 Phase 0에서 평가) + 사람 스팟 교차, 불일치 시 사람 우선.
- **기각 조건 (사전 등록 — 결과 본 뒤 수정 금지)**: ① A1 블로킹 일치 <80% → "리페인트가 러프를 안 따름" — previz 포맷 재설계 안건(스트립 무의미가 아니라 전달 방식 문제). ② A2 증분 <10%p → "END 참조 조향 무효" — 영상 채널 재설계 안건, 축 B(용량 배터리)는 START-only 구성으로 측정. ③ 증분 10~20%p → 판정 유보, n 증설 후 재판정. ④ A2 증분 ≥20%p → 채널 유효 확정, 축 B는 프로덕션 구성(START+END)으로 측정.

수용선 95%는 오너 확정(2026-08-10). 축 B(클립 서사 용량 배터리)는 이 실험의 구성 판정 이후 별도 등록 — 지금 등록하면 A 결과에 따라 소급 수정 위험.
