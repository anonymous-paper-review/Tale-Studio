# 가설: 전 레이어 출력 언어 무침범 (2026-08-19, 사전 등록)

- **가설**: 같은 한국어 시드(스토리+한국어 캐스트)에서 outputLocale 만 en/ko 로 바꿔 writer 텍스트
  파이프라인 전 레이어(s0→s1→s3→v0→v1→v2→v3→decoupage→v4/dialogue/v5)를 돌리면, 각 레이어의
  **유저 노출 자유서술 필드**가 전부 해당 언어를 따르고 교차 침범이 없다.
- **전제**: #20 배선 완료(절 주입·발화 분기·상대 참조 자동 정합), s0 단층 실측 통과(어제).
  v0·v1 은 절 미주입(디자인 어휘 산출 — 설계상 제외), v4 자유서술·v5 프롬프트는 생성기행 영어
  강제(양 로케일 공통 영어가 정답).
- **예측**: en 런의 유저 노출 필드 한글 0 / ko 런의 유저 노출 필드는 한국어(영어 침범 0).
  v4/v5 는 양 런 모두 영어. 침범이 나온다면 절 미주입 레이어(v0/v1)나 한국어 시드 재료가
  강하게 인용되는 지점(캐스트 이름 인접 서술)일 것.
- **측정**: 레이어별 JSON 전 문자열 필드 워크 → 필드 분류(유저 노출 자유서술 / 영어 강제 /
  식별자·enum 면제) → 로케일 불일치 카운트+예시. 같은 시드 고정, 레이어 산출 원문 보존.
- **기각 조건**: 어느 레이어든 유저 노출 자유서술에서 불일치 >0 이면 그 레이어의 강제 배선
  실패로 판정(= #20 미완, 해당 지점 수리 대상). 식별자/enum/영어 강제 필드의 영어는 침범이 아니다.
