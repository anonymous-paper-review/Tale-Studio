## 논의 필요 항목

1. **F1 진행바 방향**: "위→아래"가 정확히 어떤 그림인지 — 세로 진행바인지, 채팅창 상단에 붙는 가로 바인지, 단계가 위에서 아래로 쌓이는 체크리스트인지. 스케치 필요.
2. **F2 중앙 배치**: 대시보드 "중앙"이 상시 중앙 오버레이인지, 콘텐츠 비었을 때만 중앙(empty state)인지.
3. **F8 정형 타일 기준**: 캐릭터보드에서 남길 항목(뷰 각도 몇 개, 표정 몇 개)과 지울 항목의 기준 — 오너와 타일 구성 확정 필요.
4. **F4 Take 인포**: 좌측 아이콘바에 넣을 정보 범위 — 잔여 Take, 이번 액션 차감량, 요금제 링크. 생성 버튼 옆 "–1 Take" 뱃지도 함께 갈지.
5. **F11 도구 통합**: 자르기 빈도가 낮으면 선택 도구에 흡수(클립 경계 호버 시 자르기 커서). 실사용 확인 후 결정.
