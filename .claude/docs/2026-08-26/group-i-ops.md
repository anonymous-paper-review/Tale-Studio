# 그룹 I — 운영

상태: 대기 · 우선순위: 9

## 이슈

| # | 항목 |
|---|---|
| I1 | FAL 계정 만들기 |

## 메모

- 코드 작업 아님. 오너 액션 또는 오너 위임 필요 (결제 수단 연결).
- 그룹 C2(동시 호출 한도)와 연결됨 — 계정 등급에 따라 동시 생성 한도가 달라지므로, 계정 생성 시 등급/한도를 확인해 C2 설계에 입력값으로 쓴다.

## 논의 필요 항목

1. 현재 fal 호출이 어느 계정/키로 나가고 있는지, 새 계정으로 갈아탈 때 키 교체 범위 (환경변수 위치, 배포 반영).
2. 계정 등급 선택 — 동시 한도와 단가 확인 후 결정.
