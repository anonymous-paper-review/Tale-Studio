- C1+C2는 동시성 문제로 보임: 동시 호출 한도(클라이언트 큐 or fal 계정 한도)에 걸리면 에러 처리 없이 조용히 실패하고, 카운트까지 어긋남(12→11은 실패한 잡이 목록에서 사라진 것으로 추정).

## 논의 필요 항목

1. **C5 real 바로 생성 끄기**: 오너 지시는 명확 ("real 바로 생성 끄기"). Pre-viz → 오너 확인 → Real 생성의 2단계 플로우로 복원하면 되는지, 아니면 설정 토글로 둘지.
2. **C2 동시 호출 한도**: fal 계정 등급별 동시 한도를 확인하고, 클라이언트에 큐(대기열)를 둘지 서버에 둘지. 큐에 쌓인 건 "대기 중 n번째"로 표시.
3. **C1 카운트 감소**: 실패한 잡을 목록에서 지우지 말고 "실패 — 다시 시도" 상태로 남길지.
4. **C8 Draft Render**: 기대 출력물이 뭔지 정의 필요 — 파일 다운로드? 미리보기 재생? (그룹 H의 출력 기능과 경계 정리)

## C5 — 닫힘. 진입 자동 실사 생성 제거 (2026-08-27)

### 오너 지시

> "real 바로 생성 끄기라는 게 Director로 넘어오면 i2i 이미지가 바로 생성되는 로직인데
> 그걸 없애고, 특정 버튼으로 전체 재생성하든, 하나하나 눌러서 단독 생성하든,
> 채팅으로도 둘 다 가능하게 하는 걸로 바꾸는 것"

### 껐던 것 — 발사 지점이 둘이었다

| 위치 | 내용 |
|---|---|
| `director/page.tsx` | 진입 즉시 발사(`#real-grid-auto` 이관분) |
| `use-writer-director-sync` Pass 2.7 | "안전망"으로 남아 있던 두 번째 발사 |
| `real-batch-client` | `triggerRealBatchAutofill` 정의 자체 제거 — 남기면 누군가 다시 부른다 |

하나만 껐으면 다른 하나가 계속 쐈다.

### 세 경로 — 하나는 비어 있었다

| 경로 | 상태 |
|---|---|
| 전체 버튼 → `runRealBatch` | 이미 있었음 |
| 개별 클릭 → `generateStoryboardImage` | 이미 있었음 |
| **채팅** | **없었음 — 이번에 만듦** |

채팅 액션 목록에 영상 생성(`generateVideo`)은 있는데 **실사 이미지 생성이 없었다.**
자동 생성을 끄면서 이걸 안 메웠으면 "채팅으로도 가능하게"라는 지시가 지켜지지 않는다.
`generateImage` 액션을 신설했다 — id 를 주면 그 샷, 생략하면 미생성 전체.
라우트 허용·검증·프롬프트 문서화·스토어 실행 4지점을 배선했다.
(`real-batch-client` 가 스토어를 import 하므로 전체 일괄은 동적 import 로 순환을 끊었다.)

### 검증

실사 14개를 **전부 비운 상태**로 Director 진입 — 예전이면 즉시 발사됐을 조건이다.

## C4 — 닫힘. 생성 버튼이 화면을 뺏지 않는다 (2026-08-27)

원인은 한 줄이었다. 이미지·영상 생성 액션 둘 다 `set({ viewMode: 'storyboard' })` 로
화면을 밀고 있었다 — Node 뷰에서 눌렀는데 Storyboard 로 튀는 이유.

수리: 스토리보드 뷰에 있을 때만 실사 모드로 맞추고, Node 뷰면 그 자리에 머문다.

검증: Node 뷰에서 생성 클릭 → `viewMode: 'node'` 유지
(`evidence/c4-01-stays-on-node.png`).
