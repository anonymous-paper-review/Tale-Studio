# 그룹 C — 생성 파이프라인 버그 (생성이 깨지거나 막힘)

상태: 대기 · 우선순위: 3

## 이슈

| # | 화면 | 증상 원문 |
|---|---|---|
| C1 | Director | 영상 생성 중에 이미지 생성을 하면 에러 (그러고 Generated Storyboard가 12→11로 줄어듦) |
| C2 | Director | 영상 생성 눌렀으나 끊기고 생성 안 됨 (한번에 호출 가능한 갯수 제한? 일부 완료되니 나머지 진행됨) |
| C3 | Director | 전체 재생성 누르려는데 X표로 막힘 |
| C4 | Director | Node에서 영상생성 버튼 누르면 Storyboard로 튐 |
| C5 | Director | Storyboard Real로 바로 뛰는데 생성 중에 Pre-viz로 못 감 → real 바로 생성 끄기 |
| C6 | Director | Pre-viz에서 재생성 못 했었는데, 진입하면 손볼 수 없이 바로 Real 재생성됨 |
| C7 | Artist | 정보가 생성 안 되는 부분 있음 (스크린샷 참조) |
| C8 | Editor | Draft Render 눌러도 변화 없음 (어떻게 출력하지?) |

## 관찰 메모

- C1+C2는 동시성 문제로 보임: 동시 호출 한도(클라이언트 큐 or fal 계정 한도)에 걸리면 에러 처리 없이 조용히 실패하고, 카운트까지 어긋남(12→11은 실패한 잡이 목록에서 사라진 것으로 추정).
- C5+C6은 "Pre-viz 단계를 건너뛰는 플로우"라는 하나의 설계 결정에서 나온 두 증상.

## 논의 필요 항목

1. **C5 real 바로 생성 끄기**: 오너 지시는 명확 ("real 바로 생성 끄기"). Pre-viz → 오너 확인 → Real 생성의 2단계 플로우로 복원하면 되는지, 아니면 설정 토글로 둘지.
2. **C2 동시 호출 한도**: fal 계정 등급별 동시 한도를 확인하고, 클라이언트에 큐(대기열)를 둘지 서버에 둘지. 큐에 쌓인 건 "대기 중 n번째"로 표시.
3. **C1 카운트 감소**: 실패한 잡을 목록에서 지우지 말고 "실패 — 다시 시도" 상태로 남길지.
4. **C8 Draft Render**: 기대 출력물이 뭔지 정의 필요 — 파일 다운로드? 미리보기 재생? (그룹 H의 출력 기능과 경계 정리)
5. **C3 X표**: 어떤 조건에서 전체 재생성이 막히는지 재현 후, 막는 게 의도(생성 중 중복 방지)라면 이유를 툴팁으로 노출.

## 완료 조건 (초안)

- 영상+이미지 동시 생성 시 에러 없이 큐잉되고, 실패는 "실패" 상태로 남아 재시도 가능.
- Real 자동 생성 꺼지고 Pre-viz 단계에서 확인 가능.
- Draft Render가 눈에 보이는 결과물을 낸다.
