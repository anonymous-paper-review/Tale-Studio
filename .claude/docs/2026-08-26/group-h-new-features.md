## 논의 필요 항목

1. **H1 Node 구조 두 안 중 선택**: (a) 프레임별 노드 분리(노드 수 3배, 그래프 복잡) vs (b) 한 노드에 다중 포트(출구/입구 여러 개 — 그래프 간결, 구현은 포트 시스템 필요). H2 샷 체이닝은 (b)의 포트 연결로 자연스럽게 표현됨 → H1과 H2를 같은 설계로 묶어 결정 권장.
2. **H2 체이닝 의미론**: "샷 N의 End = 샷 N+1의 First"를 엣지로 연결하면 생성 순서가 직렬화됨(앞 샷 완료 후 다음 샷 생성 가능). 전체 생성(H3) 진행바·병렬성에 영향 — 체인 구간만 직렬, 나머지 병렬로 갈지.
3. **H4 타이틀/자막 범위**: 폰트·위치·스타일 커스텀까지 갈지, 1차는 고정 스타일 프리셋 몇 개로 갈지.
4. **H6 음원 조달**: 라이선스 확보 경로 — CC0/구매/생성(음악 생성 API). 몇 곡, 어떤 무드부터.
5. **H5 디졸브**: 렌더 파이프라인에서 클립 간 크로스페이드 구현 위치 (미리보기와 최종 렌더 양쪽).
