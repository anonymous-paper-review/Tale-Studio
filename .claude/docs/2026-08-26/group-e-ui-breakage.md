|---|---|---|

## 관찰 메모

- E1: 챗 응답 마크다운 렌더링에서 `---`(수평선) 또는 em-dash가 걸러지지 않는 것 — 렌더러 또는 시스템 프롬프트 수리.
- E2: @멘션 자동완성 팝업의 높이/overflow 문제 + Director에서는 멘션 후보에 내부 변수가 새는 것(E5와 연결).
- E5: 내부 ID가 (a) 챗 응답 텍스트, (b) 멘션 후보, (c) 캔버스 라벨 세 경로로 새는 듯 — 표시명 매핑 계층 하나로 해결 가능성.

## 논의 필요 항목

1. **E5 표시명 정책**: 캐릭터/샷의 사용자용 표시명을 어디서 정하나 — 샷은 "씬2-샷7"처럼 규칙 생성, 캐릭터는 사용자가 지은 이름. 내부 ID는 어떤 화면에서도 보이면 안 되는지, 디버그 모드에서는 허용인지.
2. **E3/E4 스크린샷 확보**: 원본 스크린샷(image.png)들이 이슈 텍스트에서 유실됨 — 재현 경로를 오너에게 확인하거나 스모크 스크린샷으로 재현.

## 완료 조건 (초안)

- 챗/캔버스/멘션 어디에도 내부 ID·수평선 기호가 보이지 않는다.
- @멘션 팝업이 잘리지 않고 전체 후보를 스크롤로 보여준다.
