색상 lint 게이트 — 토큰 밖 raw 색을 기계가 막는다

같다

논의: "지금까지 0건"을 관례가 지켰으니, "앞으로도 0건"은 lint가 보장한다. 위반이 눈검수가 아니라 기계에서 걸리게.

문자열과 템플릿 문자열 안의 hex 색·rgb/hsl/oklch 호출을 에러로 만든다. 색 정의는 15·18줄의 정규식 상수(HEX, COLOR_FN).

      "no-restricted-syntax": [
        "error",
        { selector: `Literal[value=/${HEX}/]`, message: MESSAGE },
        { selector: `TemplateElement[value.raw=/${HEX}/]`, message: MESSAGE },
        { selector: `Literal[value=/${COLOR_FN}/]`, message: MESSAGE },
        { selector: `TemplateElement[value.raw=/${COLOR_FN}/]`, message: MESSAGE },

    },

같다검증은 실패 먼저: 위반 5종 카나리가 전부 잡히는 것을 보고 지운 뒤 실트리 통과를 확인했다. 가동 직후 Tailwind 밑줄 표기(_rgba()가 \b 단어 경계에 안 걸리는 구멍을 발견해 lookbehind로 수리했고(18줄), 재스캔에서 7곳이 더 나왔다 — 처리 방식은 1절, 목록은 티켓 glow-token-cleanup.
