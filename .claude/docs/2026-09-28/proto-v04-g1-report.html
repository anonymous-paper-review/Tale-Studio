Writer로 넘긴 뒤 Producer는 보기·복사만 되고, 확정된 산문을 에이전트가 고치면 바뀐 문단을 보인 채 적용·되돌리기를 묻는다. Writer에서 에이전트가 고친 샷은 표시되고 되돌릴 수 있다. Artist에서 제안이 걸린 카드는 잠기고, 승인한 글 변경은 되돌릴 수 있다. dev 브랜치에 넣었고 실배포는 안 했다.

2-1 · Producer

P1 · P2 · P3 — 넘긴 뒤 잠금 · 배너 · 새로 만들려면?

같다

정한 것 Writer로 넘긴 뒤 Producer에서는 산문·제목·인물·배경·스타일·장르·톤·포맷·대사 언어를 고칠 수 없고 보기·복사만 된다. 상단에 배너와 '새로 만들려면?' 버튼. 누르면 새 프로젝트로 옮기는 방법 안내.

넘긴 뒤 무엇이 아직 열려 있나를 정하는 함수. 화면과 스토어는 이 결과만 믿는다.

//   만들어진 결과에 영향이 없다. 이 둘만 넘긴 뒤에도 열어 둔다.

export function producerLock(reachedStage: StageId | null | undefined): ProducerLock {
  const locked = !!reachedStage && reachedStage !== 'producer'

    locked,
    editable: new Set(locked ? EDITABLE_AFTER_HANDOFF : ALL_FIELDS),

같다 안내 팝업의 "불러오기"는 아직 제품에 없어(대조 보고서 4절 ④) "산문 복사 + 새 프로젝트에 붙여 넣기"로 적었다. 불러오기가 생기면 그 문구를 바꾼다.

P4 · P5 · P6 — 확정된 산문 변경 검토

같다

정한 것 산문이 확정된 뒤 채팅이 산문을 바꾸면 바로 덮어쓰지 않고 바뀐 문단을 표시한 채 적용·되돌리기를 묻는다. 적용 → 새 산문, 되돌리기 → 원문. 검토 중 포맷 뱃지와 Writer로 넘기기 잠김.

채팅이 준 산문이 "확정된 산문과 다르면" 승인 카드로 보낸다. 확정 전(살아있는 초안)은 종전대로 바로 반영.

2-2 · Writer

W1 ~ W4 — 채팅 변경 표시 띠 · 되돌리기 · 적용

같다

정한 것 채팅으로 샷·씬을 고치면 바뀐 카드가 표시되고, 보드 위 띠에 "에이전트가 N개를 고쳤어요"와 적용·되돌리기. 되돌리기 → 바꾸기 전 내용. 적용 → 표시만 사라짐.

되돌리기. 묶음에 담긴 이전 값을 역순으로 다시 쓴다. 저장은 화면 편집과 같은 함수를 탄다.

2-3 · Artist

A1 · A2 — 제안 대기 카드 표시·잠금 · 승인 뒤 되돌리기

같다

정한 것 에이전트 제안이 대기 중이면 그 카드에 "에이전트 제안 확인 중" 표시가 붙고 모습 추가·팝업 열기가 잠긴다. 외형·배경 설명 변경 제안을 승인한 뒤에는 되돌리기로 이전 문장으로.

승인이 끝난 직후 "되돌릴 문장"을 보관한다. 삭제·재생성 승인은 조건에서 걸러져 보관하지 않는다.

  • 넘긴 뒤 잠금이 채팅 경로(에이전트가 설정을 바꾸자는 제안)에 어떻게 보이는지는 종전 승인 카드 그대로라 다시 찍지 않았다
