# 기존 실패 검사 2개 개선 결과

**기존에 실패하던 두 검사를 실제 승인·저장·이미지 반영 검사로 교체했고, Artist 전체 검사가 통과했습니다.** 한국어 약속 문장은 그대로 유지했습니다. 사용자가 이번 턴에서 실패 테스트 개선을 명시적으로 승인한 범위입니다.

| 유지한 약속 | 이제 확인하는 실제 동작 |
|---|---|
| 채팅에서 새 모습을 만들어 달라고 하면 승인 뒤 그 캐릭터에 그 모습이 추가된다 | 채팅으로 새 모습을 요청해도 승인 전에는 모습 저장·이미지 생성이 0회다. 승인 후 정확한 인물에 지정한 시점과 외형을 저장하고 새 모습의 이미지 작업을 접수·완료한다. 기존 모습 두 개는 바뀌지 않는다. |
| 채팅에서 배경의 새 모습을 만들어 달라고 하면 승인 뒤 추가되고, 특정 모습만 다시 그릴 수 있다 | 승인 전에는 저장·생성이 0회다. 승인 후 새 배경 모습을 저장하고 기본 배경을 참조해 생성한다. 다른 기존 변형의 재생성을 요청하면 다시 승인받고 그 변형만 바뀐다. 기본 배경과 앞서 생성한 변형은 유지한다. |

왜 필요한가: 진행 추적 정보를 전달하기 위해 호출 인수가 추가된 것만으로 소스 문자열 검사가 깨졌습니다. 그러나 호출문장이 특정 형태인지 확인하는 것만으로는 승인 없이 생성되는지, 잘못된 인물이나 기본 모습에 결과가 붙는지를 잡을 수 없습니다. 새 검사는 사용자가 실제로 기대한 결과와 승인 전 부작용 금지를 확인합니다.

## 실행 범위

두 검사 모두 실제 `sendMessage`와 `approvePendingProposal`, 실제 모습 생성 스토어 함수, 실제 모습 저장 POST 라우트, 실제 이미지 생성 스토어와 작업 결과 확인을 실행합니다. 배경은 실제 이미지 생성 POST 라우트의 선택 모습·기본 이미지 참조 전달까지 확인합니다.

모델 응답과 외부 이미지 생성 접수·완료 응답, DB 및 번역은 테스트용으로 고정했습니다. 실제 유료 모델이나 운영 DB를 호출하지 않았습니다. 캐릭터와 배경의 생성 스토어 함수를 가짜 함수로 바꾸지 않았습니다. 기존 파일의 다른 검사들이 남긴 가짜 생성 함수는 각 검사 전후에 원래 함수로 복구해 검사 순서에 영향을 받지 않도록 했습니다.
