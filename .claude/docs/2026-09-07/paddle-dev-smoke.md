## 미리 알아둘 것

- 결제창에서 이메일을 바꾸지 않는다. 바꾸면 Paddle 고객이 둘로 갈라진다.
- 관리자 계정(`admin@tale.studio`)으로 결제하면 잔액이 "무제한"이라 확인이 안 된다. 스모크 계정으로.
- 6·7 환불은 샌드박스가 10분 단위로 승인한다. 바로 안 바뀐다.
- 11번은 새 계정이 필요하다(스모크 계정은 이미 4242 카드가 저장됨). `pnpm seed:test-accounts 1` 로 하나 만들면 stdout 에 비밀번호가 찍힌다. 새 계정은 프로젝트가 없어도 `/pricing` 결제는 된다.
- 디스코드에 오는 것: 환불 회수(정보) · 갱신 결제 실패(경고) · 웹훅 처리 실패 · 워크스페이스 없음 · 상품 없음 · 무료 두 번째 팩. **정상 결제·구독·취소는 조용하다.**
- 어긋난 것을 발견하면 그 번호와 본 것만 적어 두면 된다. 스크린샷이면 더 좋다.
