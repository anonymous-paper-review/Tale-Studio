# 판정 요청: 약속은 유지하고 검증 방법을 실제 동작 검사로 교체

기능은 새 검증을 통과했지만 기존 검사 두 개가 호출 문장의 글자 모양이 바뀌었다는 이유로 실패합니다. 두 한국어 약속은 그대로 유지하고, 기존 검사 안의 호출 문자열 비교를 실제 채팅·승인·생성 결과 비교로 교체하는 안입니다. 기존 테스트 이름·성공 조건·승인 필요 조건은 유지합니다.

1. **기존 약속:** 채팅에서 새 모습을 만들어 달라고 하면 승인 뒤 그 캐릭터에 그 모습이 추가된다.
   **현재 결과:** 모든 대상의 승인 후 생성 회귀는 통과했습니다. 작업 접수·완료 기록을 전달하는 정보가 호출에 추가되어 옛 문자열 비교만 실패합니다.
   **교체 후 확인:** 승인 전 생성 0회, 승인 후 요청한 인물과 모습이 각각 1회 생성되었는지 실제 실행으로 확인합니다.
2. **기존 약속:** 채팅에서 배경의 새 모습을 만들어 달라고 하면 승인 뒤 추가되고, 특정 모습만 다시 그릴 수 있다.
   **현재 결과:** 여러 배경 승인·생성과 모습 키 보존 회귀는 통과했습니다. 같은 이유로 옛 문자열 비교만 실패합니다.
   **교체 후 확인:** 승인 후 요청한 배경과 모습 키로 생성되며 다른 모습은 바뀌지 않는지 실제 실행으로 확인합니다.

왜 판단을 요청하는가: `.claude/rules/tdd.md`는 “빨간 테스트를 통과시키려고 문장·기대값·skip을 손대는 것은 … 금지”라고 정합니다. 새 기능은 실제 실행 검사로 검증했지만, 기존의 실패한 비교식을 수정하는 일은 이 규칙에 따라 먼저 판정받습니다. 실패를 숨기거나 검사하지 않는 코드를 추가하지 않았습니다.

선택: 위 실제 동작 검사로 교체 / 기존 비교식 유지(두 실패를 남김).
