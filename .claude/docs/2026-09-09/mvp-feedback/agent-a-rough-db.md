## 남은 적용 범위

이번 검증은 원본 예약 함수와 최소 기존 테이블 구조를 대상으로 했다. 운영 전체 스키마의 모든 트리거·정책·인증 쿠키·외부 이미지 서비스 과금은 이 검증에 포함하지 않는다. 예약 취소 검증은 외부 제출 전 DB 트랜잭션 취소이며, 이미 접수된 외부 작업의 취소를 보장한다는 뜻이 아니다. 공개 예약 함수 적용은 root 담당으로 남겼다.

기존 실패 테스트의 문장이나 기대값은 변경하지 않았다. 이번에 제품 코드를 추가 변경하지 않았고, B가 빨강→초록으로 수정한 최종 경로를 실제 DB에서 검증하는 수단을 추가했다. 새 검증은 첫 실행에서 10개 모두 통과했다.
