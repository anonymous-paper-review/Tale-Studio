Producer 후속 응답

언어 변경 승인 중 스타일 선택지가 끼어드는 문제와 자동 스타일 창의 표시 시점을 수정했다.

1

변경 전후

문제변경
언어 변경 뒤 누락된 스타일을 다시 질문구체적 조회·편집을 기획 인터뷰 재개로 취급하지 않도록 Producer 지침의 우선순위와 상충 문장을 정리했다.
승인 카드와 스타일 choices가 동시에 표시Producer 승인 중 choices의 신규 표시·복원을 막고, 기존 choices의 폐기 기록을 남긴다. 늦은 이력 응답에도 적용한다.
기존 프로젝트를 열거나 설정을 편집할 때 스타일 창 개입로드된 새 기획의 준비 전환 또는 명시적인 Writer 이동 요청에서만 자동 안내한다. 응답 중에는 기다리고 승인 처리 중에는 자동 요청을 폐기한다.
이전 프로젝트의 스타일 창 요청자동 요청과 열린 창을 프로젝트에 묶었다. 프로젝트·단계 전환 시 열린 창을 닫는다.
2

합의한 약속

약속왜 필요한가
언어 변경 승인 중에는 다른 주제의 선택지를 띄우지 않는다.실제 승인 카드와 스타일 선택지가 동시에 떠 입력을 잠갔다.
승인하거나 취소한 뒤에도 폐기한 선택지는 다시 나타나지 않는다.새로고침과 지연된 이력 응답에서 옛 질문이 되살아나지 않아야 한다.
도구 후속 응답은 원래 요청의 남은 작업과 결과에 집중한다.Writer 준비 조건을 매 설정 편집의 후속 질문으로 해석하지 않아야 한다.
일반 상담의 질문·선택지와 명시적인 스타일 변경은 유지한다.정상 상담과 기존 JSON 변경 경로를 보존한다. 스타일 저장 뒤 오류 안내가 남는 별도 한계는 아래 기록했다.
복원된 프로젝트에서는 스타일 창을 자동으로 열지 않는다.기존 프로젝트 설정 편집에 최초 기획 안내가 끼어들지 않아야 한다.
새 기획의 스토리가 준비되거나 스타일 없이 Writer로 넘기려는 명시 요청이 있을 때 스타일을 안내한다.필요한 기획 시점의 안내는 유지한다.
응답·승인 처리 중에는 자동 스타일 창을 열지 않고, 이전 프로젝트의 요청을 새 프로젝트로 가져가지 않는다.진행 중 작업과 프로젝트의 경계를 보존한다.

사용자가 승인한 수정 범위다. 독자적으로 추가한 제품 정책이나 의존성은 없다.

3

검증

구분확인한 것미검증·제한
회귀 테스트선택지 동시 표시 3건과 지연 복원 경합 등을 먼저 실패로 확인한 뒤 수정했다. 현재 관련 23개 통과.프롬프트 문구 검사는 응답 품질의 보증이 아니다.
자동 회귀 전체2,865 통과 · 실패 0 · 기존 22 제외. 타입·디자인 검사 통과. 소스 lint 오류 0 · 기존 경고 24.별도 환경이 필요한 수동 DB 테스트는 일반 자동 대상 밖이다. 최초 전체 파일 직접 실행에서는 이 환경이 없어 수동 2개가 실패했다. 기대값·skip 변경은 없다.
실제 모델·DEV 저장언어 승인 전 ja 유지 → 승인 후 ko 저장 → 채팅 재조회. Writer 첫 샷 8→9초. 일반 상담 도구 0회.여러 표현을 반복한 성공률, Artist 재실행, 유료 생성·번역·이미지 품질은 이번에 검증하지 않았다.
스타일 창기존 프로젝트 진입: 자동 표시 없음. 새 기획 준비 전환: 표시. 명시적 Writer 이동 차단: 표시. 팔레트 수동 열기: 표시.지연·다른 프로젝트 이벤트는 자동 테스트로 확인. 이미 열린 창의 같은 화면 내 실제 프로젝트 전환은 브라우저 표본 미완료.
실행 범위전용 DEV 프로젝트 3개. 최종 생성 job 0개.원래 사용자의 대기 중인 승인 카드에는 승인·취소하지 않았다. 운영·커밋·배포 변경 없음.

5

잔여 항목

항목확인한 사실다음 보완
Producer · 스타일 변경의 최종 안내모델이 지원 밖 필드를 도구에 요청해 invalid_input을 받은 뒤 기존 JSON으로 수채화 저장에 성공했다. 최종 화면에는 앞선 도구 오류가 남았다.도구 결과와 기존 JSON 실행 결과를 요청별로 합쳐 최종 상태를 안내해야 한다. 이번 후속 질문·선택창 수정에는 포함하지 않았다.
Producer · 언어 적용 범위초안 언어는 ko, 확정 설정과 기존 대사 텍스트는 ja다.기존 대사 번역·다음 단계 반영은 별도 요청으로 확인해야 한다.

추가 승인을 기다리는 작업은 없다. 위 잔여 항목은 발견 사실로 남겼다.
