# Artist 설명 저장 보호

승인 대기 중 다른 사람이 바꾼 인물·소품·배경 설명을 오래된 승인으로 덮어쓰지 않는다.
확인할 수 없는 옛 승인 카드는 다시 읽어 변경을 요청하게 한다.
이미지 저장 실패 처리와 함께 오너가 배포를 승인한 범위이며, 이 문서는 설명 저장 보호를 다룬다.

## 같이 정한 것

- 배경 설명 저장 중 다른 수정이 들어오면 새 설명으로 덮어쓰지 않는다.
  - 왜: 승인을 기다리는 동안 바뀐 배경 설명을 지키기 위해서다.
- 기본 인물 모습 저장 중 기본 모습이 교체되면 새 설명으로 덮어쓰지 않는다.
  - 왜: 승인 화면에서 보았던 모습과 저장 대상이 달라지는 경우를 막기 위해서다.
- 소품 외형 저장 중 다른 수정이 들어오면 새 외형으로 덮어쓰지 않는다.
  - 왜: 승인 후 저장 직전의 수정도 보존하기 위해서다.
- 배경 설명의 원본이 일치하면 조건부 저장이 성공한다.
  - 왜: 정상 경로 고정.

## 혼자 정한 것

| 동작 | 왜 | 버린 선택지 | 되돌리기 |
| --- | --- | --- | --- |
| 원천 확인 정보가 없는 이전 승인 카드는 저장하지 않고 다시 요청하게 한다 | 과거 승인에서 무엇을 확인했는지 알 수 없기 때문이다 | 현재 값을 옛 승인에 끼워 넣고 저장 | 쉬움 |
| 승인 당시 원천 스냅샷이 오래되면 같은 값이어도 저장하지 않는다 | 값이 바뀌었다가 돌아온 경우에도 다른 사람의 수정을 존중하기 위해서다 | 화면 글자가 같으면 저장 | 쉬움 |

기존 임시 저장본의 테스트 이름과 검증을 유지한다. 먼저 기존 main에서 실패를 확인한 뒤 설명 읽기·승인·저장 경로를 옮긴다. 모델 설정, Writer, 배경 삭제 안내는 이번 범위에 포함하지 않는다.
