# Director Take 차감과 반환 보완 검증

같이 정한 동작: 같은 작업의 같은 금액을 다시 요청하면 추가로 차감하지 않는다. 같은 작업에 다른 금액이나 작업공간을 요청하면 차감하지 않고 거절한다. 반환을 반복하면 최초 차감 총량만 반환한다. 이미 반환한 작업을 다시 차감하지 않는다. 기존에 중복 차감된 작업을 반환할 때에는 지급분별 미반환 총량을 모두 반환한다. 실제 고객의 기존 원장은 자동으로 수정하지 않는다.

혼자 정한 세부 동작: 작업이 없거나, 최초 차감 전에 실패·취소·완료 상태가 되면 새 차감을 거절한다. 이미 완료된 작업의 동일 차감 재전송은 기존 처리를 돌려준다. 실패 후 새 작업을 만들면 정상 차감한다. 차감과 실패가 경쟁하면 실패 이전에 차감한 금액을 반환하거나, 실패 후 도착한 새 차감을 거절한다. 분할 지급분·만료·환불된 지급분의 기존 잔액 계산을 유지한다.

검증은 개발 DB의 임의 이름 격리 공간에서 원본 SQL을 실행한다. 기존 SQL에서 새 기대가 실패하는 결과를 먼저 보존하고, 보완 SQL로 같은 테스트가 통과하는지 확인한다. 고객 데이터 복사·변경과 유료 생성 호출은 하지 않는다. 테스트 종료 시 임시 공간 제거와 public 함수 지문 불변을 확인한다.
