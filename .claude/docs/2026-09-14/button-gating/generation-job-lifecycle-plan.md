# 생성 작업 반환·삭제 경합 보완

같이 정한 동작:

- 이미 완료된 영상에 늦은 실패 알림이 도착하면 차감액을 반환하지 않는다.
- 작업 삭제와 늦은 차감이 겹치면 작업을 지우기 전에 남은 차감액을 모두 반환한다.
- 작업 삭제 전에 영상이 완료되면 완료 기록과 차감액을 유지한다.
- 진행 중 작업을 반환하면 작업을 종료하고 늦은 완료나 차감을 받지 않는다.

혼자 정한 세부 검증: 완료 처리와 반환·삭제의 행 잠금 순서를 바꾸어 확인한다. 차감이 먼저 확정되면 삭제 전에 반환하고, 삭제가 먼저 확정되면 늦은 차감을 거절한다. 차감 없는 작업과 실패·취소·이미 없는 작업은 삭제 성공을 돌려준다. 대기 작업의 직접 반환 동작과 영상 외 생성 작업의 삭제를 유지한다.

개발 DB 임의 스키마에서 합성 데이터로만 검증한다. 기존 경로는 실제 반환 RPC와 별도 DELETE를 순서대로 실행하며, 두 호출 사이에 차감을 넣어 경합을 재현한다. 보완 경로는 신규 원자적 삭제 RPC를 호출한다. 동일 기대를 변경하지 않고 보완 전 실패와 보완 후 통과를 별도 JSON으로 보존한다. public 함수와 고객 원장은 수정하지 않는다.
