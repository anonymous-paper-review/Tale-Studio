- **무엇을**: 스타일 선택 팝업 그리드에 보일 예시 이미지를 넣는다. 자리는 잡혀 있고 지금은 빈칸이다.

  직접 만들기로 했다 — "예시는 내가 만들어서 추후에 넣어줄게 지금은 빈칸으로 해줘"(2026-07-13).

- **되살릴 좌표**: producer 스타일 앵커 피커. `anchor.imageUrl`(실제 레퍼런스)은 노출 금지 대상.
