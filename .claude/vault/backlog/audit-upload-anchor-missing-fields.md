# audit-upload-anchor-missing-fields — 올린 그림으로 그림체를 정하면 딸려오던 보호 장치가 사라지는가

```yaml
id: audit-upload-anchor-missing-fields
source: sweep:claude:5a3338db (2/2)   # 형제: audit-upload-anchor-order-coverage
kind: audit
budget: { usd: 0, runs: 1, wall_min: 30 }
blockers: []
status: done   # 2026-08-16 밤 — 성립: 소비 자리 12곳(사전조사 9곳 + 적용 함수 내부 3곳) 중 "다른 결과" 4곳 · 피해 없음 8곳 · 판단 불가 0곳. 최대 건은 영상 카메라 장비 억제(medium 미도달, 두 겹 단절). 티켓 전제 "카드도 보정 문구가 비어 있다"는 라이브에서 거짓(12/12 보유)
priority: normal
```

- **맥락 (사람 말로)**: 그림체를 정하는 길이 이제 둘이다. 하나는 준비된 카드 중에서 고르는 길이고,
  어제 새로 난 다른 하나는 사용자가 직접 그림을 올리는 길이다. 카드로 고르면 그림 한 장만 오는 게
  아니라 **딸려오는 정보**가 있다 — 이게 만화인지 실사인지, 그 그림체에만 붙이는 검증된 보정 문구,
  두 번째 참조로 같이 넣을 그림이 있는지. 그 정보들은 그냥 장식이 아니라 실제로 분기를 만든다.
  대표적인 예: *"이 프로젝트는 실사가 아니니 영상 주문서에서 카메라 장비 이야기를 빼라"* 는 판정이
  매체 값 하나로 갈린다. 이건 지난달 실제 사고를 막으려고 일부러 넣은 장치다 — 3D 애니메이션
  프로젝트인데 영상 주문서가 실사 카메라 촬영을 지시해 그림체와 정면으로 부딪혔다.
  **그런데 올린 그림으로 가면 그 딸려오는 정보가 어디까지 따라가는지 아무도 확인 안 했다.**
  만든 세션은 그림 주소만 보고 "배선이 잘 잡혀 있어 더 쉽다"고 적고 넘어갔다.
- **알고 싶은 것**: 올린 그림으로 그림체를 정한 프로젝트가, 카드로 정했다면 받았을 보호 장치를
  실제로 못 받는 자리가 있는가 — 있다면 몇 곳인가.
- **깔고 있는 전제**: 그림체를 푸는 해석기는 결과를 한 덩어리로 돌려주는데, 그 덩어리에 들어갈 수
  있는 값은 일곱 개다. 올린 그림 경로는 그중 두 개(키와 그림 주소)만 채운다 — 이건 sweep 이 코드에서
  확인했다. 나머지 다섯 개가 비었을 때 각 소비 지점이 **카드로 골랐을 때와 같은 분기로 떨어지면**
  피해가 없고, **다른 분기로 떨어지면** 그게 곧 잃은 보호 장치다. 그 판별은 소비 지점을 하나씩 읽어야
  나온다. 카드 쪽에도 원래 비어 있는 값이 있다는 점을 잊지 말 것(일부 그림체는 보정 문구가 의도적으로
  비어 있다) — 그러니 "비었다"가 곧 "고장"은 아니다.
- **예측**: 참이면 잃은 보호 장치의 목록이 자리(파일·줄)와 함께 나오고, 그중 무엇을 사용자에게
  물어서 채울지가 아침 결정 재료가 된다. 거짓이면(피해 0곳) 올린 그림에는 그림 주소만 있으면
  충분하다는 뜻이라, 이 걱정을 닫고 더 묻지 않는다.
- **어떻게 재나**:
  1. 그림체 해석 결과 덩어리의 필드를 전부 열거하고, **카드 경로가 채우는 것**과 **올린 그림 경로가
     채우는 것**을 두 열로 나란히 적는다.
  2. 카드 경로만 채우는 필드 각각에 대해, 그 값을 **읽는 자리를 저장소 전체에서 전수 열거**한다
     (화면 표시용은 제외하고 주문서를 만드는 서버 경로만 센다).
  3. 자리마다 그 값이 비었을 때 어느 분기로 떨어지는지 코드로 확인하고 셋 중 하나로 분류한다 —
     **같은 결과(피해 없음)** / **다른 결과(보호 장치 상실)** / **읽어봐도 판단 불가**.
  4. "다른 결과"로 분류된 자리의 건수를 센다. 각 건은 파일·줄과 어떤 문구·어떤 분기가 달라지는지를
     한 줄로 적는다.
  - 코드 읽기와 세기만 한다. 모델을 부르지 않고 그림·영상을 만들지 않는다. 코드를 고치지 않는다.
- **판정선 (미리 정해두는 것)**: "다른 결과"로 분류된 자리가 **1곳 이상**이면 가설 성립 —
  그 목록이 산출이다. **0곳이면 기각.** 어떤 자리가 "판단 불가"로 남으면 그 자리는 성립·기각 어느
  쪽으로도 세지 않고 따로 적는다(추측으로 채우지 않는다). 카드 쪽에서도 원래 비어 있는 값 때문에
  같은 분기로 떨어지는 자리는 **피해 없음**으로 센다.
