# 스위프 노트 — claude:98a7ce72

- 제품 화면의 참고 사례를 모으고, 세 가지 화면 시안을 만들었다.
- 사용자는 초기 시안이 실제 작업 화면을 보지 않은 채 꾸며져 부적절하다고 되돌렸다.
- 고정해야 할 조건은 단계 사이에서 채팅과 탭의 위치를 바꾸지 않는 것, 화면이 작업 결과를 보는 자리여야 하는 것이다.
- 이후 실제 작업 화면을 보려 했으나 로그인과 브라우저 탭 접근이 필요한 조사로 이어졌다.

## 열린 것 후보

- **미결 — 오너 접근 필요:** "랜딩페이지만 보고 판단하지말아줄래 작업환경을 봐야할걸?" 
  - 로그인된 작업 화면을 어떤 범위까지 보고 참고할지 정해야 한다. 사람의 로그인·탐색이 필요한 조사라 밤 티켓으로 만들지 않았다.
- **미결 — 설계 선택:** "탭이랑 채팅창은 각단계에서 위치를 바꾸지마셈"
  - 이 고정 조건 위에서 어떤 화면 구성과 색감이 맞는지는 시안에 대한 오너 판정이 필요하다. 단일 관측으로 참·거짓을 가를 수 없어 노트에만 남긴다.

## 결정 흔적 후보

- 작업 화면을 보고 판단한다. 채팅과 탭은 단계마다 옮기지 않는다. 강한 장식보다 화면 속 제작물을 우선한다.
