### assistant
결론: `sudo pmset -a disablesleep 1` 하나면 됩니다. 뚜껑을 덮어도 시스템이 잠들지 않아서 Claude Code든 gjc든 돌아가던 프로세스가 배터리 다 될 때까지 계속 동작합니다. Apple Silicon 최신 macOS에서도 커널 레벨 플래그(SleepDisabled)로 lid-close 슬립까지 막아주는 게 확인된 방법입니다.

**사용법:**

```bash
# 켜기
sudo pmset -a disablesleep 1

# 적용 확인 (1이면 활성)
pmset -g | grep SleepDisabled

# 작업 끝나면 반드시 끄기
sudo pmset -a disablesleep 0
```
