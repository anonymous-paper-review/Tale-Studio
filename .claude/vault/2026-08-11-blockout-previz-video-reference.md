# 블록아웃 프리비즈 영상 = 모션 전달 제3후보 — 외부 방법론 수집·배선 확인 — 세션 기록

> 세션 2026-08-11 (자정 걸침). 유튜브 영상(반토막AI) + 외부 리서치 2트랙을 vault 미결에 접합한 수집 세션.
> 원칙: **외부 증언과 자체 실측을 구분해 기록.** 모션 채널 재개([[2026-08-10-previz-motion-channel]]) 시 이 파일과 리포트를 같이 읽는다.

## 0. 한 줄 요약

유튜브 "3D 더미를 씨댄스에 통째로 넣으면 생기는 일"(반토막AI, 8/7)의 방식 = **모션 채널 '전달' 미결의 제3후보** — 프리비즈 블록아웃 영상을 통째로 레퍼런스로(타이밍·속도·경로가 실리는 매체). 성립 전제를 코드로 확인: **Seedance 2.0 스키마에 `video_urls`가 이미 배선돼 있으나 제품은 전 모델 `image_urls`만 전송**(미사용 채널). 영상의 정적 채널 주장(단순 도형·역할 분리)은 F2 마네킹 캐논·인물 이중 방어의 외부 재발견. 3암 실험 스케치까지 — 등록은 오너 대기.
각색 리서치(15소스)는 별도 수확: "코마=지표 vs 콘티=설계도" 구분이 모션 채널 진단과 동형.

## 1. 실측/수집 발견 — 출처 등급 명시

- **배선 사실 (자체 실측)**: `src/lib/fal/model-schemas.ts` — seedance 2.0 reference-to-video 입력에 `video_urls`·`audio_urls` 존재(:31). happy-horse(기본)·kling-o3·veo3.1은 `image_urls`만. `src/lib/video-models.ts` refParam은 전 모델 `image_urls`(:36) → 영상 레퍼런스는 **배선됐지만 미사용**. 부재: fal storage 업로드 헬퍼, 로컬 Blender.
- **외부 증언 (n=1 데모, 우리 실측 아님)**: youtu.be/LomMGF7kcBU (8:30, 조회 2.3만, Seedance 데모). 핵심 메커니즘 주장:
  > "시댄스는 근사치와 정답을 구분하지 못해요. … 애매하게 비슷하면 그냥 정답이라고 생각하고 그대로 따라갑니다. '스토리보드는 참고만 해라'고 써놔도 소용이 없습니다."
  실패 사례가 전부 이 메커니즘: 빈 머리→대머리, 그려진 물줄기 방향 복제, 러프 포즈 순간이동. **우리 A2 실측(END 사진: 상태는 끌고 구도는 흘림)·A1(정지 샷에 화살표 추가)과 독립 수렴.**
- **영상의 처방 3규칙**: ① 피사체는 단순 도형만(디테일한 더미가 생김새 간섭) ② 색으로 종류 구분 ③ 역할 분리 — 프리비즈=카메라·구도·컷전환 / 이미지 시트=생김새·배경 / 프롬프트=색도형→피사체 매핑+구체 움직임. ①=F2 마네킹 캐논 동일 원리, ③=인물 이중 방어와 동일 구도(배경만 무방어 — [[2026-08-10-background-view-3d]] 비대칭과 정합).
- **워크플로 증언**: 블렌더는 에이전트(Codex)가 설치·조작, 사람은 안 열음. 초 단위 카메라 표(몇 초·몇 도·높이·거리)를 먼저 작성 → 우리 static_spec/dynamic_spec '발주서'와 같은 물건, **블렌더 컴파일 타깃만 없음**. 성사 시 저작 축 문제(화살표 커버리지 37%)가 LLM 드로잉→결정론 코드로 이동.
- **외부 리서치 A (일본 3DLO, CGWORLD 등 1차 취재)**: 선별적 사용이 표준(『약사의 혼잣말』 1화 80%는 예외적 고비율). 해결 대상은 기하학적 정확성(퍼스·스케일 비례·카메라·이매지너리 라인). "배경 모델 위치·스케일 고정, 카메라만 조정" 원칙 = 뷰 자산화(D-e 심장)와 같은 방향. 한계 실측: 개조 경직성·조명 분리 모순·과장 표현 취약.
- **외부 리서치 B (영화 previz)**: 확정 3요소 = 렌즈·카메라 동선·블로킹. "마지막 5%"(조명·접촉·질감·즉흥)는 항상 이관. **수치 전달이 1:1 재현의 관건**(Halon) — 카메라 표 방식의 외부 전거.
- **외부 리서치 C (3D→AI 컨트롤)**: 결합도 2티어 — **약결합 레퍼런스**(Seedance video_urls, 영상 데모 방식) vs **강결합 컨트롤**(depth/canny/pose→Wan VACE, 커뮤니티 표준, 우리 스택 밖). 공통 한계 서술: "강하게 따르지만 보장은 안 함". 실패는 depth 품질+파이프라인 위생(해상도 불일치→급격한 줌, JPEG 아티팩트, 프레임 수 규칙). → **어떤 참조 채널도 정량 보장이 아니라 정성 개선 — 실험 없이 채택 불가.**
- **각색 리서치 (15소스, 축별 종합은 리포트)**: 제외 판별="아크 기여", 추가 판별="감정 심화", 3막은 발견 아니라 구축, POV 변환 필연. **축 4가 핵심 수확**: 코마=지표(상상 위임) vs 콘티=설계도(컷번호·그림·내용·尺) — 데즈카가 그린 콘티조차 현장 불가였다는 오츠카 증언. "정지 컷 3초" 업계 경험칙 실존(B2 SHOT_PHYSICS 외부 전거 축 존재 시사).

## 3. 미결

A2′ 재등록은 (b)암에 병합(재측정 비용 흡수). **→ 가설 폼 초안 작성됨: `research/experiments/previz-video-reference-ab/HYPOTHESIS.md`** (계단: Phase 0 컴파일 프로브[크레딧 0] → 스모크 ~$4 → 본실험 27클립 ~$46). 닫히는 조건: 오너가 기각 bar [N] 확정 → 등록 성립.
- 질문: **Seedance 전속 수용** — 영상 레퍼런스 채널은 현 배선상 Seedance뿐(happy-horse 없음) → 모델 교체 논의([[2026-08-10-flash-ab-fanout-review]])와 한 테이블. 닫히는 조건: 3암 실험 결과 + 모델 교체 판단.
- 질문: **spec→Blender 컴파일 프로브** — static/dynamic_spec을 블렌더 카메라 트랙으로 컴파일(블록아웃 티어 자동화). D-e 기각 전제("수동 카메라 노동 폭발")가 에이전트 자동화로 갱신됨 — 단 심장(뷰 자산화)은 불변. 닫히는 조건: 프로브 1회로 컴파일 가능성 실측.
- 잔가지: 화살표 직결 실험은 우선순위 추가 하락(화살표=사람용 지표로 역할 확정 방향) / 강결합 티어(VACE류)는 별도 스택이라 보류 — 약결합 실험이 기각되면 재부상 / 각색 판별 질문들의 드라마투르그 프롬프트 어휘 반영은 [[2026-08-10-dramaturgy-world-derivation]] 재개 시.
