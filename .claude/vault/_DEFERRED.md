# 미뤄둔 작업 — 상시 원장

**결정은 났고 지금 안 할 뿐인 일**만 모은다. 결론이 없는 것은 여기가 아니라 각 vault 파일의
`## 3. 미결`로 간다 (판별: "무엇을 더 알아야 정할 수 있나?" = 미결 / "정해졌는데 왜 지금 안 하나?" = 여기).

- 이 파일은 날짜 파일이 아니라 **살아 있는 대기열**이다. 완료·폐기된 항목은 잘라내
  `_archive/_DEFERRED-done.md`로 옮긴다 — 여기 남은 것은 전부 아직 열려 있는 것이다.
- **재개 조건 없는 항목은 만들지 않는다.** "나중에"는 조건이 아니다.
- 킬 스위치로 꺼둔 기능은 **끄는 법이 아니라 켜는 법**을 좌표에 적는다.
- 채우는 것은 `/warp` 라우팅 4. 손으로 추가해도 무방하나 폼은 지킨다.

## 폼

```
### D-NNN · <한 줄 제목>   `상태: 대기|blocked|진행중`
- **무엇을**: 실행 단위로 구체적으로 (누가 읽어도 착수 가능하게)
- **왜 미뤘나**: 보류 사유 (비용·순서·선행조건·판단 유보 중 무엇인지)
- **언제 꺼내나**: 재개 조건 — 무엇이 생기면/끝나면 다시 꺼내는가
- **되살릴 좌표**: 파일·플래그·커밋·문서 위치
- 기록: YYYY-MM-DD
```
