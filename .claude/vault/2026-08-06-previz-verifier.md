## 0. 한 줄 요약

previz 품질 검증기를 설계(리서치 3건)→구현→2프로젝트 실행→오너 피드백 5회 반복(v0→v0.5)했다.
핵심 실측: **"보이는 대로 말해라"(사실 판정)는 변별력이 있고, "좋은지 판단해라"(품질 판단)는 전부-통과 수준으로 무르다.**
최종 코어 = 결정론 + B 전달률(블라인드 판독→코드 대조) + 종단 리드백 + 구조 모순 검출.
리포트: https://claude.ai/code/artifact/3431b72e-52ce-4466-96f4-efd74b674d15 (run1 에일리언) · https://claude.ai/code/artifact/f7f37f25-228c-4c73-9467-c77906efa144 (run2, v0.5 다이어트판)

## 1. 실측 발견 — 안 통한 시도 포함

- **리서치 수렴 (2025~26 LLM-as-judge 실무, 검색 3건)**: ① 축별 분리+호출 격리가 합의(halo 실증) ② 스케일은 binary/앵커 0-5 승, 0-100·0-10 패배 ③ rubric은 연역 뼈대+레벨당 앵커 사례 1-2개 ④ 제로샷 VLM은 샷 문법 인지 약함(ShotBench 60% 미달, 파인튜닝 소형이 추월) ⑤ 도메인 표준은 "전용 metric+LLM 하이브리드"(VBench/ViStoryBench) ⑥ 시계열 비교엔 judge 스냅샷+rubric+입력셋 고정, frozen anchor set 브리지 ⑦ meta-eval: 인간 라벨 30-50, 인간끼리 κ 먼저. **previz 전용 오픈소스는 부재** — 최근접 ViStoryBench(코드 재사용 가능).
- **변별력 실측 (2 run, 46+22샷)**: 강한 판정 = B 블라인드 판독(스팟체크 7/7 타당, ECU 하이브리드·모션 확대·앵글 평탄화 검출), 종단 리드백(63% vs 89% — 차이가 소재-양식 궁합으로 설명됨), 구조 모순 검출("무대사 선언인데 혼잣말 주입"). 무른 판정 = A 샷 규칙(12/12 MET — dramatic_purpose가 LLM 자기 정당화라 심사가 자기 채점), C 구도(플래그 0~1/46·22, 가점 만발), E 앵글 효과(기대 맵 오류가 MISS의 다수).
- **제품 결함 검출 (검증기의 실전 수확)**: run1 — 실제 대사가 46샷 어디에도 미배정(요약문 복제; A 검수자 5/6이 독립 지적, 신버전 run2에선 수정 확인됨). 양쪽 — rough-storyboard 생성기가 ECU를 "전경 매크로+와이드 배경" 하이브리드로 뭉갬, handheld_drift를 follow/push-in 대형 무빙으로 확대(스팟체크 실물 확인), 로우앵글 평탄화. run2 — 분할 자식 2샷의 design_ref null 영속, 대사 계약 모순(무대사 씬에 혼잣말·미선언 O.S. 화자·대사가 옆 샷 액션 서술로 샘).
- **리드백의 양식×소재 충돌**: 목각인형 previz는 물리 행동(서류·커피·추격)은 안정 전달, 정체성·변신·내적 의미는 못 나름. run1(외계인 변신 소재)에서 변신이 "눈을 얻어 깨어남"으로 역해석 — 얼굴 없는 양식이 스토리로 흡수됨. run2(추격 액션)는 'OASIS KINGDOM' 문구까지 판독, sc_04 beat 5/5.
- **안 통한 시도 3건**: ① 매핑 추측 — design_ref null 샷에 이름 규칙(sh_01_05→shot_5)으로 설계를 추측 매핑 → "전문 복제" 허위 결함 2건이 리포트에 실림. 오너 지적("이미지 자체는 다른 거 같은데?") → 실측 diff로 검증기 버그 확인 → 정정. ② E 기대 맵 고정(하이앵글→위축, CU→감정) — 액션 로우앵글·인서트 CU에서 기대값 자체가 오류. ③ 씬 길이를 estimated_seconds와 비교 — 같은 파이프라인이 만든 숫자라 순환 참조(오너 지적: "근거 하나도 없잖아").

## 2. 결정 — 코드로 귀결 안 된 것만

### D-2026-08-06-a: 검증기 코어 = 사실 판정 4면, 품질 판단은 보류
- 상황: 6개 판정면 중 품질 판단 계열이 전부-통과 수준으로 무름이 실측됨
- 결정: 본문 유지 = 결정론·B 전달률·종단 리드백·구조 모순 검출. 보류 = A 샷 규칙(결정론 트리거+사람 스팟으로 강등)·C 구도·E 효과(기대를 dramatic_purpose에서 유도 후 재평가). **절대 길이 판정("이 샷은 X초가 맞다") 제거** — 커버리지 제안(부족/중복)만 "미검증" 라벨로 유지 (오너: "몇초가 맞다 이런 건 일단 빼고")
- 기각한 대안: 전 축 유지 — 변별력 없는 축이 리포트를 노이즈로 채움
- 감수하는 것: 구도·효과 품질은 당분간 사람 눈이 유일한 판정자

### D-2026-08-06-b: 판정 3원칙 (검증기 설계의 정본 후보)
- 결정: ① **식단 분리** — 축은 "판정자가 무엇을 못 보는지"로 정의된다(B·리드백은 설계를 못 봐야 측정 자체가 성립) ② **LLM은 지각만, 채점은 코드** — 점수를 LLM이 매기지 않으면 스케일 편향이 원천 차단됨 ③ **연결이 불확실하면 추측 금지, NA로 표기** — 허위 복제 사건의 산물
- 기각한 대안: 이미지+규칙을 한 판정자에게 같이 주기(오너 제안에서 논의) — 확증 편향+진단 손실로 기각, 대신 "효과 판독(블라인드 인상→코드 대조)"로 흡수
- → 승격 후보: 검증기가 실험 표면으로 정착하면 .claude/rules/experiments.md에 반영

### D-2026-08-06-c: 파일럿은 서브에이전트, 벤치마크 승격 시 고정 세트
- 결정: 파일럿 판정자 = Claude Code 서브에이전트(격리 공짜, 반복 빠름). 시계열 벤치마크로 승격하는 시점에 API 모델 스냅샷+rubric 버전+고정 입력셋을 한 묶음으로 고정
- 감수하는 것: 파일럿 점수는 run 간 직접 비교 불가(참고용)

## 3. 미결

- 질문: 판독기-사람 일치도 κ — 닫히는 조건: 두 사람이 같은 20~30샷을 각자 라벨 → 인간끼리 κ → 판독기 κ≥0.6 확인. HYPOTHESIS.md의 기각 조건(핵심 축 오판 30%)도 이걸로 닫힘. 스팟체크 7/7은 통과 신호일 뿐 판정 아님
- 질문: 정답지 계약 v1 — 닫히는 조건: ① 인원수(blocking≠화면 인원 — OTS·군중 정의) ② 모션 어휘(handheld_drift 허용 변위) ③ CU에서 배경 가시성 규칙을 정의해 answer key에 반영. 두 run 모두에서 재발한 지표 결함
- 질문: 커버리지 제안(부족 8·중복 5)의 적중률 — 닫히는 조건: 오너가 제안별 채택/기각을 기록, 채택률로 이 판정면의 유지/폐기 결정
- 질문: 리드백 beat 대조 자동화 — 현재 오케스트레이터 수동 판정(✓/△/✗). 닫히는 조건: 대조 전용 에이전트(서술+beat만, 이미지 없음)로 옮기고 수동 판정과 일치 확인
- 잔가지: 검증기가 지난 세션 미결 "밤 에이전트의 오라클" 후보로 확정적 — backlog 컨테이너 정의와 만나는 시점에 재론 ([[2026-08-05-truth-source-cleanup]] 미결 3번)
