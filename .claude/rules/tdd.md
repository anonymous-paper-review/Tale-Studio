# 테스트를 먼저 쓴다 — 모든 작업 공통

> 근거: 2026-09-04 오너 결정. 2026-09-02 실측 — 빌링 정책 12건을 오너에게 보였더니 오너가 직접 정한 것 0건,
> 알고 있던 것 4건, 처음 보는 것 8건. 정책이 구현 뒤에 태어나 오너 머리를 거치지 않았고, 오너는 그 작업의
> 테스트를 "뭘 하는 건지 몰라서" 쓸 수 없었다. 순서를 뒤집는다: **동작을 먼저 정하고, 구현은 나중.**
> 오너가 하는 것은 코드가 아니라 **한국어로 "이렇게 동작한다"를 먼저 정하는 것**이다. 코드화는 에이전트 몫.
>
> 2026-09-11 오너 지시: 이 문서가 쓰던 "약속 문장"·"삼진(① 내가 정함 / ② 인지 / ③ 처음 봄)"·"판정 카드"는
> 사내 조어라 오너가 읽고 결정할 수 없었다. 용어를 세션 보고서 표준(`~/.claude/skills/artifact/SKILL.md`)이
> 이미 쓰는 것으로 맞췄다: **같이 정한 것 / 혼자 정한 것 / 결정이 필요한 것.** 절차는 그대로다.

## 순서 — 기능·수정·버그 어느 것이든

1. **설명** — 에이전트가 이 작업이 바꾸는 **사용자 경험**을 한국어 5줄 이내로 쓴다.
   구현 용어(RPC·402·mock·낙관 갱신 등) 금지. 오너가 "뭘 하는 건지 모르겠다"면 여기서 멈춘다.
   설명이 안 되는 작업은 만들지 않는다.
2. **동작 목록** — "~이면 ~한다" 꼴의 한국어 한 줄씩. 한 줄 = 테스트 하나 = 그 테스트의 이름.
   에이전트가 목록을 두 묶음으로 나눠 낸다(세션 보고서 1절·2절과 같은 구분):
   - **같이 정한 것** — 이 대화에서 오너가 정했거나 이미 알고 있는 것. 오너는 훑어보기만 한다.
   - **혼자 정한 것** — 에이전트가 유도한 것. 표: 동작 / 왜 / 버린 선택지 / 되돌리기(`쉬움` `비쌈` `못 돌림`).
     **`비쌈` 이상이 하나라도 있으면 오너 확인 전에 구현을 시작하지 않는다.** `쉬움`은 구현하고 보고에 남긴다.
   오너가 답하는 방식은 셋뿐: 그대로 / 이렇게 고쳐 / 결정이 필요한 것으로 올려.
3. **테스트 먼저** — 에이전트가 그 문장을 **그대로 테스트 이름**으로 쓰고, 구현 전이라 실패하는 것을 확인한다.
   파일 첫 줄 주석은 "이 파일이 검사하는 동작" 한국어 한 줄.
4. **구현** — 테스트가 통과할 때까지. 커밋 전 훅(`.githooks/pre-commit`)이 통과해야 한다.
5. **보고** — 완료 보고에 동작 목록을 그대로 싣는다(`owner-gates.md`와 같은 표면). 원장(`pnpm test:ledger`)에
   같은 문장이 남는다. 문장마다 **"왜: 어떤 상황에서 필요한가"** 한 줄을 붙인다(2026-09-07 오너 지시).
   정상 경로는 "정상 경로 고정"이라 적고, 고장 테스트는 그 고장이 언제 일어나는지(누가·어느 경로에서) 적는다.
   오너는 ts 를 읽지 않으므로 이 두 줄이 테스트의 전부다.

## 테스트가 실패했을 때 — 에이전트는 테스트를 고치거나 지우지 않는다

`pnpm test`가 실패하면 **결정이 필요한 것** 표(파일 설명 · 테스트 이름 · 실제로 일어난 일 · 선택지)가 자동으로 찍힌다.
선택지는 셋이고, 두 번째·세 번째는 오너만 고를 수 있다.

- **코드를 고친다** → 테스트 이름 유지. 기본값 — 에이전트가 바로 고치고 보고에 남긴다.
- **동작이 바뀌었다 → 테스트 이름을 고친다** → 오너가 새 문장을 준 뒤에만.
- **그 동작이 없어졌다 → 테스트를 지운다** → 오너가 정한 뒤에만.

실패한 테스트를 통과시키려고 문장·기대값·`skip`을 손대는 것은 오너 결정을 에이전트가 대신한 것이다. 금지.

## 적용 경계 — 테스트로 쓸 수 있는 것과 없는 것

- **테스트로 쓴다(먼저 쓰기 필수)**: 로직 · 정책(빌링·쿼터·게이트·플랜) · 권한 · 상태 전이 · API 응답 ·
  저장 형식 · 핸드오프 · 텍스트 처리. 지금 스위트의 거의 전부가 여기다.
- **테스트로 못 쓴다**: 그림·영상·프롬프트 산출의 **품질**(오너만 판정 — `experiments.md`),
  화면의 **생김새**(스크린샷 보드 — `owner-gates.md`). 이 경우 1단계에서 "테스트 대신 무엇으로
  확인하나"를 명시한다. 품질을 흉내 낸 가짜 테스트(항상 통과·경고만 찍는 것) 금지.
