# Experiments — 재현성 규칙

> `research/`와 `lab/`에 적용한다. 이 규칙은 연구를 자동 실행하거나 파일을 생성하지 않는다.

## 재현성

1. 실험 코드는 제품 함수를 import해 호출하는 얇은 wrapper다. 제품 로직을 복사하지 않는다.
2. 상류 출력을 fixture로 고정하고 실제 스테이지 코드를 실행한다. 실험용 대체 파이프라인은 만들지 않는다.
3. 모델 버전·seed·파라미터·입력을 기록한다. 재현의 기준은 같은 출력이 아니라 같은 입력과 채점 기준이다.

## 가설

실행 전에 `research/experiments/_HYPOTHESIS.md`에 예측·측정·반증 조건을 적는다. 어떤 관측이
나오면 가설이 틀렸다고 말할 수 있어야 하며, 반증 조건은 결과를 본 뒤 바꾸지 않는다.
