# /warp — 세션 증류

이 세션을 되돌아보고 아래 6갈래로 라우팅한다. 해당 없으면 그 갈래는 건너뛴다
(빈 문서·빈 섹션을 만들지 마라). 전부 해당 없으면 "남길 것 없음"이라고 보고하고 끝낸다.

## 판정 원칙 (버리는 쪽이 기본값)

- **코드로 귀결된 것은 남기지 않는다** — diff와 커밋 메시지가 기록이다.
- "다음 세션이 이걸 몰라서 같은 삽질을 반복하는가?" — NO면 버린다.
- 실측 없는 추측은 vault에 넣지 않는다 (원칙: "모든 발견은 실측 검증됨").
- **append 전에 기존 vault와 대조한다**: 같은 주제가 이미 있으면 그 파일을 개정하고,
  모순이면 옛 서술에 "무효 — <새 위치>로 대체" 표시. 중복 신설 금지.

## 미결 vs 미뤄둔 작업 — 먼저 이 판별부터

둘은 저장소도 포맷도 다르다. 섞으면 원장이 죽는다.

| | 미결 (`vault` 각 파일 `## 3. 미결`) | 미뤄둔 작업 (`vault/_DEFERRED.md`) |
|---|---|---|
| 상태 | **결론이 없다** | **결론은 났다. 지금 안 할 뿐** |
| 빠진 것 | 답 / 판단 근거 | 시간 · 순서 · 선행조건 |
| 적어야 할 것 | **닫히는 조건**(무엇이 정해지면/실측되면 닫히는가) | **보류 사유**와 **재개 조건**(무엇이 생기면 다시 꺼내는가) |
| 판별 질문 | "무엇을 더 알아야 정할 수 있나?" | "정해졌는데 왜 지금 안 하나?" |

한 논의가 둘 다일 수 있다 — 결정된 부분은 미뤄둔 작업으로, 안 정해진 부분은 미결로 쪼갠다.

## 라우팅

1. **실측·삽질·안 통한 시도** → `.claude/vault/YYYY-MM-DD-<주제>.md`
   - 포맷은 `.claude/vault/_TEMPLATE.md` 준수 (골격 고정, 해당 없는 섹션은 통째로 생략).
   - 핵심 논의는 실제 입출력 원문을 짧게 인용해도 좋다 (요약이 원문을 대체하지 않게).

2. **코드로 귀결 안 된 결정** → 위 vault 파일 안의 `## 2. 결정` 섹션
   - 항목 포맷 (10줄 이내): 상황 / 결정 / 기각한 대안 / 감수하는 것.
   - 별도 결정 로그 파일을 만들지 마라 (specs/decisions.md 없음 — 의도된 부재).
   - **반복 참조될 결정이면 승격**: 해당 정본(specs/design.md, .claude/rules/)에
     반영한다. vault는 사건 기록, 정본은 현재 믿음.
   - 그 결정이 "한다. 단 지금은 아니다"면 → 4번(미뤄둔 작업)으로도 한 줄 넘긴다.

3. **결론 없이 끝난 논쟁** → 위 vault 파일의 `## 3. 미결` 섹션
   - 질문과 함께 **닫히는 조건**(무엇이 정해지면/실측되면 닫히는가)을 반드시 적는다.
   - 세션 중 닫힌 미결이 있으면 6번(아카이브)으로 간다.

4. **결정됐지만 지금 안 하는 일** → `.claude/vault/_DEFERRED.md` (상시 원장, 날짜 파일 아님)
   - vault 날짜 파일은 **과거 사실**의 기록이고, 이건 **살아 있는 대기열**이라 한 파일에 모은다.
     흩어놓으면 "우리가 뭘 미뤘더라"를 답할 수 없다 — 그 답을 만드는 게 이 문서의 존재 이유다.
   - 항목 포맷은 `_DEFERRED.md` 상단의 폼을 그대로 따른다. 필수 4칸:
     **무엇을**(작업) / **왜 미뤘나**(보류 사유) / **언제 꺼내나**(재개 조건) / **되살릴 좌표**(코드·문서 위치).
   - **재개 조건 없는 항목은 만들지 마라.** "나중에"는 조건이 아니다. 조건을 못 쓰겠으면
     그건 미뤄둔 작업이 아니라 미결(3번)이거나, 버릴 것이다.
   - 킬 스위치·플래그로 꺼둔 기능은 **끄는 방법이 아니라 켜는 방법**을 좌표에 적는다.
   - 이미 있는 항목이면 새로 만들지 말고 그 항목을 갱신한다(상태·재개 조건 변화).

5. **같은 실수가 2번째 확인됨** → `.claude/rules/` 해당 파일에 규칙 1줄
   - 예방적 규칙 금지 — 이 세션에서 실제 발생했고, 처음이 아닌 실수만.
   - 어느 rules 파일에도 안 맞으면 추가하지 않는다 (새 rules 파일 신설은 사용자와 논의).

6. **미결 → 밤 티켓 / 아침 결정 카드** → `research/backlog/`
   - vault에 미결을 적은 **직후, 같은 자리에서** 변환한다 — 맥락이 살아있는 유일한
     시점이다. 밤중·사후 배치 변환은 8/5 실측("주기 배치 증류 — 캡처 시점엔 맥락이
     이미 소실됨")과 같은 실패 모드라 금지.
   - 판별 질문: **"맥락 제로 에이전트가 이 미결의 닫히는 조건을 오늘 밤 실행할 수 있는가?"**
     - YES → **티켓** (`research/backlog/_TEMPLATE.md` 폼). 좌표(픽스처·DB·로그 경로·
       선례 코드)와 기각 조건을 지금 얼린다 — 밤 러너는 맥락 제로의 알바생이다.
       "맥락 (사람 언어)" 섹션도 지금 채운다 (아침 HTML 리포트가 그대로 인용 — 개발용어 없이).
       tier/예산은 사용자에게 확인 (T2는 승인 금액 없으면 blocked로 생성).
     - NO (오너 결정·사람 노동·외부 트리거) → **결정 카드** (`_MORNING.md`). **2층 저장 필수**:
       ① **원문** — vault 미결 문장 그대로 (무손실).
       ② **인지 가이드** — 열린 논의는 여러 성분이 뭉쳐 있거나 측정 기준이 없거나 본질
          설계와 얽힌 경우가 많아, 원문만 남기면 아침의 인지 부담이 크다. 뭉친 성분을
          쪼개 각각 이름 붙이고(무엇이 계기 문제고 무엇이 설계 문제인지), 선택지는
          자기완결로(각 선택지가 여는 티켓·닫는 미결·비용 명시), 밤에 준비 가능한
          증거가 있으면 "밤 준비물"로 티켓과 연결한다.
     - 둘 다 아니면 (닫히는 조건 자체가 불명) → vault에만 남긴다. 티켓·카드 강제 생산 금지.
   - 세션 중 닫힌 미결이 있으면 해당 티켓/카드의 status·`→ 결정:` 표기도 갱신한다.

## 해결된 것 치우기 → `.claude/vault/_archive/`

원장은 **열려 있는 것만** 보여야 쓸모가 있다. 이번 세션에서 닫힌 것을 옮긴다.

- **미결이 닫혔으면**: 해당 vault 파일의 미결 항목에 `→ 닫힘(YYYY-MM-DD): <어떻게 닫혔나 / 커밋·파일>`을
  한 줄로 남기고 **항목 자체는 그 자리에 둔다** (날짜 파일은 사건 기록이라 통째로 유지).
- **미뤄둔 작업이 완료·폐기됐으면**: `_DEFERRED.md`에서 항목을 **잘라내** `_archive/_DEFERRED-done.md`
  맨 위에 붙이고, `→ 완료(YYYY-MM-DD): <결과 / 커밋>` 또는 `→ 폐기(YYYY-MM-DD): <사유>`를 덧붙인다.
  대기열에는 살아 있는 항목만 남긴다.
- **vault 파일 전체가 무효화됐으면**(내용 전부가 후속 결정으로 대체됨): 파일을
  `_archive/`로 옮기고, 첫 줄에 `> 무효(YYYY-MM-DD) — <대체한 위치>`를 적는다.
  `CLAUDE.md` 인덱스에서 그 줄을 지운다. **부분 무효는 옮기지 않는다** — 해당 문장만 무효 표시.
- 이동은 `git mv`로 (히스토리 보존). 아카이브한 것은 마무리 보고에 목록으로 남긴다.

## 마무리

- 새 문서가 생겼으면 `CLAUDE.md` 인덱스에 한 줄 추가 — "언제 읽어야 하는지"가
  드러나는 훅 문장으로 (예: "- .claude/vault/2026-08-04-x.md — OO 다시 팔 때 먼저").
- 변경 파일 목록과 각 파일의 요지를 보고하고, **커밋 여부는 사용자에게 확인** (자동 커밋 금지).
