## 1. 계열 분류

같은 "AI 창작 도구"라도 화면 구조가 셋으로 갈린다. **우리는 ⓐ에 속한다.**

| 갈래 | 성격 | 사례 |
|---|---|---|
| **ⓐ 에이전트 파이프라인형** | 전문 에이전트가 단계를 나눠 맡고 사람은 대화로 지시 | **OiiOii · LTX Studio · Lovart** |
| ⓑ 노드 캔버스형 | 무한 캔버스에 노드를 놓고 사람이 직접 배선 | Higgsfield · TapNow · Flora |
| ⓒ 생성 스튜디오형 | 프롬프트 → 결과. 갤러리가 화면의 주인 | Krea · Vidu · Hailuo · Dreamina · DomoAI |

## 5. 같은 자로 잰 비교 (designlang, 2026-08-13)

| 사이트 | 등급 | 대표색 | 글자크기 종류 | 모서리/그림자 | 색 개수 | 명도대비 |
|---|---|---|---|---|---|---|
| **tale-studio(소개페이지)** | **A · 96** | `#a80000` 어두운 빨강 | 11 | 4 / 3 | 4 | 100% |
| OiiOii | A · 91 | `#ff1eb4` 핫핑크 | 10 | 10 / 2 | 6 | 94% |
| Higgsfield | B · 87 | `#d1fe17` 라임 | 18 | 8 / 22 | 15 | 100% |
| Lovart | B · 87 | `#f5f4ef` 크림 | 14 | 6 / 4 | 8 | 100% |
| TapNow | B · 85 | `#1fa2dc` 스카이 | 7 | 4 / 6 | 13 | 67% |
| Flora | B · 83 | `#99eeff` 아이스블루 | 14 | 6 / 0 | 12 | 100% |
| LTX Studio | C · 79 | `#2b61ff` 파랑 | 35 | 9 / 5 | 26 | 100% |

**관찰 — 이 계열에 빨강이 없다.** 대표색이 핫핑크·라임·스카이·아이스블루·파랑·크림이고 **빨강 계열은 우리뿐**이다.
좋다/나쁘다가 아니라 *비어 있는 자리*라는 사실. 넷플릭스 레드는 이 계열의 관습이 아니라 우리만의 선택이다.

**한계** — 전부 소개 페이지다. 로그인 안쪽 작업 화면은 못 쟀다(Hailuo·OiiOii·Lovart·Flora만 일부 노출).
우리 스튜디오 내부도 못 쟀다. 등급은 *규칙성* 지표이지 "좋은 디자인"의 증명이 아니다.

## 6. 비교 도구 (오픈소스)

### designlang — 이번에 실제로 쓴 것
<https://github.com/Manavarya09/design-extract> · npm `designlang` · MIT · 계정/키 불필요

```bash
npx designlang stats <url…>            # 여러 사이트 한 화면 요약 (이번에 쓴 것)
npx designlang battle <urlA> <urlB>    # 두 사이트 정면 비교, 점수 매긴 HTML 카드
npx designlang diff <urlA> <urlB>      # 디자인 언어 차이
npx designlang visual-diff <a> <b>     # 스크린샷 나란히 + 토큰 변화
npx designlang lint <file.css>         # 우리 토큰 파일 감사
npx designlang brands <url…>           # 다중 브랜드 비교
npx designlang mcp                     # Claude Code 안에서 도구로 사용
```

`--cookie-file` 로 로그인 쿠키를 넘기면 **인증 뒤 화면도 측정 가능** — 우리 스튜디오 내부와
경쟁사 작업 화면을 재려면 이 경로다.

**우리 토큰 감사 결과** (`npx designlang lint src/app/globals.css`):

```
Score: 86/100  Grade: B   Tokens: 185
색 규율  100 · 간격 체계 50 · 모서리 80 · 그림자 100 · 접근성 100
✓ 문제 없음
```

→ 색·그림자·접근성은 만점. **약한 곳은 간격 체계 하나.** 색부터 손댈 일이 아니라는 신호.

### dembrandt — 기준선 저장 후 대조용
<https://github.com/dembrandt/dembrandt> · MIT

```bash
dembrandt <url> --save-output                                  # 기준선 저장
dembrandt <url> --compare baseline.json --html report.html     # 차이를 HTML 보고서로
dembrandt <url> --wcag                                         # 명도 대비 검사
```

### taste-skill — 왜 그렇게 했는지까지 뽑을 때
<https://github.com/senlindesign/taste-skill> · `~/.claude/skills/taste` 에 설치됨
`/taste <url>` — 토큰뿐 아니라 **트레이드오프**(무엇을 택하고 무엇을 버렸는지)를 문서로 산출.
전체 자동 실행은 Playwright 연결 필요: `claude mcp add playwright -s user -- npx -y @playwright/mcp@latest --isolated` 후 재시작.
