## 4. 컴파일 규칙으로 보낸 것 (원인 c) → 가이드 §6

## 5. 하네스로 보낸 것 (원인 d)

- 보드 콘텐츠 락(방 코너·창·탁자)이 추상 흰 지면 스타일과 충돌 — 세 레퍼런스 모두 보드 투영/배경 축이 1~2점. 사이클 2 전에 보드 판을 바꿀지 오너 결정 필요(가이드 §7).
- 생성기 관용구(2톤 타원 그림자·제품 렌더 하이라이트·유리 림·열린 미소·살색 얼굴·베이스 밴드·돌출 천창)는 부정 절 '충돌 기본값' 예시에 넣었다(E21). 부정 절만으로 안 막히는 것(폼 섀도 그라디언트)은 그대로 (d)로 남는다.

## 6. v1.1 논의 안건 (오너 육안 확인 + 외부 조사 뒤)

1. `색.역할 배분`이 실제로 refer6의 "청 바디" 잔차를 없애는지 — 사이클 2의 첫 검증 대상.
2. 선택형 승격 후보: `액센트.입도`(소수 대면/다수 소면/혼합), `형태.곡면 처리`(단일 톤/단계 면/저폴리/그라디언트), `내부선.표시 방식`(독립 선/면 도형/혼합), `지면.접지 방식` — 표본이 refer1·5·6 셋뿐이라 v1에서는 참고 후보로 두었다.
3. 피부 톤이 스타일인가 내용인가 — refer1의 붉은 피부는 캐릭터 고유(내용)인데 `재질.피부.톤`은 실측을 적게 되어 있다. 캡슐이 두 hex를 실었지만 생성기는 살색을 골랐다. 내용 가지가 생기기 전까지의 처리 규칙이 필요하다.
4. `분류`·`생성 규칙`을 본문 밖으로 뺄지(v0.2에서 보류).
5. 보드 판(§5) — 흰 무한 지면 판으로 교체 여부, 또는 스타일별 판 선택 규칙.
6. 사이클 2의 비교 조건: 같은 3장 + v1 템플릿 + §6 컴파일 스펙(권장), 또는 새 레퍼런스 추가.
