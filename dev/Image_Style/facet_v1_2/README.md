# facet 템플릿 v1.2 — 추측 허용 규약 (2026-09-08)

## 왜

사이클 3(`../facet_cycle_3/`) 뒤 오너 지적: refer4(600×337 애니 키아트)는 단순한 선 스트로크와 그라데이션이 핵심인데, LLM이 상세한 정보를 강박적으로 억측해 그려서 너무 달라졌다. 어느 정도의 추측을 허용할지 가이드를 만들어 적용하고 refer1·refer2·refer4로 다시 돌린다.

실측 원인(사이클 3 refer4 `fill/filled.jsonc` · `compile/prompts.md`):

| 단계 | 무엇이 잘못됐나 | 예 |
|---|---|---|
| 채우기 | 세지 않은 개수를 `[추정]`으로 적음 | "돌기 두상당 6~14개", "가닥 5~12", "액센트 20개 이상", "격자 6~10줄" |
| 채우기 | 종류를 나열해 '많음'을 만듦 | 내부선.양 = "많음 — 눈·속눈썹·모발 가닥·옷깃·소맷단·격자·명찰" |
| 채우기 | 판독 한계(눈 폭 ≈ 20px) 아래를 장르 상식으로 채움 | "공막·2단 홍채·동공·글린트 1~3·속눈썹 2~4", "클로즈업: 가닥 3~8까지 허용" |
| 채우기 | 한 대상에 붙은 부호를 스타일 어휘로 일반화 | 광륜 → 장식.어휘 + 레이어 "머리 뒤·위 결속" |
| 컴파일 | 그 목록을 전부 실음(하이픈 압축 170단어) | "abundant interior-lines define eyes/lashes/hair/lapels/cuffs/grids/badges", "20+ small marks" |
| 생성 | 시키는 대로 정교화 | T 장면: 라펠 파이핑·휘장·카디건 층, 가닥 10개 이상, 컨페티 25개 |

구조적 원인: 리프 240개는 각각 값을 요구하고, 값을 요구받은 LLM은 관찰이 없으면 '그 장르의 보통 그림'을 답한다. 템플릿에 **정보량의 상한**이 없었다.

## 무엇을 바꿨나

정본: `.claude/skills/artist-style-anchor/scaffolds/facet-template-v1.2.guide.md` §4 12~18항(추측 허용 규약) · §5 채움 검사 · §6 18~26. 편집 스크립트 `make_v1_2.py`(템플릿 27건) · `make_guide_v1_2.py`(가이드).

1. **원칙**: 채워진 템플릿은 그림보다 더 많은 정보를 담을 수 없다. 관찰하지 못한 값은 그 장르의 보통 값이 아니라 '없음'이다.
2. **먼저 재는 것**: `입력.판독 한계`(주체 px 크기 · 최소 판독 크기) → `디테일.묘사 밀도`(표본 개체 1개의 실측 개수 6종 → 등급 1~5). 이후 모든 개수 리프는 이 값을 인용한다.
3. **추측 허용 등급표**: `[실측]` = 센 값·잰 값 / `[추정]` = 정성어·경향·관측 상한 안의 수치, 세지 않은 개수 금지 / `[외삽]` = 한 줄 / 금지 = 장르 선험·판독 한계 아래·속성형 부호의 일반화.
4. **단순성 편향**: 갈리면 적은 쪽. 없음은 값("가닥선 없음"), 컴파일이 "no …"로 싣는다.
5. **컴파일**: 묘사 예산 절("Detail budget: …") 필수, [실측] 개수만 수치, 나열 금지, 결속형 제외, 자연문 + 등급별 단어 예산(캡슐 90~170, 앵커 70~120), 키 절, 장면 요약에서 고유 소품·로고 제외.
6. **기계 검사**: `bin/check_fill.py` — 사이클 3 채우기에 돌리면 refer4 위반 10(세지 않은 범위 3·열린 상한 2·판독 한계·묘사 밀도 부재), refer2 10, refer1 6. 사이클 4 하네스는 위반 시 1회 재작성.
