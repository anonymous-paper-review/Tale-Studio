작성 시각: A arm 생성 잡 제출 **이전**. 사후 합리화를 막기 위해 먼저 고정한다.
대상 preview: `media/style-anchors/previews/real_jp_melo.jpg` (1024×1024)

## preview 실물 기술

만개한 벚꽃 가로수길, 흩날리는 꽃잎, 자전거(책 담긴 철제 바구니)를 세우고 어깨너머로 돌아보는 젊은 여성
(동아시아계, 짧은 다크 보브, 크림 니트 카디건 + 아이보리 롱스커트). 좌우로 목재·블록 담장, 전신주와 전선,
일본식 주택 지붕. 봄 아침 **역광**, 꽃잎 깔린 노면, 얕은 심도, 필름 그레인.

## Content-bound (= 누수로 셀 것). 다른 인물·공간·시간대에서 반복되지 않는 것

| 코드 | 항목 | 판정 근거 |
|---|---|---|
| **C1** | 특정 인물 — 짧은 다크 보브 + 크림 니트 + 아이보리 롱스커트의 동아시아계 여성 | 특정 정체성 표면 |
| **C2** | 자전거 · 철제 바구니 · 책 다발 | 소품 |
| **C3** | 벚나무 · 만개한 벚꽃 | 이 룩의 최대 상투 소품. **B arm 이 텍스트만으로 소환한 바로 그 항목**(§5.2) — A 에서는 이미지발로 오는지가 관전점 |
| **C4** | 흩날리는 꽃잎 · 노면에 깔린 꽃잎 | 소품 |
| **C5** | 일본 주택가 골목 정체성 — 목재/블록 담장, 좁은 골목, 일본식 가옥 지붕 | 장소 정체성 |
| **C6** | 전신주 · 전선 | 장소 정체성 |
| **C7** | 봄 아침 시간대 | 시간대 (야간 프로브 2장에서 측정) |
| **C8** | 크림/아이보리 니트 카디건 의상 | 의상. `real` 런에서 **의상 누수가 콘텐츠 품질을 훼손**한 선례(C8) — 같은 코드 부여 |
| **C9** | 동아시아계 인종 자체 | **누수로 세지 않고 별도 기록** — 인종은 룩의 일부가 아니지만 preview 가 유일 인물 레퍼런스이므로 강제 여부를 관측만 한다 |

## Look-bound (= 전이되어야 정상. 누수 아님)

이것들이 A 에서 올라오면 **성공**이다. 보드가 못 나른 축이고, A 를 집행하는 이유다.

| 코드 | 항목 | 보드 실측 | preview 실측 |
|---|---|---|---|
| L1 | 근중립 색온도 | R−B **+24.6** (웜) | R−B **+7.2** |
| L2 | 저채도 | 16.1% | **8.3%** |
| L3 | **다색 gamut** | hue_H 0.34 / 쿨 **0.0%** | hue_H **0.60** / 쿨 **11.9%** |
| L4 | 역광 헐레이션 | 하이라이트거칠기 6.00 | **11.04** |
| L5 | 넓은 다이내믹 레인지 (어두운 앵커 요소 보유) | 그림자바닥 104 / 대비 139 | 그림자바닥 **61** / 대비 **176** |
| L6 | 고 디테일 밀도 | 강엣지 4.1% / 플랫 36% | 강엣지 **12.0%** / 플랫 **7%** |

## 사전 예측 (반증 가능하게 먼저 적는다)

1. **L1~L3 는 A 에서 개선될 것이다.** 선례 횡단 규칙 1("A 는 색 축에서 preview 쪽으로 끌려간다")이 여기서는
   **채도를 내리는 방향**으로 작동해야 한다(preview 가 보드보다 저채도인 최초 사례).
2. **C3(벚꽃)은 A 에서 누수될 것이다.** 선례 패턴("장소와 계절의 정체성이 넘어온다") + B 가 텍스트만으로도
   소환한 항목이므로 이미지가 들어가면 더 강할 것이다. **예측이 빗나가면 A 가 B 보다 깨끗하다는 강한 증거가 된다.**
3. **매체는 유지될 것이다.** B 의 일러스트 이탈은 텍스트발이었고 preview 는 실사 사진이므로, A 는 오히려
   매체를 **강화**할 것으로 예측한다. 이게 A 의 최대 기대 이득이다.
4. **야간 2장의 톤 리프트는 B 보다 작을 것이다.** preview 는 그림자바닥 61 로 보드(104)보다 어둡다 —
   A 는 야간을 덜 들어올려야 한다.

## IP 인접성 사전 소견 (§10 에서 실물 대조 후 확정)

원 설계 문서가 밝힌 차용 아키타입은 "벚꽃 가로수길+자전거, 역광 (**4월 이야기 계열**)" — 즉 특정 일본 영화
계보가 **명시적으로 호명**돼 있다. 다만 `watercolor` preview 의 기각 사유(유명작 오마주 = 화풍 자체가 특정
작품의 것)와는 구조가 다르다: 여기 차용은 **구도 아키타입**(저작권 대상 아님)이고 인물·의상은 오리지널
생성물이며, 판독 가능한 로고·랜드마크·실존 배우가 없다. 벚꽃길+자전거+돌아보는 소녀는 일본 영상물에서
극도로 흔한 상투 구도라 특정 작품 귀속이 어렵다. **사전 소견: 법무 리스크 낮음 — `watercolor` 급 상시 기각
사유에 해당하지 않음.** 단 산출물이 preview 인물을 재현하면(G1 실패) 판단이 달라진다 — §10 에서 확정한다.
