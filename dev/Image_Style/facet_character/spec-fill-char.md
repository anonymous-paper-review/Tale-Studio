# 작업: 첨부 이미지(<IMAGE>)의 캐릭터 facet 템플릿 채우기

당신은 캐릭터 분석자(VLM)다. 첨부 이미지 1장을 보고, 이 폴더의 캐릭터 템플릿을 **화면에 보이는 캐릭터마다 카드 1장씩** 채운다. 읽는 순서: `facet-character-v0.guide.md`(목적·계층·메타 태그·작성 규칙·경계) → `facet-character-v0.jsonc`(조립도) → 스타일 맥락 파일 `<STYLE_CTX>`(이 그림의 스타일 분석 — "스타일 기본값 따름"의 기준). 산출물은 이 폴더에 저장하는 파일들이다: `card-1.jsonc` … `card-N.jsonc`(N = 캐릭터 수, 최대 <MAXN>장, 화면 왼쪽부터·두드러진 순), `cards.md`(카드별 한 줄 식별 메모: 위치·한 문장 묘사), `proposals.md`.

## 고정 규칙 (하네스 제약)

- 작가·프랜차이즈·작품·브랜드·**캐릭터 이름** 고유명사를 절대 쓰지 마라(추측·부정문도 금지). 원본이 무엇인지 알아보더라도 시각 속성만 적는다. `정체성.고유 식별.출처 구분`은 기존/오리지널/판독 불가 중 하나만.
- 값은 한국어(hex·px·%·영문 태그 어휘는 허용). 이 폴더의 다른 파일은 수정하지 마라. 외부 검색·네트워크 접근 금지.
- 최종 메시지에는 `proposals.md` 전문과 `cards.md` 전문만 붙여라(카드 전문은 파일에 있으면 된다).

## 카드 채우는 법

1. 가이드 §5의 규칙을 따른다. 선택형(`[N개 중 1개 선택: …]`)은 후보 중에서 고르고, 관찰값이 후보에 없으면 억지로 고르지 말고 자유 서술한 뒤 `proposals.md`에 "후보 밖"으로 적는다. 값 앞에 신뢰도 태그 `[실측|추정|외삽|해당 없음]`를 붙인다.
2. 키·계층·순서·주석은 그대로 두고 값만 바꾼다. 값의 `ex.` 접두는 지운다. 키 이름이 `_`로 시작하는 규약 리프(예: `_기준계`)는 값을 바꾸지 않는다.
3. 스타일 소유 축(가이드 §6: 코·입 표현, 눈 묘사 수준, 피부 톤 표현, 헤어 렌더링, 손 표현 수준 등)은 이 캐릭터가 같은 그림의 다른 캐릭터와 다르게 그려졌을 때만 오버라이드하고, 아니면 `"스타일 기본값 따름"`으로 적는다. 스타일 맥락 파일이 없으면 관찰값을 직접 적고 `[추정]`을 붙인다.
4. 그림에서 관찰되지 않는 값(가려짐·표본 없음)은 비워 두지 말고, 다른 리프·원형 번들·일반 지식에서 **가장 그럴듯한 값**을 골라 `[추정]`을 붙이고, 근거를 그 가지의 `기타` 리프에 한 줄로 적는다(오너 방침: 유저가 주지 않은 정보는 LLM이 유추한다).
5. `관계` 가지는 캐릭터가 1명이면 전체 `[해당 없음]`. `배치`는 캔버스 좌상단 기준 %로. `상태.포즈.키포인트 세미 정량`은 카드 1(가장 두드러진 캐릭터)만 채우고 나머지는 `[추정] 생략`.
6. 색은 hex, 크기는 기준 대비 비율, 개수는 정수. 촬영본(회색 캐스트)이면 보정값을 쓰고 실측값을 괄호에.

## proposals.md

채우면서 발견한 템플릿의 빈틈을 한 항목당 한 줄로: `- [유형] 키 경로 — 내용 (근거: 이 이미지에서 관찰한 것 1문장)`. 유형은 `새 facet`(적을 key가 없었다: 가지 경로·key 이름·값·주석 초안 2문장 이상) / `후보 밖`(선택형 후보에 관찰값 없음: 추가할 후보) / `모호`(해석이 갈림: 어느 쪽으로 채웠나) / `중복`(두 key가 같은 것을 가리킴) / `스타일 경계`(캐릭터 값인지 스타일 값인지 갈림). 최소 8개, `후보 밖`과 `새 facet`을 우선해서 찾아라 — 이 캐릭터를 재현하는 데 필요한데 서식에 자리가 없는 속성이 있는지가 핵심 질문이다.
