**C 외장** — 노출 범위를 아이템 속성에서 복장 전체 속성으로 이동(맨살은 레이어를 겹친 결과) · '상태'를 `착용 상태`(열림·걸침·걷어올림·흘러내림, 가변)와 `손상·오염`(젖음·찢김·그을림·피·파손, 가변)으로 분리 · 네크라인·칼라 축 추가(Fashionpedia 25 + 태그 collar 절; 세일러 칼라처럼 식별 기여가 큼) · 소매 길이와 기장을 별도 리프로 · 양말 → 양말·레그웨어(높이 8단) · 복장 전체 리프 3개 신설(`레이어 겹침 순서`, `전체 실루엣` H/V/A/X/O/블록, `색 구성` 면적 순 3~5색) · 세트 번들을 가지로(`상위군` 12 선택형 + `명칭·구성` + `적용 범위·오버라이드`: 레이어 리프 값이 있으면 번들을 이김) · 액세서리에 `시그니처` 리프(착장 안에서의 보존 순위) · 액세서리 위치 4군 유지하되 '몸'에 다리 포함(가터·앵클릿·니패드) · 소지품에 `방향·자세` 추가, '어느 손' → '어느 손·부위'(등·허리·어깨 장착) · 착탈 표식에 페이스페인트·스티커·주얼 추가(문신은 B에 남김) · 장갑 비대칭 표기(single glove, 양손 ` ; ` 분리).

**D 상태** — 머리 방향 = 절대 방향(뷰어 기준) + 몸통 대비 차(°) · 몸통 방향에 ¾ 후면 추가 · 시선에 흘김·다른 인물·사물·먼 곳 추가(D = 방향, G = 대상) · 발 리프 추가 · 동세 라인 = CSI(직선/C/S) + 방향 · 무게 중심에 지지물·공중 · **키포인트 값 형식**: OpenPose BODY_25 기본(COCO 17·18 대안), 정규화 (x, y, v) 삼중항, 관절 내각 '≈ N°', 픽셀 금지 · 감정 = EMFACS 7 + 중립, 강도 = FACS A~E, AU 조합 참조 리프 · 이마 핏줄 = 분노 마크로 통합, 얼굴 위 음영선 = shaded_face/gloom · 표정의 땀(기호)과 D4 땀(발한) 분리 · 동공 변화·기호 위치·크기 추가 · 동작 단계 3 → 5(정지·진행 중) · 잔상+스피드라인 다중 선택형 · 휘날림에 바람 방향·세기 필수 · 상처: 흉터 → B, 붕대 → C4, D4는 신선한 부상만 · 부분 변신 = 단계 선택형 · 호흡·수면·의식 확장 · **좌/우 규약**: 신체 부위 = 캐릭터 기준(OpenPose L/R), 방향·시선·바람 = 화면 기준.

**E·F·G** — E: 모든 리프 기본값 "스타일 기본값 따름" + 덮어쓰는 스타일 key 경로, 이펙트 = 종류(8 다중) + 위치·범위 + 색·강도, `재질 오버라이드` 추가, 디테일 밀도 = 눈·얼굴:의상 한 리프, 모션 표현은 D3·몸 자체 발광은 D4로 경계 · F: 좌표 규약(좌상단 기준 %, 화면 좌우 vs 캐릭터 좌우), 앵커를 절단 프레이밍까지, 폭·여백·초점 추가, 프레이밍 5 → 9(원경·cowboy·부분·하반신), 가려짐 = 가리는 것(6군) + 부위(LIP 20 → 8군 + COCO), 가장자리 절단은 프레이밍+가려짐으로 흡수, 시점 높이는 캐릭터 리프로 두지 않음 · G: 구성(단독/다인 초점/다인 동등)·대상 추가(단독이면 가지 전체 [해당 없음]), 공간 = 상대 위치 + 간격 + 몸 방향 관계, 접촉 = 유형 12군 + 부위(행위자 → 대상), 주의 = 시선 대상 ×2, 상대 크기 = 실측 / 설정 / 머리 높이차, 상호작용 = '행위자 → 대상: 동사'(D3와 상호 참조).

## 3. 스타일 템플릿과의 경계 — 합의된 원칙

- "이 캐릭터가 무엇을 가졌는가" = 캐릭터, "이 스타일이 그것을 어떻게 그리는가" = 스타일. 양쪽에 있는 항목은 캐릭터 값의 기본이 `"스타일 기본값 따름"`이고, 같은 그림의 다른 캐릭터와 다르게 그려질 때만 오버라이드.
- 스타일이 이기는 축(캐릭터는 "따름"): 코·입 표현, 눈 묘사 수준·눈꺼풀 선 굵기·글린트 관습, 피부 톤 표현·광택·셀 단계, 헤어 구축·하이라이트 형태·외곽·눈썹 투과, 손 표현 수준, 사지 조형(굵기·테이퍼·관절), 부위별 과장, 무얼굴 여부, 포즈·표정의 화풍 편향.
- 캐릭터가 이기는 축(스타일에 두지 않음): 홍채·피부·머리 hex와 색 구성, 종족 파츠와 표면 재질(무엇으로 되어 있나), 의상 종류·색, 머리 컷·길이·아호게, 결손·대체, 실제 포즈 각도·표정·배치·관계.
- 뜻이 다른 동명 항목: `정체성.인간형 정도`(존재가 무얼굴인가) vs `인물.무얼굴 여부`(스타일이 얼굴을 생략하는가); `선.끝점 처리`(선 캡) vs `머리카락.질감.끝 처리`(컷 모양); `재질.피부.재료감`(어떻게 칠하나) vs `얼굴.피부.재질`(무엇으로 되어 있나).
- 스타일 템플릿 쪽 신설 제안(오너 판단): `인물.눈.눈썹 투과`(앞머리 위로 눈썹·눈이 비치는 관습 — B-2), 좌/우 규약을 스타일 가이드에도(D).

## 4. 오너 판단이 필요한 것

1. **기여도 축의 범위** — 식별만 재므로 D~G가 전부 '하'. 가이드 §4는 가변층을 카드 예산 밖으로 빼는 규칙으로 처리했고, '장면 재현 기여도' 축 추가 여부는 사이클 뒤 결정(E·F·G ⑳).
2. **F.위치(3×3)·깊이층(3층)·G 선택형 6개**는 실측이 아니라 기하 정의·외부 어휘로 닫았다(사내 2인 상호작용 실측 0). 유지할지, 자유 서술로 낮출지.
3. **선택형 163개의 후보 밖 비율**이 첫 사이클의 검증 항목 — 후보가 외부 어휘에서 왔으므로 우리 레퍼런스(refer1·2·3의 인물)에서 얼마나 맞는지 봐야 한다.
4. **규약 리프**(D `키포인트.기준계` 등 값이 아니라 형식을 적는 리프)는 프롬프트에 싣지 않는 표시가 필요(D ⑳) — 컴파일 규칙을 쓸 때 정한다.
5. **부분 변신 완료 형태**는 별도 A·B 카드로 두는 방식(D ⑯) — 다중 폼 캐릭터의 표현 방법.
6. **스타일 템플릿 신설 요청 2건**(§3 마지막) 수용 여부 — 수용 시 v1.1에 포함.
7. **계층 간 조율 항목** — (a) 페이스페인트: B-1 `얼굴.얼굴 표식`(문신·페이스페인트 3범주)과 C `착탈 표식.페이스페인트·스티커·주얼`이 겹친다 → 영구(문신)는 B, 착탈은 C로 정리하고 B-1 후보에서 페이스페인트를 빼는 방향. (b) 예시 캐릭터의 [추정] 값(C의 언더셔츠·벨트·머리끈·부츠 커프, B-2의 hex·아호게 길이)은 공동 예시 문장에 없어 각자 추정한 것 — 실측 이미지 기반 캐릭터로 교체할 때 정리. (c) `정체성.종족 파츠.목록`(A)과 `신체.파츠·표식.비인간 파츠.종류 수`(B-2)는 일치해야 한다는 규칙을 양쪽 주석이 명시 — 채우기 스펙에서 검사 항목으로. (d) 그런데 두 후보 집합이 어긋난다: A 목록 11(공통 8 + 뾰족귀 · 헤일로)과 B-2 종류 12(공통 8 + 지느러미 · 더듬이 · 국소 피복). B-2는 뾰족귀를 B-1 `얼굴.귀.형태`로, 헤일로를 C2 머리 액세서리(오너 노트 원안)로 보았다. 제안: A 목록에 지느러미·더듬이를 추가하고, 뾰족귀·헤일로의 소속(정체성 파츠로 셀지, 귀 형태·액세서리로 뺄지)을 오너가 확정 — 확정 전까지 '종류 수 일치' 검사는 공통 8종만 대상으로 한다.
