## §오너 노트 수정 제안

골격에서 고친 곳(→)과 추가한 곳(+):

1. **B3 길이 5단 → 7단.** 오너의 '매우 짧음/단발/중간/긴/매우 긴'에 민머리(bald)와 극단적으로 긴(absurdly long: 신장 초과)을 더하고, 경계를 Danbooru 랜드마크(턱·어깨·허리·바닥·신장)로 고정했다. + `끝 위치`(정수리 0%~발 100%) 리프로 등급 경계 캐릭터를 보강.
2. **B3 앞머리 '일자/시스루/옆으로/M자/없음' → 4축 분해.** '시스루'는 형태가 아니라 **숱·간격(성김)** + **렌더링 투과(눈썹·눈이 비침)** 의 합성이라 두 리프로 나눴다. 'M자'는 Danbooru의 curtained hair(커튼)·parted bangs(갈라짐)에 대응시켜 이름을 바꿨다. '없음'은 태그가 없어(no_bangs 0건) forehead·hair pulled back으로 정의. + 길이(3단) · 눈 가림(5상태) 리프.
3. **B3 옆머리 '길이'만 → 길이(5) + 형태(8) + 돌출 조형(5).** 히메컷·hair intakes·hair flaps처럼 실루엣을 바꾸는 요소가 길이 축에 안 담겨서 추가.
4. **B3 뒷머리 6종 → 12종.** 사이드 포니테일·원 사이드 업·하프업(two side up)·로우 타이·멀티 타이·상투를 추가하고 '올림'은 번/올백으로 분해. + 묶음 높이(3) · 묶음 개수(정수) · 땋음·번 세부(자유). **변동성을 준불변으로 낮춤** — alternate hairstyle·hair down이 각각 14만·4만 건으로, 같은 캐릭터가 머리를 풀거나 다르게 묶는 장면이 흔하다(오너 노트의 'B 대부분 불변' 예외).
5. **B3 가르마 → 5종**(없음/중앙/옆/지그재그/이중). 앞머리 갈라짐(parted bangs)과 두피 가르마(parted hair)를 Danbooru처럼 분리.
6. **B3 아호게·더듬이 → 종류·개수(4) + 형태(10) + 위치·길이.** '더듬이' = antenna hair(2가닥 이상), 1가닥 = ahoge, 짧고 굵음 = cowlick이라는 Danbooru 판별 규칙을 그대로 채택.
7. **B3 질감 '직모/웨이브/곱슬' → 5단**(kinky·ringlets/drill 추가). + 끝 처리(6) · 정돈도(3) · **특수 재질(11: 불꽃·액체·에너지·결정·식물·깃털·기계·촉수·구름·리본)** 신설 — 오너 골격에 없던 판타지 헤어 축. 볼륨·층은 하나로 묶어 자유 서술.
8. **B3 렌더링 방식(덩어리/가닥/유광 링/지그재그 하이라이트) → 스타일 소유로 판정.** 오너의 네 후보는 구축(덩어리·가닥)과 하이라이트 형태(링·지그재그)라는 두 축이 섞여 있고, 둘 다 스타일 템플릿 `재질.헤어.구축·하이라이트·외곽`·`인물.헤어 구축`이 이미 갖는다. 캐릭터 템플릿에는 `렌더링` 가지에 리프 3개(구축·하이라이트 형태·눈썹·눈 투과)를 두되 값은 `스타일 기본값 따름`이 기본이고 변동성은 가변, 기여도는 하. 오버라이드 조건(특수 재질·같은 그림 안에서 이 캐릭터만 다름)을 주석에 명시. **스타일 템플릿에 `인물.눈.눈썹 투과` 리프 신설을 제안한다**(현재 없음 — refer 실측에서 시스루 관습 여부를 방언 절에 실을 자리가 없다).
9. **B3 색 → 계열(12) + hex + 다색 구성(10) + 보조색 + 안쪽 색.** 오너의 '그라데이션·하이라이트·투톤·안쪽 색' 중 **'하이라이트'는 색 축에서 뺐다** — 하이라이트 색은 스타일 팔레트 규칙이 정한다. 대신 스트릭·끝 색·뿌리·좌우 분할·앞머리 색·패턴을 추가.
10. **B4 비인간 파츠 반복 구조 — 오너 5속성(종류·위치·개수·크기·색) + 4속성**(세부 유형·재질·표면·형태 변형·손상·사람 귀 공존). `종류 수` 리프가 A `정체성.종족 파츠.유무`·`목록`과 일치해야 함을 명시. 착용물(animal ear headphones·fake tail·horned headwear)은 C2로 배제.
11. **B4 손 '손가락 수(4/5), 표현 수준(장갑형/상세)' → 형태(8, 파츠 유형) + 손가락 수(정수) + 표현 수준(스타일 기본값) + 손톱(5).** 표현 수준은 스타일 `인물.손`이 소유하므로 캐릭터 값은 기본값 따름. 손가락 수는 Danbooru 어휘가 없어 정수 자유 값.
12. **B4 '신체 문양·문신·흉터' → 문신 / 흉터 / 문양·반점(선천) 3분할**, 각각 위치를 신체 구역 선택형으로(얼굴은 B-1). 오너 골격에 없던 **봉합 자국(stitches)·백반·패치워크 피부**를 후보에 추가.
13. **B4 체모 → 정도(4) + 부위(8).** 성적 부위 태그는 BRIEF §4에 따라 제외. 색 리프는 두지 않음(머리 베이스와 동일 가정, 다르면 기타).
14. **B4 '의족·의수 등 결손/대체' → 결손 부위(10, 절단 높이 병기) + 대체 종류(8) + 개수·좌우 + 외관·재질·색 + 관절 표현(3).** 사이보그의 기계 팔(결손 대체가 아닐 수 있음)도 시각 속성이 같아 여기서 함께 적도록 했고, 프레이밍 가림을 결손으로 오독하지 않도록 F 참조를 넣었다.
15. **A·B-1 조각과의 어휘 정렬(합칠 때 결정 필요).** A `종족 파츠.목록`(11)과 B-2 `파츠 항목.종류`(12)의 후보가 3+2개 어긋난다(§경계 둘째 표). B-2 쪽 판단: 뾰족귀는 귀 형태(B-1)이지 별도 파츠가 아니고, 헤일로는 오너 노트가 C2 머리 액세서리로 둔 항목이라 파츠에서 뺐다. 지느러미·더듬이는 Danbooru 포스트 수(head fins 1.9만·antennae 2.9만)가 뾰족귀 외 파츠와 같은 급이라 추가했다. B-1 `얼굴.피부.패턴`과 B-2 `문양·반점.종류`의 백반·패치워크는 전신/국소로 갈랐고 양쪽 주석에서 상호 참조하도록 B-2 쪽에 문장을 넣었다.
16. **메타 태그 적용 결과.** 머리카락 컷·색·아호게·특수 재질·파츠 종류·결손·대체 종류 = 불변·상; 뒷머리 스타일·묶음 높이·개수·정돈도 = 준불변; 렌더링 3리프·손 표현 수준 = 가변·하. 오너의 '머리(형태+색) > … > 나머지' 순위와 충돌 없음.

## §기여도 근거

- **머리(형태+색) 상**: Danbooru 전체에서 가장 큰 일반 태그군이 머리 길이·색이다(long_hair 619만, short_hair 312만, black/blonde/brown_hair 각 200만 이상, hair_between_eyes 178만). 캐릭터 wiki 페이지의 관례적 서술 순서도 머리 색·머리 모양·눈 색 순(관찰; 정량 미측정). 포스트 수는 등장 빈도이지 식별 기여도의 직접 측정은 아니므로 '상' 판정은 오너 노트의 순위(머리 > 눈 > 실루엣 > 액세서리 > 피부 > 나머지)를 1차 근거로, 포스트 수를 보조 근거로 썼다.
- **앞머리 유형·눈 가림·뒷머리 스타일·아호게 상**: blunt_bangs 43만·hair_over_one_eye 37만·twintails 123만·ponytail 96만·ahoge 97만 — 실루엣을 바꾸는 요소이며, 앞머리·아호게는 얼굴 근처라 썸네일 크기에서도 판독된다.
- **옆머리·가르마·끝 처리·정돈도 중~하**: 옆머리(sidelocks 94만)는 빈도는 높지만 대부분의 캐릭터에 있어 변별력이 낮아 중, 가르마(side_part 4.7천·middle_part 1.5천)는 태그 자체가 드물어 하, 끝 처리·정돈도는 스타일·장면에 흡수되기 쉬워 하.
- **특수 재질 상(있을 때)**: fiery_hair 4.5천·liquid_hair 2.3천처럼 드물지만, 있으면 캐릭터를 단독으로 정의한다(희소성 = 변별력).
- **파츠 종류·세부 유형 상**: animal_ears 175만·tail 119만·horns 69만·wings 63만 — 있는 캐릭터의 실루엣을 지배한다. 위치·개수·크기·색은 중(같은 종류 안의 변별), 재질·사람 귀 공존은 하.
- **결손·대체 상**: prosthesis 1.3만·amputee 1.1만·mechanical_arms 2.5만으로 희소하며, 있으면 실루엣·색 모두 바꾼다.
- **문신·흉터 위치 중, 유형·색 하**: tattoo 21만·scar 17만 — 위치가 실루엣에 안 보여도 노출 부위의 도안은 시그니처가 될 수 있어 도안은 중. 얼굴 흉터(scar_across_eye 등)는 강한 식별자지만 B-1 소관.
- **문양·반점 중/하, 체모 하**: body_markings 1.7만은 종족 표식이라 중, mole·freckles(얼굴 외)는 하; body_hair 2.4천은 애니풍에서 거의 그리지 않아 하.
- **렌더링 3리프·손 표현 수준·손톱·손가락 수 하**: 스타일이 결정하거나(렌더링·표현 수준) 썸네일에서 판독되지 않는다(손톱·손가락 수).

## §미검증

1. **Danbooru 원본 접근 불가** — 모든 wiki·태그 수치는 safebooru.donmai.us 미러 JSON API 기준. wiki 본문은 같은 DB이나, post_count는 안전 모드 필터 때문에 원본보다 작을 수 있다(상대 순위는 유지된다고 가정).
