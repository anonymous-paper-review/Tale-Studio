## 1. 무엇이 왜 문제였나 (진단 3층)

1. **정보 교집합 공백** — 정물 보드가 운반 가능한 정보 = {재질, 조명, 그레이드, 심도}.
   사람이 "3D 애니메이션"을 판별하는 축 = {두신비, 얼굴 조형, 피부·머리카락 셰이딩, 아웃라인}.
   **교집합이 거의 비어 있어** 배선이 정상인데도 스타일이 안 지켜졌다. (§4.1)
2. **preview ≠ anchor** — 픽커에 보이는 그림(여우 셰프, 스타일라이즈드 3D)과 모델이 받는
   앵커(포토리얼 정물)가 서로 다른 물건이었다. 오너가 고른 것과 모델이 받는 것의 괴리. (§1.1)
3. **그레이드가 매체 행세** — 구 앵커가 실제로 나르던 건 석양 앰버 그레이드뿐이라,
   `real`(차가운 사진)과 `real_3d`(따뜻한 사진)의 델타가 매체가 아니라 **색온도**였다. (§1.2~1.3)

+ 앵커 밖의 공범: 프롬프트에 실리는 매체어(`photorealistic` 등)가 앵커 이미지를 이긴다
  (2026-07-14 판정, §6D에서 그레이드 축으로 독립 재현). **앵커만 갈아서는 안 됐다.**

## 3. 검증 실측

- **게이트 3종 통과** (§6A.2): 정체성 누수 0/4(보드 인물과 산출 인물의 성별·헤어·의상 전부

- **정보량 임계 실측** (§6B.1): 보드 내 인물 정보량 최대(C2)·중(C1)·최소(C1b) 3종의 인물
  전이 품질이 **전부 동등** — "임계점만 넘으면 되고 임계는 낮다".
- **앰버 프롬프트 제어** (§6D): 중립 보드 + 씬 프롬프트의 석양 명시 → 채도 28→73%,
  R−B +42→+98로 **기준선(석양 원본 54%/+62) 초과 복원**. 앰버 제거는 무비용 확정.
  동시에 "텍스트 그레이드 권위 > 앵커 이미지"의 실측 재확인 = B4/B5 필요성의 증거.
- **오너 프로덕션 실측** (2026-08-13, fal 경로): 스타일 축 개선 확인. F-004는 시트 재생성
  육안까지 부분수리 유지.

## 4. 이번 런이 남긴 교훈 (플레이북의 코어)

1. **판별 질문이 먼저다**: "사람이 이 매체를 알아보는 근거가, 이 보드가 나를 수 있는 정보와
   겹치는가?" 안 겹치면 보드를 더 잘 그리는 게 아니라 **보드에 그 정보를 넣어야** 한다.
2. **preview 직결 금지**: preview는 목표 레지스터의 정의(오너가 고른 것)로만 쓰고, I2I로
   중립 보드를 새로 굽는다. 방어절("Do NOT reproduce its subject") 1문장에 기대지 말 것.
3. **시간대·그레이드는 Content-bound**: "이 요소가 다른 인물·공간·시간대에서도 반복되는가?"
   아니오면 보드에서 뺀다. 보드에 구우면 모든 프레임에 강제된다(구 앰버의 병증). 색은
   조명이 아니라 **오브젝트에** 넣는다(청천·적사과 — C1b 검증).
4. **인물은 익명성 락 4겹으로**: 평범한 이목구비·무지 의상·소지품 0·중립 포즈 + 종(種) 락.
   정체성 표면을 지우면 조형 언어만 남고, 그게 우리가 원하는 전부다. G1 게이트는 유지.
5. **인물 정보량은 임계만 넘기면 된다**: 클로즈업의 추가 정보는 전이 성능에 기여하지
   않았다(3점 실측). 단 오너가 룩 선언 축에서 클로즈업을 선호할 수 있다 — 최종 미학 판정은
   오너 몫(스킬 규정).
6. **앵커 교체는 텍스트 정리와 세트다**: 프롬프트에 매체어가 살아 있으면 텍스트가 이긴다.
   B4/B5가 이미 배포돼 있으므로 다른 앵커 교체 시 이 축은 재작업 불요 — 단 각 앵커의
   `medium` 값이 정확해야 B7 억제가 맞게 돈다.

6. **fal 프로덕션 실측 1샷** — higgsfield 검증은 방향성일 뿐(§6C-4). 이거 전엔 성공 주장 금지.
