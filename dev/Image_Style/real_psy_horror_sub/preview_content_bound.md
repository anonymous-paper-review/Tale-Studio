## preview 실물 (`preview.jpg`, 1024×1024)

1점 투시의 낡은 아파트 복도. 끝에 커튼 친 창, 그 앞에 **등 돌린 인물 1인**(회색 롱코트/카디건).
천장에 노출 백열전구 1개. 양쪽 벽은 벗겨진 벽지 + 물얼룩, 하부 벽판(wainscoting)과 걸레받이 몰딩.
바닥엔 낙엽·파편. 좌우로 문 여러 개. 계측: Y 1.00% · C\* 2.99 · b\* −0.94 · clash 6.22.

## P — 새면 안 되는 것 (G-content 실패 조건)

| id | 항목 | 위험도 판단 |
|---|---|---|
| **P1** | **1점 투시 복도 구도** | 높음 — preview 의 최대 특징. 카페·스쿠터가 복도형 소실점 구도가 되면 누수 |
| **P2** | **등 돌린 단독 인물** | 높음 — `No people` 프로브(cafe·scooter)에 인물이 나타나면 최악 시나리오 |
| **P3** | 복도 끝 커튼 친 창 | 중간 — 카페는 창을 요구하므로 **커튼·격자·복도끝 배치**가 복제될 때만 계상 |
| **P4** | 천장 부착 노출 전구 | **판정 불가 — 보드(S1)와 같은 채널.** A 에서 전구가 나와도 preview 귀속 불가. §9 에서 T 대비 증분만 본다 |
| **P5** | 벗겨진 벽지 + 물얼룩 | **판정 불가 — 보드(S3)와 같은 채널.** 위와 동일 처리 |
| **P6** | 하부 벽판·걸레받이 몰딩 | 중간 — 보드에는 **없다.** preview 고유라 귀속 가능 |
| **P7** | 바닥의 낙엽·파편 | 중간 — 보드에는 없다. 귀속 가능 |
| **P8** | 회색 롱코트/카디건 의상 | 중간 — 인물 프로브에서 의상이 지정돼 있으므로(`worn utility jacket`) 이탈하면 누수 |
| **P9** | 복도 양쪽 반복되는 문 | 낮음 |

**중요 — 이 런의 구조적 한계**: preview 와 보드가 **같은 룩·같은 소재(낡은 방/전구/얼룩 벽)**를 공유한다.
그래서 P4·P5 는 원리적으로 A 귀속이 불가능하다. `real_2ref` 는 preview 가 보드와 완전히 다른 장소(지중해 정원)라
누수 귀속이 깨끗했지만, **여기서는 깨끗한 축이 P1·P2·P6·P7·P8 뿐**이다. 판정은 그 5개로 한다.

## 예측 — G-time (오너가 지목한 핵심 질문)

§3.3 에서 도출한 모형은 **"조명을 더 명시적으로 말한 *채널*이 이긴다"** 이고, 앵커 이미지는
그 경쟁에서 **항상 졌다**(T cafe 창 Y 10.37% = 주광 유지, T noon Y 22.20% = 룩 소멸).

preview 도 **이미지**다. 그러므로:

> **예측 A-1: A 는 G-time 에서 B 가 아니라 T 처럼 행동한다.**
> 즉 A cafe 의 창은 주광을 유지하고(Y ≫ 3%), B cafe(2.91%)처럼 붕괴하지 않는다.
> **기각 조건**: A cafe 창 Y 가 5% 미만으로 떨어지면 예측 기각 — 그 경우
> "이미지는 텍스트에 진다"가 아니라 "레퍼런스 *장수*가 권위를 만든다"로 모형을 고쳐야 한다.

> **예측 A-2: A 는 색 축에서 preview 쪽으로 끌린다** (플레이북 §7 횡단 규칙 1).
> 구체적으로 T 대비 **b\* 가 내려가고(웜→중립·냉), C\* 가 내려간다**. preview 가 T 보다 차갑고 옅으므로.
> **기각 조건**: A 의 b\*·C\* 가 T 대비 preview 반대쪽으로 움직임.

> **예측 A-3: A 는 clash 를 못 올린다.** preview 의 clash(6.22)가 보드(9.31)보다 **낮기** 때문이다.
> B 는 clash 를 올렸지만(7.04→8.91) A 는 내리거나 유지할 것이다.
> **기각 조건**: A 평균 clash 가 T(7.04)보다 1.5 이상 상승.

세 예측이 다 맞으면 결론은 **"A 는 T 를 이기지 못하고, B 와도 다른 방식으로 실패한다"** 가 된다.

3. 산출물이 그 요소를 **재생산**하는가.
