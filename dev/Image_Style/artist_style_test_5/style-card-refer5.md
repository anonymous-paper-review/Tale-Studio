## 6. 발견

1. **콘텐츠 색 지시 > 스타일 팔레트**: 표준 프로브의 색 지정(teal 헤어·mustard 코트·mint 스쿠터·red 신발)이 스타일의 블루 모노크롬을 **부분 오버라이드** — 선·형태·구도 문법은 유지된 채 채움색만 다색화. refer1 ABCE의 "명시적 팔레트 텍스트가 보드 팔레트를 이김"의 콘텐츠판. **프로덕션 함의: 모노크롬 순수성이 필요한 스타일은 콘텐츠 색 지시를 제거하거나 "strict monochrome" 강제 절을 스타일 레이어에 넣어야 함** (파라미터화 후보).
2. **무인물 원작의 인물 외삽 성립**: 방언 절을 스타일 문법에서 외삽(+2-ref 절은 장면용으로 대체)해도 인물 프로브가 스타일 정합 — 단 이 방언은 실측이 아니므로 반복 안정성 미보증.
3. **촬영 캐스트 정규화 성립**: 화면 촬영 원본이라도 "no gray photographic cast/moiré" 명시 + hex 보정 추정으로 클린 벡터 재현 — 유저 업로드가 촬영본인 프로덕션 시나리오에 유효.
4. 아이소메트릭 투영이 전 프로브(정면 포트레이트 지시 제외)에서 유지 — 투영 자체가 스타일 층으로 전이됨.
