# 캐릭터 facet 템플릿 작성 가이드 (v0, 2026-09-07)

캐릭터 facet 템플릿 = 특정 캐릭터 한 명의 값을 **변동성 순서**로 기록하는 조립도. 스타일 템플릿(`facet-template-v1.jsonc`)이 "이 그림체가 무엇이든 어떻게 그리는가"를 담는다면, 이 템플릿은 "이 캐릭터가 누구이고, 몸이 어떻고, 무엇을 입었고, 지금 무엇을 하며, 어디에 있는가"를 담는다. 캐릭터는 그림에서 정보 밀도가 가장 높은 개체이므로 별도 파일로 둔다(오너 결정 2026-09-07, 조사 원문 `dev/Image_Style/facet_character/OWNER_NOTES.md`).

## 1. 목적과 위치

- 최종 목적은 스타일 템플릿과 같다 — 채워진 템플릿만으로 그림을 다시 그렸을 때 원본과 같은 그림. 스타일 템플릿의 1차 목표(스타일 재현)가 진행되는 동안, 캐릭터 템플릿은 그 다음 단계(내용 재현)의 골격을 미리 준비한다. 사이클 검증은 아직 돌리지 않았다(v0 = 조사 초안).
- **같은 캐릭터를 다른 장면에 재현**할 때 어느 층을 고정하고 어느 층을 바꿀지가 계층 순서 그대로다: 정체성(불변) → 신체(준불변) → 외장(교체 가능) → 상태(순간) → 국소 렌더링(스타일 오버라이드) → 배치 → 관계.

## 3. 계층 (변동성 순서)

| 층 | 최상위 key | 변동성 | 내용 |
|---|---|---|---|
| A | `정체성` | 불변 | 존재 유형 · 인간형 정도 · 외견 성별 표현 · 외견 연령대 · 원형·역할(번들: 역할 범주 + 원형 이름 + 번들 함축 + 세계관 계열) · 고유 식별(출처 구분 + 시그니처 요소) · 종족 파츠 유무·목록 |
| B | `신체` | 준불변 | 비율·체형(등신·데포르메 등급·체형 10단·어깨/허리/골반·가슴·목·기준 신장·상대 키) · 얼굴(얼굴형 7분류·비율·눈{형태 4축·홍채·동공·하이라이트·속눈썹·눈썹·눈 밑·묘사 수준}·코·입·귀·표식·피부) · 머리카락(길이·색·형태·질감·렌더링) · 파츠·표식(비인간 파츠 반복 구조·손·문양·체모·결손/대체) |
| C | `외장` | 준불변(교체 가능) | 의상(레이어별 아이템 반복 구조 + 세트 번들) · 액세서리(위치별) · 소지품·장비 · 착탈 표식(화장·네일·붕대) |
| D | `상태` | 가변 | 포즈(자세·몸통·머리·시선·팔·다리·동세·무게 중심·키포인트 세미 정량) · 표정(감정·강도·부위별·만화 기호·FACS 참조) · 동작(동사+대상·단계·모션 표현) · 물리·생리 상태 |
| E | `국소 렌더링` | 가변 | 이 캐릭터에서만 전역 스타일을 덮어쓰는 값(윤곽·셰이딩·디테일 밀도·이펙트). 기본값은 전부 "스타일 기본값 따름" |
| F | `배치` | 가변 | 위치·앵커·크기·프레이밍·깊이층·z-order·가려짐 |
| G | `관계` | 가변 | 다른 개체와의 공간·접촉·주의·상대 크기·상호작용 |

## 4. 메타 태그 (모든 리프 주석 맨 앞, 고정 형식 `[변동성:…][기여도:…]`)

**변동성** — "같은 캐릭터를 다른 장면에 그릴 때 이 값이 바뀌는가".

| 등급 | 정의 | 판정 근거 |
|---|---|---|
| 불변 | 바뀌면 다른 캐릭터로 읽히거나, 바뀐 것 자체가 예외로 표기되는 값 (A 전부, B 대부분) | 태그 커뮤니티가 `alternate_species / alternate_hair_color / alternate_eye_color / alternate_skin_color / alternate_hair_length / genderswap / aged_up·down` 같은 '캐논 이탈' 태그를 두는 속성 |
| 준불변 | 캐릭터에 귀속되지만 장면 단위로 교체돼도 같은 캐릭터로 읽히는 값 (C 전부, 머리 묶음 방식, 체형 세부) | `alternate_costume / alternate_hairstyle / alternate_headwear / alternate_weapon`, 코스프레 규칙(입은 캐릭터의 정체성 유지) |
| 가변 | 장면마다 당연히 바뀌며 표기 대상이 아닌 값 (D·E·F·G) | 포즈·표정·배치에는 이탈 태그가 없음 |

캐릭터 정의(캐릭터 카드) = 불변 + 준불변. 장면 재현 = 카드에서 불변·준불변 복사, 가변은 장면 지시로 새로 채움. 의상 교체 장면 = 불변 복사 + 준불변 중 C만 교체. 경계 사례: 머리 길이는 불변, 묶음 방식은 준불변. 종족 파츠는 불변, 변신은 가변(D4). 원형 이름은 불변(사복을 입어도 '기사'), 원형이 함축하는 의상 세트는 준불변.

**기여도** — "이 리프가 빠지거나 틀렸을 때 '같은 캐릭터'로 인식될 확률이 얼마나 떨어지는가".

| 등급 | 정의 | 예 |
|---|---|---|
| 상 | 틀리면 다른 캐릭터로 보이거나, 없으면 생성기가 기본값으로 되돌려 실루엣·얼굴 틀이 깨지는 골격 facet | 머리 색·형태, 눈 색·형태, 등신·체형·의상 실루엣(번들), 존재 유형·성별·연령대, 종족 파츠 목록, 시그니처 액세서리 |
| 중 | 틀리면 '어딘가 다르다'지만 같은 캐릭터로 읽힘 | 피부색(애니풍에서 변별력 낮음, 이색 피부는 상으로 승격), 세부 얼굴 비율, 의상 디테일·무늬·재질, 상위 범주(역할 범주·세계관·종족 명칭) |
| 하 | 인식에 거의 기여하지 않음 | 관계 문서·규칙 플래그·자유 관찰, D~G 대부분(장면 정보로는 중요하나 '같은 캐릭터' 판정과 무관) |

근거: 오너 우선순위(머리 > 눈 > 실루엣 > 액세서리 > 피부색 > 나머지) · 캐릭터 검색 DB의 식별 facet(성별·눈 색·머리 색·머리 길이·나이·동물귀) · 만화 얼굴 인식 연구의 특징(피부색·머리색·머리 양) · 스타일 템플릿 사이클 1 교훈(지시가 없으면 생성기가 평균값으로 회귀). 승격·강등: 태그는 템플릿의 기본 등급이고, 캐릭터별 조정은 값 태그를 바꾸지 않고 `정체성.고유 식별.시그니처 요소`에 그 리프를 올리는 것으로 한다 — 시그니처에 오른 리프는 등급과 무관하게 '상'.

**기여도 축의 범위**: 기여도는 '같은 캐릭터로 인식되는가'만 잰다. 그래서 D~G(포즈·표정·배치·관계)는 거의 전부 '하'가 되는데, 이것은 장면 재현에서 덜 중요하다는 뜻이 아니다 — 아래 삭감 순서 ①이 가변층을 카드 예산 밖(장면 예산)으로 빼는 이유다. 장면 재현 기여도를 별도 축으로 둘지는 사이클 검증 뒤 오너가 정한다(E·F·G 조사 노트 제안 ⑳).

**프롬프트 예산이 빠듯할 때 버리는 순서**: ① 가변층(D~G)은 캐릭터 카드 예산에 넣지 않는다(장면 예산에서 관리) ② 카드 안에서는 하 → 중 → 상, 같은 등급에서는 긴 자유 서술 → 선택형 값 순 ③ 번들이 있으면 하위 개별 리프부터 버리고 번들 이름만 남긴다(단 번들 통념과 다른 값은 번들보다 먼저 살린다) ④ 시그니처 요소에 오른 리프는 마지막까지 남긴다 ⑤ 골격 facet(존재 유형·성별·연령대·등신)은 1~2 토큰이므로 절대 버리지 않는다 ⑥ 삭감은 삭제이지 요약이 아니다 — 요약은 값을 평균화한다 ⑦ 최소 카드: 존재 유형 · 성별 · 연령대 · 등신 · 머리 색+형태 · 눈 색 · 원형 이름 · 종족 파츠 목록 · 시그니처 상위 3.

## 5. 작성 규칙 (스타일 가이드 §4와 같음 + 3항)

1~7. 스타일 템플릿 가이드 §4의 주석 필수 · 주석 형식 · 선택형 표기 · 선택형 허용 조건 · 후보 밖 값 · 값 규칙 · 계층 규칙을 그대로 따른다.
8. **선택형의 근거는 외부 어휘로 닫는다.** 스타일 템플릿은 우리 실측(refer1~6)으로 후보를 닫았지만, 캐릭터 템플릿은 실측 표본이 없으므로 외부 분류 체계를 근거로 쓴다 — 태그 커뮤니티의 태그 그룹(머리·눈·얼굴·몸·의상·자세·제스처·표정), 포즈 키포인트(OpenPose 18/25, COCO 17), 표정 액션 유닛(FACS), 의상 어트리뷰트(DeepFashion 5범주·DeepFashion2 13카테고리), 신체 부위 분할(LIP 20 라벨), 영화 샷 사이즈. 주석의 `분석 근거:`에 출처를 적고, 출처가 스니펫만 확인된 것은 조사 노트 §미검증에 남긴다. 수백 개짜리 어휘는 상위 범주만 선택형(후보 3~12개)으로, 세부는 자유 서술 + 참고 후보.
9. **가지마다 `기타` 리프 하나.** 후보에 없는 관찰을 적는 자유 텍스트 탈출구. 여기 적힌 값이 반복되면 후보 갱신(버전업) 대상이다.
10. **고유명사 금지는 캐릭터 이름에도 적용된다.** `고유 식별`은 이름이 아니라 출처 구분(기존/오리지널/판독 불가)과 시그니처 요소(다른 리프 경로 3~5개)로 표현한다. 태그 이름은 어휘로서 영문 인용 가능하되 특정 작품 전용 태그는 쓰지 않는다.
11. **반복 구조.** 의상 레이어·액세서리 위치·비인간 파츠처럼 같은 속성 묶음이 여러 번 나오는 곳은 한 번 정의한 구조를 복제한다. 예시 캐릭터에 없는 슬롯은 `[해당 없음]`.

## 6. 스타일 템플릿과의 경계

- 스타일 템플릿 `인물` 가지 = 이 스타일의 **모든** 캐릭터에 공통인 값(눈을 점으로 그리는가, 선 위계, 셀 단계, 스타일 기본 등신). 캐릭터 템플릿 = 특정 캐릭터에 고유한 값.
- 같은 이름의 속성이 양쪽에 있으면 캐릭터 값은 `"스타일 기본값 따름"`을 쓸 수 있고, 주석에 스타일 경로를 적는다. 스타일이 이기는 축(코·입 표현, 피부 톤 표현, 머리카락 렌더링 방식, 눈 묘사 수준)은 기본이 "따름"이고 캐릭터 고유 과장이 있을 때만 오버라이드한다. 콘텐츠가 이기는 축(홍채 색, 피부 hex, 종족 파츠, 금속·비늘 피부 재질)은 캐릭터 값이 우선하며 스타일 템플릿에 두지 않는다(콘텐츠 누출 경로).
- 뜻이 다른 동명 항목: 캐릭터 `인간형 정도`(존재가 무얼굴인가) vs 스타일 `인물.무얼굴 여부`(스타일이 얼굴을 생략하는가) — 캐릭터 '완전 인간형' + 스타일 '무얼굴 예'가 공존할 수 있다.
- 계층별 경계 표는 각 조각의 조사 노트 §경계에 있다.

## 7. 프롬프트 사용법 (초안)

- **캐릭터 카드** = A + B + C(불변·준불변)를 §4의 순서로 압축한 것. 스타일 캡슐 뒤, 장면 지시 앞에 온다.
- **장면 지시** = D + F + G(가변). E는 스타일 캡슐에 대한 예외 절로 붙는다("this character only: …").
- 컴파일 규칙(값 → 영문 토큰, 예산 절단, 번들 전개)은 사이클 검증 뒤에 스타일 가이드 §6과 같은 형식으로 쓴다. v0에서는 정의하지 않는다.
