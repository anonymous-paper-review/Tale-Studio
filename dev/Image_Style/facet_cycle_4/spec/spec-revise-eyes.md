# 작업: 눈 값 재측정 (filled.jsonc — 규약 보완 v1.2.1)

당신이 채운 이 폴더의 `filled.jsonc`에서 표본 개체(오른쪽 인물, 얼굴 82px)의 눈이 감겨 있어 눈 값이 닫힌 눈 기준으로 채워졌다(눈 요소 1, "닫힌 눈은 공막·글린트 없음"). 규약 보완: **표본 개체의 눈이 감겨 있으면 눈 값만 화면에서 가장 큰 열린 눈에서 센다.** 첨부 이미지(<IMAGE>)를 다시 보고 아래만 고쳐라.

- `디테일.묘사 밀도.실측 개수`의 ⑤ 눈 요소 — 가장 큰 **열린** 눈(어느 인물인지, 눈 폭 px를 지목)에서 홍채 톤 + 동공 + 광점 + 속눈썹 가닥 + 눈꺼풀 선을 센 값으로 바꾼다. 판독 한계(눈 폭 ≈ 17px, 2px 선·3px 점)는 그대로 — 보이는 것만 센다. 등급은 기준별 문턱(눈 요소 ≤3 → 2, 4~6 → 3)과 중앙값 규칙으로 다시 계산한다(다른 기준이 그대로면 대개 유지된다).
- `인물.눈` 가지 전체(크기·처리·눈매·속눈썹·눈꺼풀 선·공막·글린트·눈썹 투과·디테일) — 열린 눈 표본 기준으로 다시 적는다. 감은 눈의 처리(굵은 곡선 등)는 `인물.표정 기본값`에 표정 분포와 함께 적는다.
- `인물.표정 기본값` — 5명의 표정을 세어 분포로 적는다(예: 감은 눈 미소 2, 열린 눈 미소 2, 놀람 1).

다른 값·키·주석은 손대지 않는다. `proposals.md`·`scene_summary.md`는 그대로. 다른 파일을 만들지 마라. 고유명사 금지. 최종 메시지에 고친 key 경로와 새 값의 목록만 붙여라.
