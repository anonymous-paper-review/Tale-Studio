# 사이클 4(Claude) — <REF>

## 1. 프로브 점수
표: 프로브(캐릭터/카페/스쿠터/액션) × 5축(스타일 충실도 / 콘텐츠 중립성 / 재질 분리 / 구조 안정성 / 독립성, 0~5) + 묘사 밀도(과소/일치/과잉 — 원작 표본 개체 대비 생성물 개체의 내부선·가닥선·장식 개수 배수를 근거로, 예: "과잉 ×2.5 — 가닥 12 vs 원작 4") + 정체성 누출(없음/경미/뚜렷 — 무엇이 복제됐는지 구체적으로) + 한 줄 근거. 마지막 행에 충실도 평균, 묘사 밀도 집계(과소/일치/과잉 개수), 누출 집계. 캡슐이 스타일 어휘로 선언한 요소의 등장은 누출로 세지 않되, 원작의 배치 관용구까지 겹치면 경미로 표시한다.

## 2. T 장면 (템플릿만)
축별 일치도 표(매체 · 선 · 채움 · 명암/그림자 · 색 · 형태 · 정밀도 · 질감/마감 · 조명 · 투영/시점 · 배경/지면 · 장식 · 디테일 밀도 · 인물 방언, 0~5). 사이클 3 T 장면이 주어졌으면 같은 표에 열을 추가하고 해소/완화/잔존/악화/신규를 표시한다. '디테일 밀도' 행에는 원작 대비 배수(내부선·가닥·장식)를 적는다.

## 3. 잔차 목록
프로브와 T 장면에서 원작 스타일과 다른 점을 중요도 순으로 최소 8개, 그중 묘사 밀도(과잉·과소) 항목 최소 2개. 한 항목당 한 줄: `- [축] 원본: … / 프로브: … / T: … → 원인 (a|b|c|d|e|f): 근거 — 관련 key: 경로`. 원인: (a) 템플릿에 key 없음 · (b) 채워진 값이 틀림 · (c) 값은 맞는데 프롬프트에 안 실림 · (d) 프롬프트에 있는데 생성기가 무시 · (e) 참조 이미지가 원작 스타일을 프로브로 나르지 못함 · (f) 추측 허용 규약이 관찰을 막음(규약이 '없음'으로 적게 했지만 원작에 실제로 있는 것). filled.json·prompts.md·check.md·gen/*.txt를 실제로 대조해 판정한다.

## 4. 새 facet 제안
(a) 항목마다 가지 경로 · key 이름 · 값 · 주석 초안(여러 문장). (f) 항목은 규약의 어느 조항(12~18)이 문제인지와 고칠 문장을 적는다.

## 5. 총평
프로브(원작 참조)와 T(템플릿만) 중 어느 쪽이 원작 스타일에 가깝고 왜인지 2문장, 누출 위험 판정 1문장, 이 원작의 상위 3축, 묘사 예산 절("Detail budget")과 정교화 부정 절이 생성물에 실제로 작동한 흔적이 있는지 1문장, 사이클 3 T 장면 대비 정교화가 줄었는지(원작 대비 배수 비교) 1문장.
