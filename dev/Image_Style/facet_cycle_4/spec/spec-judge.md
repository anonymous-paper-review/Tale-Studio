# 작업: 사이클 4 판정 — <REF> (템플릿 v1.2 추측 허용 규약)

첨부 이미지: (1) 원작, (2)~(5) 프로브 4장 — 캐릭터·카페·스쿠터·액션. 참조 `[원작]` 하나 + 압축 캡슐(PROBE_ANCHORS) + 장면 절(+ 인물 절) + 부정 절로 생성, (6) T 장면 — 원작을 보지 않고 채워진 템플릿(v1.2)만으로 컴파일한 프롬프트로 그린 같은 종류의 장면(무참조)<PREV>. 이 폴더의 `filled.json`·`prompts.md`·`check.md`·`gen/*.txt`를 읽고 `residuals.md`를 쓴다. 고유명사 금지(원작이 무엇인지 알아도 시각 속성만). 다른 파일 수정 금지, 외부 검색 금지. 최종 메시지에 `residuals.md` 전문.

사이클 4의 초점: 사이클 3에서 단순한 원작(선 몇 개와 소프트 그라디언트)이 "그 장르의 보통 그림"으로 정교화돼 재현에 실패했다. v1.2는 채우기에 **추측 허용 규약**(판독 한계 · 표본 개체를 실제로 센 묘사 밀도 등급 · 세지 않은 범위 금지 · 장르 선험 금지 · 단순성 편향)을, 컴파일에 **묘사 예산 절**("Detail budget: …")과 **정교화 부정 절**을 넣었다. 판정의 첫 질문은 "생성물이 원작보다 정교한가, 성긴가, 같은가"다.

## residuals.md 형식

# 사이클 4 — <REF>

## 1. 프로브 점수
표: 프로브 × 5축(스타일 충실도 / 콘텐츠 중립성 / 재질 분리 / 구조 안정성 / 독립성, 0~5) + **묘사 밀도**(과소/일치/과잉 — 원작 표본 개체 대비 생성물 개체의 내부선·가닥선·장식 개수 배수를 근거로, 예: "과잉 ×2.5 — 가닥 12 vs 원작 4") + 정체성 누출(없음/경미/뚜렷 — 무엇이 복제됐는지 구체적으로) + 한 줄 근거. 마지막 행에 충실도 평균, 묘사 밀도 집계, 누출 집계.

## 2. T 장면 (템플릿만)
축별 일치도 표(매체 · 선 · 채움 · 명암/그림자 · 색 · 형태 · 정밀도 · 질감/마감 · 조명 · 투영/시점 · 배경/지면 · 장식 · 디테일 밀도 · 인물 방언, 0~5). 사이클 3 T 장면(7)이 있으면 같은 표에 열을 추가하고 해소/완화/잔존/악화/신규를 표시한다. '디테일 밀도' 행에는 원작 대비 배수(내부선·가닥·장식)를 적는다.

## 3. 잔차 목록
프로브와 T 장면에서 원작 스타일과 다른 점을 중요도 순으로 최소 8개, 그중 **묘사 밀도(과잉·과소) 항목 최소 2개**. `- [축] 원본: … / 프로브: … / T: … → 원인 (a|b|c|d|e|f): 근거 — 관련 key: 경로`. 원인: (a) 템플릿에 key 없음 · (b) 채워진 값이 틀림 · (c) 값은 맞는데 프롬프트에 안 실림 · (d) 프롬프트에 있는데 생성기가 무시 · (e) 참조 이미지가 원작 스타일을 프로브로 나르지 못함 · **(f) 추측 허용 규약이 관찰을 막음(규약이 '없음'으로 적게 했지만 원작에 실제로 있는 것)**. filled.json·prompts.md·check.md·gen/*.txt를 실제로 대조해 판정한다.

## 4. 새 facet 제안
(a) 항목마다 가지 경로 · key · 값 · 주석 초안. (f) 항목은 규약의 어느 조항이 문제인지 적는다.

## 5. 총평
프로브(원작 참조)와 T(템플릿만) 중 어느 쪽이 원작 스타일에 가깝고 왜인지, 누출 위험, 이 원작의 상위 3축, **묘사 예산 절("Detail budget")과 정교화 부정 절이 생성물에 작동한 흔적이 있는지 1문장**, 사이클 3 T 장면 대비 정교화가 줄었는지 1문장.
