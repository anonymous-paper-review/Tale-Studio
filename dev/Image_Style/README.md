## 6. 핵심 발견 (프로덕션 설계 직결)

1. **텍스트 방언 절이 인물 스타일 전이의 결정 변수** (58→79점). 이미지 레퍼런스만으로는 비율·이목구비가 안 넘어옴 → Style Card에 방언 절을 **저장**하고 캐릭터 생성 시 주입해야 함
2. **보드 팔레트는 기본값, 명시적 팔레트 텍스트가 이김** → 팔레트를 스타일과 분리된 유저 파라미터로 노출 가능 (v2 "톤은 modifier" 원칙의 실증)
3. **보드의 구체적 생김새(기하·팔레트 인스턴스)가 다운스트림 룩을 결정** → 보드 선별(4~6장 중 1장) = 룩 결정 행위. 스타일당 보드 2종(표준/각진 판)을 룩 옵션으로 제시 가능
4. **모델은 무지시 시 대칭·균일선·균등배치 기본값으로 회귀** → 비대칭/선 위계는 명시 절 필수 (E′)
5. **IP 고유명사는 부정문이어도 nsfw 거부** (higgsfield/GPT Image) → 분석 출력은 중립 서술어+hex만
6. **모작 가드**: 단일 원작 정합 튜닝은 금지, 단 장식 시스템을 구조 문법으로 추출해 팔레트 교체하면 스타일 층으로 복권 가능 (ABCD 폐기 → ABCDE 복권 사례)
7. 무인물 장면에 방언 텍스트를 넣어도 인물 소환은 안 되나(콘텐츠 락이 이김) 효과도 없음 → 생략이 정답
8. 원작 팔레트 일부는 브랜드 결합 요소라 중립 추출에서 자연 탈락 (refer2 크림슨→웜앰버) → 필요 시 팔레트 텍스트로 후행 복원
9. **분석 스캐폴드의 구조가 VLM 분석 품질을 결정** (실험 7: 분석자 고정 시 2.9→4.5). 축 하나(입력 아티팩트 분리)의 부재가 파이프라인 전체 실패로 전파 — 자동화에서는 스캐폴드가 분석자의 암묵 판단을 대체하는 필수 장치. 신설 축(색 분배·외삽 규칙)은 선언이 생성까지 전달되는 실행 변수
