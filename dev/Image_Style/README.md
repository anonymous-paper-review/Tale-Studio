## 4. 실험 2 — 작가 스타일 온보딩 (refer1: 플랫 벡터 팝)

파이프라인 6단계: 계산 통계(`style_stats.py`) → 14-facet 분석 → Style Card(캡슐+hex+방언 절) → 중립 보드 I2I 생성 → vision QA → 전이 프로브 4종(캐릭터/카페/스쿠터/액션). 상세: `artist_style_test/style-card-refer1.md`.

### 조건 사다리 (전 조건 산출물 보존, 파일명 = `test_<probe>_<조건>.png`)

| 조건 | 구성 | 인물 점수 | 결론 |
|---|---|---|---|
| T 기준선 | `[표준 보드]` | 3/5 | 장면은 충분, **인물 방언 손실** |
| A | + 원작 2nd ref | 3.5~4/5 | 중립성 최고, 문법 약함 |
| **AB** | + 방언 절 텍스트 | 4.5/5 | **결정적 기여 = B(텍스트)** |
| ABC | A' 마네킹 보드로 교체 | 4.5~5/5 | C = 룩 변조기 (각지고 절제된 판) |
| ~~ABCD~~ | 원본 정합 미세튜닝 | 폐기 | **모작 과적합** — 중립성 위반 |
| ABCE | + Neutral 절제·팔레트 교체·콘텐츠 제거 | 83~86/95 | 중립성 최고, 톤 8/10로 순화 |
| ABCDE | + D 무대 문법을 E 팔레트로 일반화 | ≈88/95 | **톤 10/10 회복** |
| +E′ | + 구조물 비대칭·선 3단계·불균일 산포 | A/B 전 축 개선 | **최종 정본 레시피** |

### 확정 레시피 (프로덕션 이식 대상)

- **배경/사물/공간** = `[보드, 원작 Core 1장]` + 장면용 2-ref 절 (방언 텍스트 생략 — 무효과 실측)
- **캐릭터/인물 샷** = `[보드, 원작 Core 1장]` + 인물용 2-ref 절 + **Style Card의 방언 절**
- E′ 3절(비대칭·선 위계·불균일 산포)은 해당 특성이 있는 스타일에서 기본 포함
- 정체성 누수 게이트(원작 캐릭터 비유사 vision 판정) 필수

## 6. 핵심 발견 (프로덕션 설계 직결)

1. **텍스트 방언 절이 인물 스타일 전이의 결정 변수** (58→79점). 이미지 레퍼런스만으로는 비율·이목구비가 안 넘어옴 → Style Card에 방언 절을 **저장**하고 캐릭터 생성 시 주입해야 함
2. **보드 팔레트는 기본값, 명시적 팔레트 텍스트가 이김** → 팔레트를 스타일과 분리된 유저 파라미터로 노출 가능 (v2 "톤은 modifier" 원칙의 실증)
3. **보드의 구체적 생김새(기하·팔레트 인스턴스)가 다운스트림 룩을 결정** → 보드 선별(4~6장 중 1장) = 룩 결정 행위. 스타일당 보드 2종(표준/각진 판)을 룩 옵션으로 제시 가능
4. **모델은 무지시 시 대칭·균일선·균등배치 기본값으로 회귀** → 비대칭/선 위계는 명시 절 필수 (E′)
5. **IP 고유명사는 부정문이어도 nsfw 거부** (higgsfield/GPT Image) → 분석 출력은 중립 서술어+hex만
6. **모작 가드**: 단일 원작 정합 튜닝은 금지, 단 장식 시스템을 구조 문법으로 추출해 팔레트 교체하면 스타일 층으로 복권 가능 (ABCD 폐기 → ABCDE 복권 사례)
7. 무인물 장면에 방언 텍스트를 넣어도 인물 소환은 안 되나(콘텐츠 락이 이김) 효과도 없음 → 생략이 정답
8. 원작 팔레트 일부는 브랜드 결합 요소라 중립 추출에서 자연 탈락 (refer2 크림슨→웜앰버) → 필요 시 팔레트 텍스트로 후행 복원
