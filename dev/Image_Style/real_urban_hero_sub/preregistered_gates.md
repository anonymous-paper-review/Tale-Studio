## A. 룩 서명 — 상한 비교자 = preview

preview `previews/real_urban_hero.jpg` 를 육안 + 계측으로 읽어 확정한 **도심 히어로 서명 6항**.
G-look 은 이 목록 중 몇 개가 산출물에 나타나는지로 채점한다.

| # | 서명 | preview 에서의 근거 |
|---|---|---|
| **L1** | **넓은 동적 범위** — 밝은 하늘/하이라이트와 어두운 잔해가 한 프레임에 공존, 그림자가 검게 뭉치지 않음 | 밝은 청회색 하늘 + 어두운 파편·그림자에 디테일 유지 |
| **L2** | **고채도 순색 악센트 × 저채도 회색 지반** — 코발트·에메랄드·앰버·바이올렛이 콘크리트/아스팔트 위에 얹힘 | 5인 코스튬 원색 vs 회색 폐허 |
| **L3** | **혼합 색광** — 서로 다른 색온도의 광원이 한 프레임에 (주광 + 화염 오렌지 + 에너지 시안/보라) | 폭발 오렌지 + 시안 건틀릿 + 보라 에너지 |
| **L4** | **크리스프 마이크로 콘트라스트 / HDR 클래리티** — 표면 질감이 또렷, 소프트 포커스 없음 | 강엣지 20.0%, 플랫 블록 4% |
| **L5** | **젖은/반사 지면** — 노면이 빛을 되쏘아 프레임 아래쪽에 두 번째 광원처럼 작동 | 젖은 아스팔트의 반사 |
| **L6** | **모뉴멘털 도시 스케일** — 광각·낮은 카메라, 수직 구조물이 프레임을 압도 | 24mm 로우앵글, 마천루 |

### A-1. L1~L6 의 수치 프록시 (산출물 열람 전 확정)

| 서명 | 계기 | 읽는 법 |

## D. 게이트 정의 (오너 지정 4종)

- **G-look** — 도심 히어로 시그니처(고대비·시네마틱 도시광·스케일감)가 나오는가. L1~L6 중 **3개 이상**이면 통과.
- **G-time** — 각 프로브가 **자기 시간대**를 유지하는가 (cafe=late afternoon / scooter·action=night / character=시간대 무언급).
- **G-skeleton** — B 목록(C1~C8) 침투 여부. 0건이면 통과.
- **G-figure** — 인물이 자연스러운가 + C 목록(P1~P5) 침투 여부. 히어로 복장이 새면 **침투로 기록**.

## E. 설계 (payload 동일, refs 동일 — 텍스트 1절만 다름)

| | T | B |
|---|---|---|
| refs | 보드 1장 | 보드 1장 (동일) |
| 절 | 표준 헤더만 | 표준 헤더 + **룩 절(자기완결형)** |
| 콘텐츠 | `real_3d_v2/probe_*.txt` **md5 동일본** | **동일 문장** (diff 확인) |
| 장수 | 4 | 4 |

**의도적으로 넣지 않은 것**: ① 룩 절에 시간대 보호문("keep the scene's own time of day") 없음 —
넣으면 G-time 을 못 잰다. ② 장르 명사(히어로·케이프·초능력) 없음 — 룩 절은 **촬영·그레이드 어휘만**으로
썼다. "blockbuster" 는 제작 규모 레지스터이지 내용 명사가 아니라는 판단. 이 선택 자체가 C 목록의 측정 대상이다.
