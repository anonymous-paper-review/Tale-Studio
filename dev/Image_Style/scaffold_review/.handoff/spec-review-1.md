# 리뷰 과제: 그림체 분석 스캐폴드 v2 → v3 — 누락 facet 발굴 + 계층화

당신은 이미지 스타일 분석 파이프라인의 **리뷰어**다. 목표는 현행 스캐폴드 v2(`inputs/scaffold-v2.md`)를 비판적으로 검토해 (1) 빠져 있거나 한 줄에 뭉개져 암묵적으로만 다뤄지는 스타일 축을 **증거와 함께** 발굴하고, (2) 전체 축을 파이프라인 기능 기준으로 **계층화**한 제안서를 이 폴더에 `review.md`로 쓰는 것이다. 최종 메시지에도 그 전문을 붙여라.

## 맥락 (반드시 읽을 것 — 전부 `inputs/`에 있음)

- `scaffold-v2.md` — 현행 v2 (원문 14 facet 복원 + 신설 축 ⑮⑯⑰ + E′ 기본 절)
- `scaffold-orig.md` — v2의 원천인 원문 워크플로 4~7단계 (549줄)
- `comparison.md` — v2 vs 원문 스캐폴드 A/B 실측. 분석자는 당신의 이전 세션 2개였다. 핵심: 축 하나(입력 아티팩트 분리)의 부재가 보드와 프로브 전부의 실패로 전파됨 / 신설 축(색 분배·외삽 규칙)은 선언이 생성 결과까지 전달됨 / 잔여 격차 = 배경 정규화 판단(순백 vs 틴트)·E′ 조건부 절의 무조건 적용
- `analysis-refer5-orig.md`, `analysis-refer5-v2.md` — 그 A/B의 두 분석 산출물 (무엇이 달랐는지 직접 비교 가능)
- `style-card-refer1.md`, `-refer2.md`, `-refer3.md`, `-refer5.md`, `-refer6.md` — 5개 스타일의 실행 기록. 각 카드의 **"발견" 절**이 가장 중요한 증거다
- `README.md` — 실험 전체 인덱스. §6 핵심 발견 9건과 §9 잔여 항목을 읽어라
- **첨부 이미지 5장** (순서대로): refer1 = 플랫 벡터 팝 / refer2 = 세미 페인터리 키아트 / refer3 = 스톱모션 퍼펫 실사진 / refer5 = 아이소메트릭 라인아트(화면 촬영본) / refer6 = 아이소메트릭 무선 플랫 면분할(화면 촬영본)

파이프라인 구조 — 분석 결과가 어디로 가는지가 **계층화의 기준**이다:

| 출력 슬롯 | 내용 |
|---|---|
| 앵커 보드 캡슐 `{RENDERING_RULES}` | 영문 2~4문장, 중립 정물 보드 I2I 생성 프롬프트 |
| 인물 방언 절 `Figure rules:` | 인물 프로브 텍스트 보강 |
| 장면/인물 2-ref 절 | 고정 문구 (원작을 2번째 ref로 물릴 때의 역할 지시) |
| 부정 절 | **현재 슬롯 없음** — "이 스타일이 아닌 것" |
| QA 게이트 | 보드 facet 대조 ①~④, 정체성·모티프 누수 게이트 |
| Style Vector | 0~5 수치 12축, 스타일 간 비교용 |
| 프로덕션 파라미터 후보 | 팔레트 오버라이드, 강도, 룩 옵션(보드 2종) 등 유저 노출 가능 변수 |

## 해야 할 것

**A. 누락/암묵 축 발굴.** 5장 이미지와 5개 카드를 대조해, v2 체크리스트로는 잡히지 않거나 한 줄에 뭉개진 스타일 속성을 찾아라. 후보마다 반드시: ① 근거(어느 이미지·카드의 무엇), ② v2가 못 잡는 이유, ③ **생성 결과를 실제로 바꾸는가**(바꾸지 않으면 탈락 — comparison.md가 보여주듯 축은 실행 변수여야 한다), ④ 들어갈 출력 슬롯, ⑤ 계산 측정 가능성. 특히 의심할 영역: 배경/지면 처리와 정규화 규칙 · 그림자 시스템(캐스트 섀도 유무·형태·색) · 채움 규칙(선과 면의 관계, 선택적 채움 논리) · 장식 모티프 시스템(어휘·산포 리듬·전경 통과) · 스케일 의존 디테일(작은 인물/소품의 LOD) · 재질 사전의 누락 재질(피부·헤어·액체·발광체·건축 표면) · 부정 절 · 캡처 계층(작품 자체 / 작품의 사진 / 물리 오브젝트의 사진 — refer3와 refer5는 이 점에서 다르다) · facet별 신뢰도 표기(실측/추정/외삽) · 다중 입력 시 커버리지.

**B. 계층화.** 기존 17축 + 채택 후보를 트리로 재편. 각 노드에 (a) 티어와 역할, (b) 결정 순서 의존성(무엇을 먼저 확정해야 하는가), (c) Core-정의 축인지 modifier인지, (d) 출력 슬롯, (e) 측정 접지 가능 여부. 목표: 리프 축 ≤ 25, 각 축 정의 1문장.

**C. 병합·삭제·조건화.** v2에서 겹치는 것(예: 선 vs 가장자리, 질감 vs 디테일 밀도), 앵커에 구우면 안 되는 것(분위기), 조건부여야 할 것(E′ 절 — 어떤 게이트로?)을 지적하고 처리안을 제시.

**D. 채택 후보마다 영문 캡슐 문구 예시 1개** — 생성기에 그대로 들어갈 수 있는 문장 형태로.

**E. 자기 검토.** 추측에 기댄 제안, 근거가 이미지 1장뿐인 제안, 생성 결과 변화가 불확실한 제안을 스스로 표시하라.

## 규칙

- 작가·작품·브랜드 고유명사 금지 (이미지 출처 추측도 금지).
- 근거는 이미지에서 실제로 보이는 것과 카드에 기록된 실측뿐이다. "일반적으로 ~가 중요하다"는 근거가 아니다.
- 산출물은 `review.md` 하나. 다른 파일 수정 금지. 네트워크 금지.
- 분량 200~400줄, 표 위주. 한국어(캡슐 문구 예시만 영문).

## D. 캡슐 문구 예시
## E. 자기 검토
