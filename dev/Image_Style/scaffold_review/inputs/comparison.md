## 4. 발견

1. **스캐폴드 구조가 VLM 분석 품질을 결정한다 (분석자 고정)**: 원문 → 복원판으로 스타일 충실도 **2.9 → 4.5**. 결정 축은 **2-0 입력 아티팩트 분리** — 원문에는 이 축이 없어 촬영 캐스트가 "종이 바탕"으로 채택됐고, 그 오류가 보드와 4장 전부에 전파됐다. 축 하나의 부재가 파이프라인 전체 실패로 이어지는 구조.
2. **원문 스캐폴드의 함정 = "의도된 것인가"를 묻지 않음**: Facet 9(질감)·14(불완전성)가 관찰된 노이즈·블러를 스타일로 흡수하게 유도. 복원판의 "의도된 표면 질감"·"클린이 시그니처면 없음 명시" 문구가 부분 방어했으나 Codex-v2도 불완전성을 Core로 분류 — 생성기가 플랫 지시를 우선해 결과에는 미반영. 방어를 분석 단계에서 완결하려면 Facet 14에 "촬영·압축 흔적은 불완전성이 아니다" 명시 필요.
3. **신설 축은 선언 → 생성 경로를 탄다**: ⑯ 색 분배(액센트 소품 한정)와 ⑰ 야간 외삽 규칙이 캡슐/방언 절을 거쳐 산출물에 그대로 구현됨 — 축이 기록용이 아니라 실행 가능한 제어 변수임을 실증.
4. **잔여 격차(Codex-v2 vs Claude-weak 0.25)**: 바탕 정규화 판단 — 스캐폴드는 "캐스트를 제외하라"고 했지만 "무엇으로 대체할지"는 분석자 판단(Claude=순백, Codex=쿨그레이 절충). 2-0에 **배경 정규화 규칙**("가장 밝은 실측 영역보다 밝은 순색으로 복원, 틴트는 의도 근거 있을 때만") 추가 여지. 액센트 면적 상한도 캡슐에 수치로 박아야 함.
5. **E′ 기본 절 과적용 리스크**: Codex-v2가 조건부 절("비대칭/선 위계를 갖는다면")을 무조건 캡슐에 실음. 이번엔 무해했으나 스타일에 따라 해가 될 수 있음 → Style Vector 불규칙성 ≥3 같은 **게이트로 조건화** 권장.
6. **분석자 vs 스캐폴드**: Claude-weak(약한 스캐폴드+강한 분석자)가 여전히 최고점. 즉 스캐폴드는 분석자의 암묵 판단을 대체하는 장치이고, 자동화(VLM) 시나리오에서 필수 — 8월 판단("4/4 통과는 내 암묵 판단이 메운 것")의 실증.
