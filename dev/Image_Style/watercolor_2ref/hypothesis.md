# 가설 — **생성 결과를 보기 전 작성** (`research/experiments/_HYPOTHESIS.md` 5줄 폼)

## 가설

`watercolor` 앵커 보드는 **인물이 전혀 없는 순수 정물**이다. 이것이 `real_3d` 의 C2 보드(익명 인물 스터디 포함, `anchor-B1` §5.1)와의 **구조적 차이**다. `real_3d` 2-ref 테스트의 핵심 결론은 "이득은 장면 쪽에만 있고 인물은 동등 — 보드가 이미 인물 방언을 나르고 있었으므로"였다. 그 설명이 옳다면 **보드가 인물 방언을 전혀 나르지 않는 이 런에서는 비대칭이 뒤집혀야 한다.**

## 전제

- 보드 = 정물 7요소(창·구체·머그·유리컵·천·화분·사과), 인물 0
- preview = 인물 1 + 동물 2종(검은 고양이·갈매기) + 마을 원경, IP 인접도 높음
- 프로브 콘텐츠·절 payload 는 `real_3d` 와 동일 (변인 통제)

## 예측

1. **인물 축(character·action)에서 A > T 가 이번엔 나타난다.** `real_3d` 는 "동등"이었다. 보드에 인물 정보가 0 이므로 preview 가 유일한 인물 정보원이다.
2. **그 대가로 G1 정체성 누수 위험이 `real_3d` 보다 높다.** 레퍼런스 집합 안의 유일한 인물이 저 소녀 하나뿐이라 "이 스타일의 인물"과 "저 특정 캐릭터"를 가를 대조군이 없다.
3. **장면 축(cafe·scooter)에서도 A > T 가 나오되, 밀도 이득의 상당 부분은 B(텍스트 단독)가 회수한다** — `real_3d` §8 의 축 분해가 매체를 바꿔도 재현되는지가 관전 포인트.
4. **G-grade 는 야간 프로브(scooter·action)에서 위험하다** — preview 가 한낮 고조도이므로 밤이 씻겨나갈 수 있다. `real_3d` 는 반대 방향(석양이 오후를 밀어냄)이었다.

## 측정

- 육안 판정(T vs A 스타일 축) + 게이트 4종(G1 정체성 / G2 동물 / G-content 장소 / G-grade 시간대)
- 계기: `hue_metrics.py` (쿨픽셀 B>R · 명도 · 색상대 4밴드 — **생성 전 캘리브레이션 완료**), `style_stats.py`, `fg_metrics.py`

## 기각 조건

- 예측 1 기각: character·action 에서 A 가 T 대비 인물 조형 개선을 보이지 않으면 → "보드가 인물을 나르는가"는 인물 이득을 설명하는 변수가 아니다. `real_3d` §2.1 의 구조적 설명이 틀렸다는 뜻이 되므로 그쪽 보고서에 되먹임해야 한다.
- 예측 3 기각: B 가 T 에 붙어 있으면 → 밀도 이득이 매체 의존적이며 `real_3d` §8 을 일반화하면 안 된다.
