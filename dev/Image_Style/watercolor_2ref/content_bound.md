# preview Content-bound 목록 — **생성 전 선작성**

대상: `preview_watercolor_raw.jpg` (640×640 JPEG, `style_anchors.preview_url`, key=`watercolor`)
작성 시각: 생성 잡 제출 **이전**. 이 목록에 없는 요소가 산출물에 나오면 사후 추가가 아니라 "목록 밖 누수"로 별도 기록한다.

## 0. 먼저 — 이 preview 는 IP 인접도가 매우 높다

기존 `real_3d` preview(파리 거리 + 의인화 여우)와 성격이 다르다. 이 preview 는 **널리 알려진 애니메이션 장편의 상징적 한 컷과 모티프 단위로 겹친다** — 빗자루를 탄 소녀 + 검은 고양이 + 빨간 머리 리본 + 바다 낀 붉은 기와 마을. 개별 요소가 아니라 **조합 전체가 하나의 식별 가능한 정체성**을 이룬다.

→ 그래서 이 런의 G1 은 `real_3d` 보다 **훨씬 무거운 판정**이다. real_3d 에서 G1 은 "preview 속 여우를 베꼈나"였지만, 여기서는 "**제3자의 저작 캐릭터를 재현했나**"가 된다. 프로덕션에 이 preview 를 물리는 결정은 스타일 품질 문제 이전에 **법무 문제**다. 이 점은 실측 결과와 무관하게 보고서 결론에 명시한다.

## 2. 생물 (G2 — 이 런에서 재정의된 게이트)

`real_3d` 의 G2 는 "의인화(수인화)"였다. 이 preview 에는 의인화 동물이 없다 — 대신 **자연주의 동물이 둘** 있다. 그래서 이 런에서 G2 는 **"부르지 않은 동물의 등장"**으로 바꿔 읽는다. 게이트 개수(4종)와 취지(preview 고유 생물이 콘텐츠를 침범했는가)는 유지된다.

## 4. 그레이드·대기 (G-grade)

| # | 요소 |
|---|---|
| 16 | **한낮 고조도 주광**, 창백한 크림색 하늘 |
| 17 | 원경 대기원근 헤이즈 |
| 18 | **큰 청록 색면**(바다) — 계기상 teal 11.9% / 쿨픽셀 15.6% (보드는 1.0% / 2.5%) |

**프로브별 위험 방향이 다르다:**
- `cafe` = "late afternoon" 실내 → 위험 = 창밖이 한낮 바다·고조도로 열림, teal 상승
- `scooter`·`action` = "at night" → 위험 = **밤이 씻겨나가 명도 상승**. 여기서 쿨/teal 상승은 밤이면 정당하므로 누수 근거로 쓰지 않는다 (`hue_metrics.py` 헤더의 해석 규칙)
- `character` = "plain flat neutral background" → 위험 = 배경이 마을·바다로 채워짐
