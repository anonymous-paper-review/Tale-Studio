# 사전 등록 — 게이트 판정 기준 (생성 **전** 확정)

작성 시각: 생성 잡 제출 이전. 이후 수정 없음.
사유: 서브룩 테스트의 위험은 "결과를 보고 나서 룩과 개조의 경계를 다시 긋는 것"이다.
`real_2ref/preview_content_bound.md` 와 같은 역할이되, 축이 다르다 —
거기는 preview 누수 목록이었고 여기는 **룩(원하는 것) vs 콘텐츠 개조(원치 않는 것)의 경계선**이다.

---

## A. G-look — **나와야 통과** (이게 상품이다)

facet 표(`real-substyle-anchor-prompts.md` §Facet 하이테크 SF 열)와 앵커 프롬프트 원문에서 도출.

| # | 시그니처 | 육안 판정 기준 | 계기 |
|---|---|---|---|
| L1 | **쿨 팔레트** | 화면 지배색이 회색~청흑. 웜 캐스트 없음 | `hue_spread` 쿨대 ≥ 60% / `amber` R−B < 0 |
| L2 | **클린 메탈** | 금속이 고광택 크롬처럼 — 선명한 반사·깨끗한 하이라이트. 낡음·부식 없음 | `sf_metrics` 하이클립 |
| L3 | **인공광 시그니처** | 발광 엣지·림라이트·실내 광원이 인공(형광/LED/네온/홀로그램 광). 자연 일광 단독이면 미달 | `sf_metrics` 시안악센트 > 0 |
| L4 | **매우 높은 대비 + 날카로운 그림자** | 깊은 암부와 밝은 하이라이트 공존, 그림자 가장자리가 단단함 | `sf_metrics` 대비 · 암부 |
| L5 | **절제된 고채도 악센트** | 시안이 **악센트**로 (면적 작게) — 화면 전체가 파랗게 물들면 L5 는 미달(preview 병증) | 채도평균 낮음 + 채도p99 높음 |

**G-look 통과 조건**: L1·L3 필수 + L2/L4/L5 중 2개 이상.

## D. G-content — **콘텐츠 개조** (이 런의 관전점, `euro_period` 의 period 축과 대칭)

**통과 = 룩만 입고 물건은 그대로.** 재질·광원·그레이드가 SF로 바뀌는 것은 **정상**(그게 상품).
아래는 "물건 자체가 미래 물건이 되었는가"의 목록이다. 하나라도 나오면 **개조로 기록**.

| # | 개조 항목 | 판정 |
|---|---|---|
| M1 | **스쿠터 → 호버바이크** (바퀴 소실·부양·이색 실루엣) | 결정적 증거 |
| M2 | 스쿠터가 바퀴는 있으나 **미래형 컨셉 차량**으로 재설계 (일반 배달 스쿠터로 안 읽힘) | 개조 |
| M3 | **카페 → 미래 시설** (홀로그램 메뉴·발광 패널 가구·로봇 바리스타·미래도시 창밖) | 개조 |
| M4 | **가로등 → 미래 구조물** / 거리가 미래도시 협곡으로 | 개조 |
| M5 | **의상 개조** — 낡은 유틸리티 재킷·카고 바지가 **테크 슈트/파워드 아머/발광 스트립 의상**으로 | 개조 |
| M6 | 화면에 **홀로그램 UI·부유 디스플레이·추상 글리프** 추가 (preview 의 서명) | 개조 (preview 누수 겸용) |
| M7 | 인물이 **비인간/사이보그/증강 신체** 로 | 개조 |

**경계선 명시 (사후 재해석 방지)**:
- ✅ 통과로 셀 것: 젖은 노면에 시안 반사 / 가로등이 LED 백색 / 카페 조명이 형광 / 금속이 크롬처럼 광남 /
  창밖이 밤이고 차가움 / 의상 원단이 매끈한 기술 섬유처럼 렌더됨(**형태는 유지**)
- ❌ 개조로 셀 것: 위 M1~M7

## F. 상한 비교자

preview 룩 서명 (측정 완료, 생성 전 기록):

| 이미지 | 시안악센트 | 채도평균 | 채도p99 | 대비 | 암부 | 쿨대 | R−B | hue_H |
|---|---|---|---|---|---|---|---|---|
| **board** | 20.21% | 33.3% | 100.0% | 190 | 21.4% | 94.9% | −21.4 | 0.40 |
| **preview** | 41.88% | 40.2% | 85.5% | 112 | 8.5% | 100.0% | −26.7 | 0.09 |

⚠ 상한이라 부르지만 preview 는 **L5 를 스스로 위반**한다 — 시안이 악센트가 아니라 화면 전체다
(hue_H 0.09 = hue 완전 붕괴). 따라서 "preview 에 가까울수록 좋다"가 아니라
**"쿨/시안 축에서는 preview 가 상한, 절제(L5)·대비(L4) 축에서는 board 가 상한"** 으로 읽는다.
