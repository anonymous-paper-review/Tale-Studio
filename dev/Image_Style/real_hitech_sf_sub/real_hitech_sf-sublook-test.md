## 한 줄 결론

**보드는 멀쩡하다 — 그런데 룩이 콘텐츠에 의존해서 켜진다.** 밤·인공광 콘텐츠(스쿠터·액션)에서는
T 만으로 룩이 과잉으로 나오고, 낮 실내(카페)에서는 절반만, **플랫 배경 인물에서는 완전히 꺼진다**
(t_character 시안악센트 0.32% · 채도 7.0% · 대비 100 — 그냥 회색 사진). **룩 절 텍스트가 그 구멍을 닫는다**
(b_character 4.85% / 20.3% / 203). 그리고 **대비 축은 이미지가 아니라 텍스트가 소유한다** —
B 4장이 전부 200~206 으로 수렴하는데 T 는 100~196 으로 흩어진다. 관전점인 **콘텐츠 개조는 T 에서 0/4** —
스쿠터는 4장 전부 바퀴 달린 현대 스쿠터이고 호버바이크는 없다. 다만 **B 는 발광 프롭을 추가한다**
(가방·소매·배달통에 시안 라이트 스트립) — 룩 절의 `emissive edges` 문구가 "발광체를 새로 만들어도 된다"로
읽힌 것이다. 그리고 개조와 별개로 **보드의 야경 스카이라인이 밤 씬 3/3 에 따라 들어온다**(붉은 항공장애등까지
동일) — action 의 "좁은 거리"를 파노라마 조망으로 넓히는 부작용까지. 판정: **보드 재제작 불요,
룩 절 승격 권장 — 단 발광 허가 문구를 잘라내고, 스카이라인은 부정문으로 막고.**

**A arm 추가 후 (§9)**: preview 를 2번 레퍼런스로 넣어도 **B 를 못 이긴다** — 인물 점화는 B 의 절반,
카페에서는 룩을 오히려 8배 깎는다(시안 36.3%→4.2%). 다만 **누수는 거의 0**이라 기각 사유가
선행 5종과 다르다(누수가 아니라 **무이득**). 부수 소득 2건: **발광 프롭 신설이 A 에서 재발하지 않아
룩 절 텍스트가 범인으로 확정**됐고, **2-ref 절의 긴 부정 목록이 스카이라인 누수까지 눌렀다**(가설, 검증 7크레딧).

창가 방 코너(창밖 = **야경 스카이라인**). 인물·텍스트 없음. 육안 판정: facet 표 전항 충실.

### 1.2 preview `media/style-anchors/previews/real_hitech_sf.jpg` (1024² JPEG)

야경 메가시티 상공의 미니멀 커맨드룸. 회백색 기술 슈트 인물 뒷모습이 **홀로그램 UI 패널**(추상 글리프)에
손을 뻗음. 판독 가능 문자 없음, 얼굴 없음.

### 1.3 정합 감사 — **preview 가 파는 것 ≠ anchor 가 나르는 것** (양방향 불일치)

| | preview 가 파는 것 | 보드가 나를 수 있나 |
|---|---|---|
| 홀로그램 UI·부유 디스플레이 | **주 판매 포인트** | ❌ **못 나름** — 정물에 발광 UI 없음 (구조적 공백) |
| 야경 메가시티 | 화면의 절반 | △ 창밖 스카이라인으로 부분 보유 |
| 기술 슈트 인물 | 유일 인물 | ❌ 못 나름 (정물 보드) |

| | 보드가 나르는 것 | preview 가 보여주나 |
|---|---|---|
| **고광택 크롬 스페큘러** | 크롬 컵 = 보드 최강 신호 | ❌ 금속 클로즈업 자체가 없음 |
| **매우 높은 대비** | 대비 **190** | ❌ **112** — preview 가 훨씬 밋밋 |
| **절제된 악센트(L5)** | 시안 20.2% + hue_H 0.40 (회색·녹색 잔존) | ❌ **스스로 위반** — 시안 41.9%, **hue_H 0.09** = hue 완전 붕괴 |

**감사 결론**: 이 서브룩은 preview↔anchor 가 **hue 가족(쿨)만 일치하고 나머지는 어긋난다.**
preview 는 룩의 *콘텐츠 판타지*(홀로그램·메가시티)를 팔고, 보드는 룩의 *재질·광학 문법*(크롬·엣지광·대비)을
나른다. 오너가 픽커에서 고른 것과 모델이 받는 것이 real_3d §1.1 만큼 갈라지지는 않았지만(둘 다 쿨 SF다),
**"내가 고른 홀로그램 커맨드룸"을 기대한 사용자는 앵커에서 그걸 못 받는다.**

⚠ **preview 는 상한이 아니다.** 팀리드 지시의 "상한 비교자 = preview 룩 서명"을 문자 그대로 쓰면
잘못된 목표를 겨눈다 — preview 는 L5(절제)를 스스로 어긴 **단색 블루 워시**다(hue_H 0.09).
따라서 아래 판정은 **쿨/시안 축은 preview, 절제·대비 축은 board** 를 상한으로 이원 적용했다(`prereg_gates.md` §F).

### 2.2 의도적으로 넣지 않은 것 (게이트 선점 방지)

- **공간 facet 제외** — 원본 프롬프트의 `sleek minimalist future-city interior with a night skyline`
  는 **콘텐츠**다. 넣으면 G-content 를 못 잰다(카페를 미래 시설로 만들라고 지시하는 셈).
- **`Mood: control and the future` 제외** — 이 런의 관전점이 "SF 룩이 현대 콘텐츠를 개조하는가"인데
  `future` 는 개조를 직접 유발할 수 있는 유일한 어휘 트리거다. 넣었다면 B 의 G-content 결과가
  **룩 탓인지 단어 탓인지 구분 불가**가 된다. `real_2ref` §2.2 가 방언 절을 뺀 것과 같은 판단.
  **대가**: 이 런은 "무드 문장을 넣으면 어떻게 되는가"에 답하지 않는다(§7 한계 2).
- **시간대 락 없음** — "NOT night" 류를 넣지 않았다. 보드가 야경 창을 품고 있어 **카페(late afternoon)가
  밤으로 끌려가는지**가 G-time 의 측정 대상이다.

### 2.3 콘텐츠 문장 동일성 검증 (런 간·팔 간 비교 가능성)

`probe_*.txt` 4종은 `real_3d_v2` 원문과 md5 동일. T/B 의 콘텐츠+꼬리 2줄 md5 4/4 동일(`SAME`).
즉 T→B 의 유일한 차이는 **삽입된 룩 절 1문단**이다.

### 3.0 계기를 새로 만든 이유

기존 계기 3종은 전부 **웜 축**(앰버 지배)을 재도록 만들어졌다 — 이 서브룩의 상품은 정반대다.
`amber_metrics.py` 로 이 런을 재면 앵버비율이 전부 0.0% 로 나와 **아무것도 구분하지 못한다**.
그래서 `sf_metrics.py` 를 새로 썼다: 시안 악센트 면적 · 채도(평균/p99) · **휘도 대비(p95−p5)** ·
하이라이트 클립 · 암부 비율. `real_2ref` 가 `hue_spread.py` 를 만든 것과 같은 사유다.

### 3.1 발견 1 — **대비 축의 주인은 텍스트다** (4/4 재현, 이 런 최강 신호)

| 프로브 | T 대비 | **B 대비** | Δ |
|---|---|---|---|
| character | 100 | **203** | +103 |
| cafe | 196 | **200** | +4 |
| scooter | 132 | **206** | +74 |
| action | 142 | **205** | +65 |

**B 4장이 200~206 에 수렴한다(폭 6). T 는 100~196 으로 흩어진다(폭 96).**
facet 표가 "대비: 매우 높음"이라고 명시한 축을 **보드는 콘텐츠에 따라 들쭉날쭉 전달하고, 텍스트는
매번 같은 값으로 못 박는다.** 이는 플레이북 §7 횡단규칙 2("텍스트가 어휘로 집을 수 있는 축은
텍스트가 이긴다")의 **새 축(대비)에서의 독립 재현**이다 — 기존 실증은 장면 밀도·매체·인물 방언이었다.

### 3.2 발견 2 — **룩은 콘텐츠 의존적으로 켜진다** (T 팔의 3단 분화)

| 콘텐츠 성격 | 프로브 | T 의 룩 전달 | 근거 |
|---|---|---|---|
| **밤 + 인공광원 내장** | scooter · action | **과잉 전달** | 시안 57.8·64.9% / 채도 51.4·58.5% — 보드(20.2/33.3)를 넘어섬 |
| **낮 실내 + 창광** | cafe | **절반** | 시안 15.3% / 채도 19.0% / 대비 196 — 쿨·대비는 왔으나 인공광 서명 약함 |
| **플랫 배경 인물** | character | **소멸** | 시안 **0.32%** / 채도 **7.0%** / 유채색픽셀 **4.7%** / 대비 **100** |

**t_character 는 사실상 무채색 회색 사진이다.** 보드의 크롬·시안·엣지광·고대비가 **하나도** 전이되지 않았다.
진단: 이 룩의 보드 신호는 **오브젝트에 결박돼 있다**(크롬 컵의 반사, 크리스털의 엣지광, 야경 창).
배달원 인물에는 크롬도 발광면도 없으므로 **신호가 내려앉을 표면이 없다.** 플레이북 §1.1 의
"정보 교집합 공백"과 같은 구조지만 축이 다르다 — 매체가 아니라 **룩이 필요로 하는 표면**의 공백이다.

**이 진단의 직접 확증**: t_cafe 에는 화분 식물이 있고, 거기에 보드의 facet(`the plant catches a
razor-sharp rim of edge light`)이 **잎마다 시안 림라이트로 정확히 재현됐다**(증거: `ev_cafe_window_TB.png` 좌).
즉 보드는 **같은 종류의 표면이 콘텐츠에 있으면 그 facet 을 정확히 나른다.** 인물에서 실패한 것은
보드가 약해서가 아니라 **표면이 없어서**다. 따라서 처방은 "보드를 더 잘 굽기"가 아니라
"표면 없이도 적용되는 어휘(조명·대비·그레이드)를 텍스트로 말하기"가 된다 — §5 판정의 근거.

### 3.3 발견 3 — 밤 콘텐츠에서 룩이 **단색 블루 워시로 퇴화**한다 (L5 위반)

| t_scooter | 89.5% | 51.4% | 0.23 |

밤 프로브는 **화면의 90~97%가 유채색 파랑**이고 hue 엔트로피가 보드의 0.40 에서 0.20 대로 붕괴한다.
facet 스펙의 `restrained cool near-monochrome ... only a few controlled accents` 는 **악센트**를 말하는데
산출은 **전면 도포**다. 그리고 **preview 가 이 병증의 가장 극단적 사례**(hue_H 0.09)라는 게 뼈아프다 —
오너가 픽커에서 고른 그림이 곧 병증의 견본이다.

이는 `real` 의 웜 단색 gamut(§4.1)과 **정확한 거울상**이다. 차이: `real` 은 씬이 조명을 말하면 뒤집혔지만,

- **M5 의상 개조 ❌** — t_character 는 **낡은 천 유틸리티 재킷·카고 바지·캔버스 새첼·워커**. 테크 슈트 아님.

- M2/M4/M7 ❌.

**B 는 발광 요소를 추가한다 — 현상은 4/4 전부에서 나타나고, 그중 2장이 개조로 판정된다.**

판정 기준은 사전 등록의 경계선(`prereg_gates.md` §D)이다: **그 물건이 현실에서 발광체를 가질 법한가.**
카페 선반 LED·스쿠터 헤드라이트는 실재하므로 통과, **캔버스 가방·천 소매·배달 탑박스는 아니므로 개조.**

|---|---|---|
| **b_character** | 새첼에 **시안 라이트 바 2개**, 소매 포켓에 **발광 스트립** (증거: `ev_m5_b_character_glow.png`) | **M5 부분** — 의복 *형태*는 보존(유틸리티 재킷·카고 유지), *발광 요소만 추가* |

**귀속은 확정적이다.** T·B 는 refs 동일·콘텐츠 문장 md5 동일이므로, 이 발광 추가는 **룩 절 텍스트에서 왔다.**

즉 스쿠터가 호버바이크가 되는 식의 개조는 아니고, **물건에 라이트를 붙이는** 개조다.

개조(M1~M7)와 별개의 축이다. 증거: **`sky_leak.png`** (좌→우: 보드 창밖 · t_scooter · b_scooter · t_action).

보드 창밖의 야경 스카이라인 — 블루-화이트 타워 조명 + **작은 붉은 항공장애등** + 특유의 보케 —
이 **t_scooter · b_scooter · t_action 배경에 거의 그대로 재현된다.** 붉은 항공장애등까지 같이 온다.

**프로브는 스카이라인을 요구한 적이 없다.**
- scooter: "주차된 배달 스쿠터 · 가로등 · 젖은 노면" — 원경 지정 없음
- action: **"좁은 거리"(narrow street)** — 파노라마 스카이라인 조망과 **모순된다**

판정: **M4(미래 구조물) 아님** — 스카이라인들은 전부 평범한 현대 도시다. 따라서 §4.4 의 G-content
0/4 판정은 유지된다. 그러나 이것은 **보드에서 온 콘텐츠 추가**이고, `real_2ref` §5 의 C-항목 누수와
같은 성질이다(거기선 preview 가 범인이었고 여기선 **보드 자신**이다). 무해하지 않은 경우가 하나 있다 —
**action 의 "좁은 거리"가 스카이라인 조망으로 넓어진 것은 프롬프트에 대한 나쁜 답이다.**

이 누수는 **텍스트로 못 막았다** — B 팔에서도 그대로 나온다(룩 절은 공간을 말하지 않으므로 당연).
막으려면 스트립 경로의 부정문(`storyboard-strip.ts:176` 계열, "Do NOT reproduce its subject")이
서브룩 single/multiref 경로에도 필요하다 — `real_2ref` §8-2 의 권고와 같은 자리다.

**보드 재제작 = 불요.** 근거 3가지:
1. 보드는 facet 전항을 충실히 담고 있고(§1.1), 육안 품질도 높다(크롬 반사·크리스털 엣지광 = 사진급).

3. 그 구멍을 **텍스트가 실제로 닫는 것이 실증됐다**(§4.1 미달형 2장 → B 완전통과, §3.1 대비 수렴).

설계도 가능하다. 이 런은 그것을 시험하지 않았고, 텍스트 처방이 더 싸므로(0크레딧) 먼저 권하지 않는다.

### 9.6 preview IP 인접성 평가

**판정: 낮음. watercolor 형 상시 기각 사유는 발견되지 않는다.**

| 축 | 관측 | 위험 |
|---|---|---|
| 특정 작품 오마주 | 구도(홀로그램 벽 앞 인물 + 통유리 야경)는 **장르 전반에 확산된 아키타입** — 단일 원천을 특정할 수 없음 | 낮음 |
| 배우 유사성 | **뒷모습, 얼굴 0** | 없음 |
| 로고·판독 텍스트 | **없음** (홀로그램은 전부 추상 글리프·와이어프레임·다이얼) | 없음 |
| 캐릭터 의상 | 회백색 무광 기술 슈트 — 심라인·관절 패널뿐, **엠블럼·색 블로킹·헬멧 등 식별 요소 없음** | 낮음(잔여 최대) |
| 랜드마크 | 스카이라인에 붉은 첨탑등 타워 1기 — 일반 방송탑 실루엣, 특정 건물 단정 불가 | 낮음 |

`anchor-refresh-playbook.md` §7 횡단규칙 3 의 watercolor 사례는 **preview 자체가 유명작 오마주**여서
법무 사유로 상시 기각이었다. 여기는 그 조건이 성립하지 않는다 — 원 설계 문서(`real-substyle-anchor-prompts.md`
§쇼케이스)가 이미 "구도 아키타입만 차용, 인물·의상·로고 전부 오리지널 + no real actor 네거티브 명시"를
집행했고, **산출물이 그 계약을 지키고 있음을 육안 확인**했다.

⚠ **한계**: 이것은 **시각적 유사성 소견이지 법률 자문이 아니다.** 또한 원 설계 문서가 아키타입 출처로
특정 영화 2편을 명시적으로 지목해 두었다는 사실은 기록에 남아 있다 — 구도·조명·스케일이 저작권 대상이
아니라는 그 문서의 전제에 의존한 판단이다. 잔여 위험을 하나만 꼽으면 **기술 슈트**다.

### 9.7 그래서 A 를 배선해야 하는가 — **아니다. 단 기각 사유가 선행 런과 다르다**

| | 선행 5종(매체 앵커) | **`real_hitech_sf`(이 런)** |
|---|---|---|
| 기각 사유 | **콘텐츠 누수**(장소·계절·의상 정체성) 또는 법무 | **이득이 없다** — 누수는 거의 0인데 **룩을 오히려 깎는다** |

- **cafe 에서 A 는 룩을 크게 잃는다**: 시안 15.33 → **4.19%**, 채도 19.0 → **11.9%**, 채도p90 45.9 → **32.5%**.
  a_cafe 는 T 보다 **덜 SF 답다** — 회색 미니멀 카페에 가깝다. 이 서브룩의 상품이 그레이드인데 **상품을 깎았다.**
- **scooter 는 무변화**, action 은 시안 −15.7%p / 대비 +46 으로 혼합.
- **얻는 것은 장면 밀도 하나뿐**: cafe 강엣지 10.9 → **17.5%**, 플랫 19 → **13%** (A 가 3자 중 최고).
  선행 런의 "A 의 이득은 장면 밀도"가 **여기서도 재현**됐다. 그러나 **밀도는 이 서브룩이 팔러 온 것이 아니다.**

**결론**: A 배선 불가. **B(룩 절)가 A 를 모든 축에서 이기거나 비긴다** — 인물 점화 2배, 대비 4/4 우세,
카페 룩 8배, 누수는 발광 프롭 1종(문구 수정으로 제거 가능). **§6 권고는 A 실측 후에도 그대로 유지된다.**
