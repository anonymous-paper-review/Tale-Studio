## 1. 프로브 점수
표: 프로브 × 5축(스타일 충실도 / 콘텐츠 중립성 / 재질 분리 / 구조 안정성 / 독립성, 0~5) + 정체성 누출(없음/경미/뚜렷 — 원작의 인물·얼굴·헤어·의상·로고·배치·모티프 중 무엇이 복제됐는지 구체적으로) + 한 줄 근거. 마지막 행에 충실도 평균과 누출 집계.

## 2. T 장면 (템플릿만)
축별 일치도 표(매체 · 선 · 채움 · 명암/그림자 · 색 · 형태 · 정밀도 · 질감/마감 · 조명 · 투영/시점 · 배경/지면 · 장식 · 디테일 밀도 · 인물 방언, 0~5) + 사이클 2 장면이 있으면 같은 표에 열 추가하고 해소/완화/잔존/악화/신규.

## 3. 잔차 목록
프로브와 T 장면에서 원작 스타일과 다른 점을 중요도 순으로 최소 8개. `- [축] 원본: … / 프로브: … / T: … → 원인 (a|b|c|d|e): 근거 — 관련 key: 경로`. 원인: (a) 템플릿에 key 없음 · (b) 채워진 값이 틀림 · (c) 값은 맞는데 프롬프트(캡슐·앵커·인물 절)에 안 실림 · (d) 프롬프트에 있는데 생성기가 무시 · (e) 참조 이미지가 원작 스타일을 프로브로 나르지 못함(이미지 채널 손실). filled.json·prompts.md·anchors.md·gen/*.txt를 실제로 대조해 판정한다.

## 4. 새 facet 제안

## 5. 총평
