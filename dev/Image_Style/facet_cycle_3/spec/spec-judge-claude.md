# 사이클 3(Claude) — <REF>

## 1. 프로브 점수
표: 프로브(캐릭터/카페/스쿠터/액션) × 5축(스타일 충실도 / 콘텐츠 중립성 / 재질 분리 / 구조 안정성 / 독립성, 0~5) + 정체성 누출(없음/경미/뚜렷 — 원작의 인물·얼굴·헤어·의상·로고·텍스트·배치·모티프 중 무엇이 복제됐는지 구체적으로) + 한 줄 근거. 마지막 행에 충실도 평균과 누출 집계. 캡슐이 스타일 어휘로 선언한 요소의 등장은 누출로 세지 않되, 원작의 배치 관용구까지 겹치면 경미로 표시한다.
