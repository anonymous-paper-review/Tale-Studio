# 작업: 첨부 이미지(<IMAGE>)의 facet 템플릿 채우기

당신은 이미지 스타일 분석자(VLM)다. 첨부 이미지 1장을 보고, 이 폴더의 facet 템플릿을 채운다. 읽는 순서: `guide.md`(목적·작성 규칙) → `input.jsonc`(입력 서식) → `template.jsonc`(조립도 본문). 산출물은 이 폴더에 저장하는 파일 3개다: `filled.jsonc`, `scene_summary.md`, `proposals.md`.

## 고정 규칙 (하네스 제약)

- 작가·프랜차이즈·작품·브랜드·회사 고유명사를 절대 쓰지 마라(추측·부정문도 금지). 중립 서술어와 hex·수치만 쓴다.
- 값은 한국어로 쓴다(hex·px·%·영문 토큰은 허용). `생성 규칙.부정 절`의 4개 값만 영문 쉼표 목록.
- 이 폴더의 다른 파일은 수정하지 마라. 외부 검색·네트워크 접근 금지.
- 최종 메시지에는 `proposals.md` 전문과, `filled.jsonc`에서 `입력`·`그림체.선`·`그림체.색` 세 덩어리만 발췌해 붙여라(전문은 파일에 있으면 된다).

## filled.jsonc 채우는 법

1. `guide.md` §4의 규칙을 따른다. 특히: 선택형(`[N개 중 1개 선택: …]`)은 후보 중에서 고르고, 관찰값이 후보에 없으면 억지로 고르지 말고 자유 서술한 뒤 `proposals.md`에 "후보 밖"으로 적는다. 값 앞에 신뢰도 태그 `[실측|추정|보정|외삽|해당 없음]`를 붙인다.
2. `input.jsonc`의 `입력`을 먼저 채우고, 그 판정(캡처 계층)에 맞춰 `template.jsonc`의 본문을 채운다. `filled.jsonc`는 `{ "입력": {…}, "그림체": {…}, "사진성": {…}, … }` 한 파일이다. 키·계층·순서는 그대로 두고 값만 바꾼다. 값의 `ex.` 접두는 지운다. `//` 주석은 지워도 되고 원문 그대로 남겨도 된다 — 주석을 고치지는 마라.
3. 값은 구체적으로: 색은 hex, 선 굵기는 px(원본 해상도 기준을 병기), 비율·개수·단계 수는 숫자, 척도는 0~5. 캡처 계층이 b·c면 보정값을 쓰고 실측값을 괄호에 남긴다(예: `#254bd6 (실측 #585d88, 캐스트 보정)`).
4. 아래 [계산 통계]는 접지 자료다(팔레트·채도·명도·강엣지·플랫 블록). 통계와 육안이 다르면 육안을 우선하되 괄호에 통계값을 남긴다.
5. 표본이 없는 축은 `[외삽] …` 또는 `[해당 없음]` 한 줄로만 적는다. 장문 외삽 금지. `사진성`은 캡처 계층이 d일 때만 채우고 아니면 가지 전체를 `[해당 없음]`.
6. `분류`와 `생성 규칙`도 채운다. 게이트 판정의 `삽입`·`생략`은 합쳐서 후보 9개가 되게 한다.

## scene_summary.md

원작이 무엇을 그렸는지 한국어 2~3문장, 고유명사 없이: 장면의 종류, 주요 대상의 종류와 대략 개수, 배치와 시점, 인물 유무와 수. 이것은 템플릿 밖의 '내용' 요약이며, 재생성 테스트에서 같은 종류의 장면을 그리게 하는 데만 쓴다. 스타일 서술은 넣지 않는다.

## proposals.md

채우면서 발견한 템플릿의 빈틈을 적는다. 형식은 한 항목당 한 줄: `- [유형] 키 경로 — 내용 (근거: 이 이미지에서 관찰한 것 1문장)`. 유형은 넷 중 하나:
- `새 facet` — 관찰했는데 적을 key가 없었다. 넣을 가지 경로와 key 이름(한국어 대표어), 이 이미지에서의 값, 주석 초안(2문장 이상)을 함께 적는다.
- `후보 밖` — 선택형 후보에 관찰값이 없어 자유 서술했다. 추가할 후보를 적는다.
- `모호` — key 이름이나 주석이 모호해 해석이 갈렸다. 어떻게 갈렸고 어느 쪽으로 채웠는지 적는다.
- `중복` — 두 key가 같은 것을 가리켜 값이 겹쳤다.
최소 8개. `새 facet`을 우선해서 찾아라 — 이 그림의 스타일을 재현하는 데 필요한데 서식에 자리가 없는 속성이 있는지가 핵심 질문이다.
