# 작업: 프로브용 압축 캡슐(PROBE_ANCHORS) 작성

이 폴더의 `filled.json`(채워진 스타일 템플릿)과 `prompts.md`(컴파일된 캡슐)만 보고 `anchors.md`를 쓴다. 원본 이미지는 없다. 다른 파일은 수정하지 마라. 고유명사 금지. 최종 메시지에 `anchors.md` 전문.

## anchors.md 형식 (헤더 글자 그대로, 코드블록 없이)

## PROBE_ANCHORS
영문 6~9문장, 100~120단어(순서는 이 스타일의 `분류.Core` 순). 원작 이미지를 스타일 참조로 함께 주는 프로브에 얹는 압축 캡슐 — 이미지가 나르지 못하는 값만: ① 투영·시점 ② 선(상대 굵기 비교 서술 + 색 hex) ③ 채움·그림자(플랫/셀, 캐스트 섀도 유형·방향) ④ 팔레트 역할("#hex is ground only, never an object plane; objects are #hex bodies; accent #hex ≤ N% on …") ⑤ 지면·배경 문법(방향어 유지) ⑥ 장식 산포 ⑦ 면별 명도가 Core면 부위→hex ⑧ 유리·곡면 처리 ⑨ 구도(주체 높이 %, 빈 바탕 %). 재질 사전 전체·과정 서술·내용 지시·하이픈 압축 문체 금지 — 생성기가 읽는 자연문으로.
