# 작업: prompts.md 길이 상한 재적용 (v1.2.1 §6 23 보완)

이 폴더의 `prompts.md`는 당신이 방금 컴파일한 것이다. §6 23의 "Core 절은 예산과 무관"을 예산 없음으로 읽어 PROBE_ANCHORS와 CAPSULE이 상한을 크게 넘었다. 보완된 규칙: **절대 상한 = 등급별 상한 + 40단어** — CAPSULE은 등급 1 → 130 / 2 → 150 / 3 → 180 / 4 → 200 / 5 → 210단어, PROBE_ANCHORS는 등급 1~2 → 130 / 3 → 150 / 4~5 → 160단어. `filled.json`의 `디테일.묘사 밀도.등급`으로 상한을 정한다.

고치는 법: Core 절(§6 15 장식 형상·hex·크기·산포·레이어, §6 16 선의 층별 문장, 배경 그래픽 구성, 그라디언트 지시문, Detail budget, 키 절, 팔레트 역할, 투영)은 남기고, 재질 사전·형태·정밀도·질감 같은 비-Core 절부터 지운다. 그래도 넘으면 Core 절의 예시·부연을 줄이되 수치는 남긴다. 자연문 유지, 하이픈 압축 금지, "at most/maximum" 대신 "about N". NEGATIVE·SCENE·FIGURE는 그대로. COVERAGE 표는 지운 절이 있으면 그 행의 '실린 섹션'을 `—`(예산)로 갱신한다. 원본 이미지는 없다 — `filled.json`에 없는 것은 보태지 않는다. 다른 파일을 만들거나 고치지 마라. 최종 메시지에 두 섹션의 단어 수와 `prompts.md` 전문.
