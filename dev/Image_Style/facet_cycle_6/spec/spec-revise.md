# 작업: 채움 검사 위반 수정 (filled.jsonc)

이 폴더의 `filled.jsonc`는 당신이 방금 채운 것이고, 하네스가 추측 허용 규약(`guide.md` §4 12~18항)으로 검사해 아래 위반을 찾았다. 첨부 이미지(<IMAGE>)를 다시 보고 **위반 항목만** 고쳐라 — 다른 값·키·주석은 손대지 않는다.

- 세지 않은 범위 → 표본 개체를 지목해 실제로 센 값 하나로("표본 우측 인물(얼굴 80px): 7"). 두 표본을 셌으면 최소~최대와 표본 둘을 적는다.
- 열린 상한("N개 이상"·"수십") → 센 값으로.
- 등급 1~2에서 '많음·높음·다수' → 센 값과 함께 정성어를 문턱에 맞춘다(내부선 ≤6 = 적음).
- 판독 한계·묘사 밀도가 비었으면 통계의 '판독 한계 참고' 줄과 표본 개체로 채운다.
- 속성형 부호의 결속 위치 서술은 지운다. 등급 1~2에서 `부정 절.정교화`가 비었으면 채운다.
- 경고 항목은 고칠 의무가 없지만, 나열이 6항목 이상인 값은 4항목 이하로 줄여라.

`proposals.md`·`scene_summary.md`는 그대로 둔다. 다른 파일을 만들지 마라. 고유명사 금지. 최종 메시지에 고친 key 경로와 새 값의 목록만 붙여라.
