# 보드 A/B — 확장 보드 vs 보드 없음 (2026-09-07, 오너 결정 1)

> 질문: 앵커 보드를 거치는 과정이 정보 손실을 일으키는가. (A) 피사체를 늘린 확장 보드(정물 + 남성·여성 전신 + 동물 + 풍경 소경)를 만들어 `[보드, 원작]`으로 프로브를 그리는 방법과 (B) 보드 없이 원작을 유일한 참조로 `[원작]`만 주는 방법 중 어느 쪽이 4개 표준 프로브에서 스타일 충실도가 높은가. 동시에 (B)의 정체성 누출·모작 위험을 본다.

## 설계

- 레퍼런스 3장(refer5·refer1·refer6), 조건 2개, 프로브 4개(캐릭터·카페·스쿠터·액션) = 24장 + 확장 보드 3장.
- **캡슐·FIGURE·NEGATIVE는 두 조건에 동일** — 사이클 2의 컴파일 산출물(`facet_cycle_2/<ref>/compile/prompts.md`)을 쓴다. 조건 간 차이는 참조 이미지 구성뿐.
- (A) 확장 보드: `bin/hf_image.sh board.txt board.png <원작>` — 콘텐츠 락은 2×2 시트(좌상 정물 / 우상 성인 남녀 전신 / 좌하 동물 / 우하 풍경 소경). 프로브 = `[board, 원작]`, 기존 확정 레시피의 두 참조 문장 유지.
- (B) 보드 없음: 프로브 = `[원작]`, 첫 참조 문장만("sets the visual style ONLY … Do NOT reproduce its subject").
- 판정: 프로브별 5축(충실도/중립성/재질/구조/독립성) + 정체성 누출 플래그(원작의 대상·캐릭터·배치가 복제됐는가). 판정자 Codex + Claude, 최종은 오너 육안.
- 비용: (A) 35 · (B) 28 크레딧 / 레퍼런스 → 189 크레딧.
