# 작업: 보드 A/B 판정 — <REF> (확장 보드 vs 보드 없음)

첨부 이미지 10장은 순서대로: (1) 원작, (2) 확장 보드(원작을 스타일 참조로 I2I 생성한 2×2 스타일 시트: 정물 / 성인 남녀 / 고양이 / 풍경), (3)~(6) 조건 A "확장 보드" 프로브 — 참조 `[확장 보드, 원작]`로 그린 캐릭터·카페·스쿠터·액션, (7)~(10) 조건 B "보드 없음" 프로브 — 참조 `[원작]`만으로 그린 캐릭터·카페·스쿠터·액션. **두 조건의 텍스트 프롬프트(캡슐·부정 절·인물 규칙·장면)는 동일하고 참조 이미지 구성만 다르다.** 프롬프트 원문은 이 폴더의 `expanded/*.txt`·`noboard/*.txt`.

질문: 앵커 보드를 거치는 것이 정보 손실을 일으키는가, 아니면 원작을 직접 참조하는 것이 정체성 누출·모작을 일으키는가. 원작의 **스타일**(선·채움·명암·색·형태·정밀도·투영·배경·장식)만 기준으로 채점하고, 대상·배치의 차이는 무시한다. 고유명사 금지. 다른 파일 수정 금지, 외부 검색 금지. 산출물은 이 폴더의 `judge-<REF>.md` 하나이며 최종 메시지에 전문을 붙인다.

# 보드 A/B 판정 — <REF>

## 1. 프로브별 점수
표: 프로브(캐릭터/카페/스쿠터/액션) × 조건(A 확장 보드 / B 보드 없음) × 5축(스타일 충실도 / 콘텐츠 중립성 / 재질 분리 / 구조 안정성 / 독립성 — 각 0~5) + 정체성 누출(없음 / 경미 / 뚜렷: 원작의 특정 대상·배치·모티프가 복제됐는가). 조건별 충실도 평균을 마지막 행에.

## 2. 확장 보드 자체 QA
보드가 원작 스타일을 얼마나 담았는가(0~5), 4개 칸 중 스타일이 무너진 칸, 원작 콘텐츠 복제 여부.

## 3. 조건 간 차이
프로브마다 A와 B가 갈린 축을 한 줄씩. "보드가 정보를 잃게 한 축"과 "보드가 정보를 보탠 축"을 분리한다.

## 4. 결론
어느 조건이 더 높은 성능인지(충실도 평균과 누출 플래그를 함께), 그 판단이 뒤집힐 조건(다른 스타일·인물 유무), 권고(채택 / 혼합 규칙 / 추가 실험).
