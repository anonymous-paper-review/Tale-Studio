# Tale Studio 랜딩 페이지 · 개발 전달 문서

이 폴더가 랜딩 페이지의 **원본 전체**예요. 사이트에 필요한 파일만 들어 있어요.
함께 받은 `TaleStudio_메인.html`은 모든 걸 한 파일에 담은 **시안**이라, 보이는 모습과 움직임을 확인할 때 쓰면 돼요.

---

## 1. 실행하기

Node 18 이상이 필요해요.

```bash
npm install
npm run dev            # 개발 서버 → http://localhost:5173
npm run build          # 배포용 → build/web/
npm run preview        # 배포용 결과를 로컬에서 확인
npm run build:single   # 시안 한 파일 → dist/TaleStudio_메인.html
```

- **배포는 `build/web/`을 써 주세요.** 이미지 · 영상 · 스크립트가 각각 파일로 나뉘어 있어요.
- `build:single`은 시안 공유용이에요. 약 7MB라 서비스에 쓰면 안 돼요.

## 3. 디자인 기준

**글꼴**
- 한글: Pretendard Variable (CDN)
- 숫자 · 영문 강조: Inter (Google Fonts)

**폭과 여백**
- 콘텐츠 최대 폭 `1200px`, 좌우 여백 `24px`
- 모든 섹션이 같은 폭을 써요

**테마**
- **다크가 기본**이에요. 사용자가 고른 테마는 `localStorage`의 `tale-theme-v2`에 저장돼요.
- 다크와 라이트의 색은 `:root[data-theme='dark']` · `:root[data-theme='light']`에 나뉘어 있어요.

|---|---|---|
| `--bg` | #0B0B0B | #FFFFFF |
| `--surface` | #1F1E1D | #F1F0EC |
| `--surface-2` | #262624 | #E8E6E0 |
| `--text` | #F5F4EE | #141312 |
| `--text-2` | #C2C0B6 | #4A4843 |

**단계 색** (Lumi 6단계, 강조와 그라데이션에 사용)

| #F2A33A | #E8606F | #8B63E8 | #5A6AE6 | #3E9BE0 | #2DB39A |

**포인트 글씨**
- 다크: 흰 빛이 지나가는 효과
- 라이트: 6색 그라데이션
- 헤드라인의 "Lumi"와 마지막 "시작해 볼까요?"는 두 테마 모두 그라데이션이 흘러요

## 4. 화면 구성

### 홈 (`#home`)
1. **내비게이션**: 로고 · Tale 서비스 · 작품 · 요금 · 테마 버튼 · 시작하기
2. **히어로**
   - 헤드라인의 "Lumi"가 지워지고 → 캐릭터가 하나씩 나왔다가 → 다시 써져요 (6명 순서대로)
   - 이야기 입력창: 파일 첨부, 길이 · 화면 비율 · 장르 선택
3. **한 줄의 여정**: 위 6개 버튼 + 앱 시연이 자동으로 이어서 재생돼요
4. **왜 Tale** — "글 한 줄이 영상이 되기까지, 한곳에서 Lumi와 함께 만들어요."
   - 왼쪽 네 가지를 스크롤하면 오른쪽 카드가 바뀌어요
   - 01 **All-in-one** 현장과 같은 제작 프로세스: 6단계 카드가 차례로 켜져요
   - 02 프롬프트 몰라도 글 한 줄로 시작: Lumi가 산문을 쓰는 작은 동작 화면
   - 03 인물 템플릿으로 오류 없는 캐스팅: 템플릿(@서윤 · @도현 · #버스 정류장)이 샷마다 붙어요
   - 04 콘티로 먼저 보고, 손으로 연출해요: 콘티 위에 색 화살표가 그려지고, 20 Takes vs 5 Takes 비교
5. **작품**: 실제 영상 5편(16:9)이 자동으로 흐르는 캐러셀. 이 영역이 보일 때만 영상이 재생돼요
6. **검증된 AI 모델을 한곳에서**: AI 모델 10개를 로고와 함께 보여 주는 칩 모음 (`.explore`). 로고는 `assets/ai/` (출처 `SOURCES.md`)
7. **마지막**: 폭죽이 겹치며 터지고 "Lumi와 시작하기 · 요금 확인하기"

### Tale 서비스 (`#service`)
- 잘하는 세 가지: 글쓰기 · 아이디어 넓히기 · 스토리보드 먼저
- 기능 카드: 채팅으로 기획 · 인물 보드 · 카메라와 조명 · 마스터 시트 · 영상 생성
- 마지막 영역

### 요금 (`#pricing`)
- 요금제 3개, 자주 묻는 질문, 마지막 영역

### 한국어 / English (사이트 전체)
- 상단 내비의 🌐 **KO / EN 드롭다운**으로 바꿔요. 선택은 `localStorage`의 `tale-lang`에 저장되고, 바꾸면 페이지를 다시 불러요. 주소에 `?lang=en` / `?lang=ko`를 붙여 바로 열 수도 있어요.
- HTML 원문은 한국어예요. 영어일 때 `src/i18n.js`가 화면의 한국어를 `src/i18n/en.js` 사전으로 바꿔요(나중에 생기는 채팅 · 시연 글자도 자동으로).
  - `TEXT`: 글자 조각 → 영어, `BLOCK`: 어순이 바뀌는 문장(요소 전체) → 영어 HTML, `PROSE`: 타이핑으로 나오는 긴 문장(코드에서 `t()`로 사용)
  - **한국어 문구를 고치면 사전의 키도 같이 고쳐 주세요.** 키가 안 맞으면 그 부분만 한국어로 남아요.
- 약관 화면도 이 언어 설정을 따라요(영문은 원문, 한국어는 번역).

### 약관 및 정책 (`#terms` · `#refund` · `#privacy` · `#acceptable-use`)
- 푸터 링크로 들어가요. 왼쪽에 문서 목록이 있고, 언어는 사이트 전체 설정(KO / EN)을 따라요.
- 내용은 `src/legal/*.ko.html` · `*.en.html` 파일이고, `src/legal.js`가 화면에 넣어요. 문구를 고칠 때는 이 파일만 바꾸면 돼요.
- 영문은 talestudio.art의 현재 원문 그대로, 한국어는 원문을 자연스럽게 옮긴 번역이에요. **법무 검토 후 게시해 주세요.**

## 5. 움직임 정리

| 요소 | 동작 | 위치 |
|---|---|---|
| 헤드라인 Lumi | 0.09초 간격으로 지우기 → 캐릭터 1.3초 → 0.11초 간격으로 쓰기 → 1.9초 대기 | `main.tsx` 맨 아래 |
| 나타나기 | `.reveal`이 화면에 들어오면 `.in`이 붙어요 | `common.js` |
| 앱 시연 | 화면에 30% 보이면 재생, 벗어나면 멈춤. 버튼으로 단계 이동 | `main.tsx`, `appsim.js` |
| Editor 시연 | 실제 영상을 1.25배속으로 재생하고 타임코드 · 재생 헤드를 맞춰요 | `appsim.js` `editor()` |
| 왜 Tale 카드 | 화면 가운데에 온 항목에 맞춰 바뀌어요. `.six__panel[data-panel]`이 있으면 그 패널, 없으면 작은 동작 화면 | `main.tsx` `activate()`, `index.html` |
| 폭죽 | 처음 3개 겹쳐 터지고, 0.62~0.88초마다 계속. 하나가 4.2초 동안 보여요 | `main.tsx` `pop()` |
| 채팅으로 기획 카드 | 대화가 0.5초 간격으로 차례로 나와요 | `page.css` |

- 사용자가 움직임 줄이기를 켜 두면(`prefers-reduced-motion`) 대부분의 움직임이 꺼져요.

| 앱 시연 · 동작 화면 | 연출된 애니메이션 | 그대로 써도 돼요. 실제 앱과 연결하지 않아요 |
| 작품 "전체 보기" | `#works`로 이동 | 작품 페이지가 생기면 연결 |

## 7. 확정이 필요한 문구 · 숫자 ⚠️

임시로 넣은 예시예요. 기획에서 확인해 주세요.
- 요금제 가격 · Take 수
- "4번 생성 · 20 Takes", "확정 후 5 Takes", "Seedance 2.0 720p 기준 예시"
- 채팅으로 기획 카드의 대화: "8컷 · 90초 → 6컷 · 60초", 결말 예시 두 개
- 자주 묻는 질문 답변
- AI 모델 목록 (출시 시점에 실제 제공하는 것만 남겨 주세요) · 로고 사용은 각 회사 브랜드 가이드 확인
- 작품 캐러셀의 제목 · 장르 (임시 제목: 우산 하나 아래 · 벚꽃이 지기 전에 · 야시장 한 입 · 강가의 조약돌 · 차밭의 아침)

## 8. 성능 · 접근성 메모

- `lumi-persona.js`(3.1MB, WebGL)가 가장 커요. 챗봇 버튼에서만 쓰니 나중에 불러오기(lazy)를 권해요.
- 영상은 `assets/gen/umbrella-15s.mp4`(0.14MB)와 작품 영상 `work-*.mp4` 4편(각 0.2~0.3MB, 480px · 소리 없음 · 시안용 최소 화질)이에요. 원본 고화질은 CDN에 올려 바꿔 주세요.
- 생성 이미지는 512px 안팎이라, 큰 화면용 고해상도 이미지로 바꾸면 더 선명해져요.
- 장식용 시연 화면은 `aria-hidden`이에요. 버튼과 입력창은 키보드로 쓸 수 있어요.
- 휴대폰 폭(390px)에서 가로 스크롤 없는 것 확인했어요.
