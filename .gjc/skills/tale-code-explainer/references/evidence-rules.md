# 근거, 정직성, 실패 처리

가이드는 현재 코드의 기준 커밋 스냅샷이다. 코드에 없는 런타임 사실이나 작성자 의도를 보완해서는 안 된다. 모든 중요한 주장에는 아래 상태 하나를 붙인다.

```text
코드 확인
테스트 확인
프로젝트 규칙
프레임워크 규칙
런타임 확인
근거 미확인
```

## 우선순위와 충돌

주장은 다음 순서로 신뢰한다.

1. 현재 소스 코드와 설정
2. 해당 동작을 고정하는 테스트
3. `AGENTS.md`, `CLAUDE.md`, `.claude/rules/`의 프로젝트 계약
4. 설치된 패키지 버전과 공식 프레임워크 계약
5. 주석과 과거 문서
6. 실제로 조회한 런타임 상태

주석과 코드가 다르면 코드를 현재 구현으로 표시한다. 프로젝트 규칙과 코드가 다르면 `의도한 구조`와 `현재 구현`을 분리한다. 런타임을 조회하지 않았다면 `런타임 미확인`이라고 쓴다. `근거 미확인`을 추측으로 채우지 않는다.

파일명·디렉터리명·import·검색 결과·주석만으로 역할, 호출, 실행 위치를 확정하지 않는다. 호출자와 실제 진입점, import와 실제 호출문을 함께 확인한다. 환경변수, SDK, route 위치, `"use client"`만 보고 실행 위치를 단정하지 않는다.

## 코드 원문과 줄 범위

- 현재 저장소 원문만 인용하고 코드 안에 교육용 주석을 넣지 않는다.
- 모든 발췌 첫 줄에 `저장소 상대 경로:시작줄-끝줄`을 표시한다.
- 실제로 확인하지 못한 줄 번호를 만들지 않는다.
- 떨어진 범위를 하나의 코드 블록으로 합치지 않으며 생략 범위는 코드 밖에서 밝힌다.
- 원문을 간결하게 고치거나 가짜 코드로 바꾸지 않는다.
- 일반 예제가 꼭 필요하면 `저장소 코드 아님`으로 명시한다.

테스트는 제품 약속을 고정하는 근거일 수 있지만, 통과했거나 실제 환경에서 실행되었다고 쓰지 않는다. 이 스킬 실행 중 테스트, 린터, 포매터, 빌드는 실행하지 않는다.

## 설계 설명

각 설계 선택은 실제 코드 한 곳 이상에 연결한다. 직접 근거가 없으면 작성 의도로 표현하지 말고 다음처럼 쓴다.

```text
현재 코드가 얻는 효과: ...
작성 당시 의도: 근거 미확인
```

장점과 비용은 현재 기능의 실제 효과를 적는다. 코드·문서에 없는 대안은 하나만 `비교를 위한 대안`으로 표시한다. 변경 영향은 확인된 호출자, 상태, 테스트, 외부 계약 범위에서만 적는다.

## 시각 근거

화살표는 확인된 호출 또는 데이터 이동만 뜻한다. 미구현 의도는 점선과 `의도`, 미확인 관계는 연결선 없이 `근거 미확인` 영역으로 표현한다. SVG의 `title`, `desc`, 고유 ID, 실제 파일·심볼 상자도 근거 검토 대상이다. 외부 리소스 없이 열리는지는 verifier로 확인한다.

브라우저 렌더를 실제로 확인할 수 없으면 SVG·HTML 문법과 중복 ID는 검사하되 artifact와 완료 응답에 `브라우저 렌더 미확인`을 적는다. 시각 검증을 했다고 말하지 않는다.

## 실패 처리

**대상을 찾지 못함**: 검색한 용어와 위치를 evidence에 적고 가까운 후보를 최대 3개 제시한다. 후보가 서로 다른 사용자 행동이면 선택을 요청한다. 임의의 기능을 만들지 않는다.

**호출 관계가 끊김**: 확인한 마지막 노드까지만 실선으로 그리고 이후는 `연결 근거 미확인`으로 분리한다. 관련 테스트 또는 route 진입점에서 역방향으로 한 번 더 조사한다.

**함수가 너무 큼**: 정상 경로, 비즈니스 조건, 실패 복구, 외부 부작용으로 나누고 전체 함수를 한 블록으로 쓰지 않는다. 크기가 학습과 유지보수에 주는 비용은 tradeoffs에 기록한다.

## 최종 점검

verifier 실행 전후에 주요 노드와 코드 카드의 파일·심볼·줄 범위가 원문과 맞는지, 코드·테스트·규칙·프레임워크·런타임 상태를 섞지 않았는지, 실행 위치·비즈니스 조건·TypeScript/Next.js 의미가 같은 코드에 연결되는지 확인한다. 주요·보조 개념은 각각 5개 이하이며, 카드 하나는 질문 하나만 답하고, 학습 확인 답에는 코드 근거가 있어야 한다. 기준 커밋과 미확인 사항이 보이며, 실행하지 않은 테스트·미확인 런타임·작성자 의도가 사실처럼 표현되지 않아야 한다.
